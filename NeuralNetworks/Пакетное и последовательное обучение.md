**batch_size** — это **количество обучающих примеров, по которым вычисляется градиент перед одним обновлением весов**.

**Последовательное обучение** — это режим, при котором веса нейронной сети обновляются **после каждого отдельного обучающего примера**.
### Алгоритм:
1. Берётся один объект $(x,y)$
2. Считается предсказание $\hat{y}$
3. Вычисляется ошибка
4. Выполняется backpropagation
5. Веса обновляются
### Характеристика:
- `batch_size = 1`
- Частые обновления весов
- Шумный, но быстрый градиент
- Хорошо подходит для:
    - потоковых данных,
    - очень больших датасетов,
    - онлайн-обучения
### Минусы:
- Нестабильная сходимость
- Плохо векторизуется
- Может «скакать» вокруг минимума

**Пакетное обучение** — веса обновляются **один раз после обработки всей обучающей выборки**.
### Алгоритм:
1. Прогоняется весь датасет
2. Считается суммарная функция потерь
3. Вычисляется градиент
4. Веса обновляются один раз
### Характеристика:
- `batch_size = N` (где N — размер обучающей выборки)
- Точный градиент
- Стабильная сходимость
### Минусы:
- Большие затраты памяти
- Медленно на больших данных
- Плохо подходит для онлайн-режима

На практике используется **мини-пакетное обучение** — компромисс между двумя предыдущими подходами.
### Алгоритм:
1. Датасет разбивается на пакеты по `batch_size`
2. Для каждого пакета:
    - считается ошибка,
    - выполняется обновление весов
### Характеристика:
- `1 < batch_size < N`
- Баланс между скоростью и стабильностью
- Хорошо работает на GPU

Типичные значения:
- 16, 32, 64, 128, 256
