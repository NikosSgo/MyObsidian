## Виды функций принадлежности

Функции принадлежности используются для задания степени принадлежности элементов нечёткому множеству. На практике чаще всего применяются простые параметрические формы.

---
## 1. Треугольная функция принадлежности

Треугольная функция задаётся тремя параметрами ( a < b < c ).

$$  
\mu(x)=  
\begin{cases}  
0, & x \le a \  
\dfrac{x-a}{b-a}, & a < x \le b \  
\dfrac{c-x}{c-b}, & b < x < c \  
0, & x \ge c  
\end{cases}  
$$

**Свойства:**
- максимум равен 1 в точке $b$;
- симметрична или асимметрична;
- проста и вычислительно эффективна.

**Применение:** приближённое описание понятий типа «средний», «нормальный».

---
## 2. Трапециевидная функция принадлежности

Трапециевидная функция задаётся четырьмя параметрами ( a < b < c < d ).

$$
\mu(x)=  
\begin{cases}  
0, & x \le a \  
\dfrac{x-a}{b-a}, & a < x \le b \  
1, & b < x \le c \  
\dfrac{d-x}{d-c}, & c < x < d \  
0, & x \ge d  
\end{cases}
$$
**Свойства:**
- имеет плато, где ( \mu(x)=1 );
- устойчивость к шуму;
- расширенное ядро.

**Применение:** лингвистические термы «высокий», «допустимый».

---
## 3. S-образная функция принадлежности

S-образная функция используется для **плавного возрастания** степени принадлежности.

Задаётся параметрами ( a < b ).

Типичная форма:

$$  
\mu(x)=  
\begin{cases}  
0, & x \le a \  
2\left(\dfrac{x-a}{b-a}\right)^2, & a < x \le \dfrac{a+b}{2} \  
1 - 2\left(\dfrac{b-x}{b-a}\right)^2, & \dfrac{a+b}{2} < x < b \  
1, & x \ge b  
\end{cases}  
$$

**Свойства:**
- гладкий переход от 0 к 1;
- отсутствует резкая граница.

**Применение:** понятия «большой», «высокий», «достаточный».

---
## 4. Z-образная функция принадлежности

Z-образная функция является **зеркальным отражением S-образной**.

Задаётся параметрами ( a < b ).

$$ 
\mu(x)=  
\begin{cases}  
1, & x \le a \  
1 - 2\left(\dfrac{x-a}{b-a}\right)^2, & a < x \le \dfrac{a+b}{2} \  
2\left(\dfrac{b-x}{b-a}\right)^2, & \dfrac{a+b}{2} < x < b \  
0, & x \ge b  
\end{cases}  
$$

**Свойства:**
- плавное убывание;
- симметрия S-образной функции.

**Применение:** понятия «малый», «низкий», «недостаточный».

---
## Краткое сравнение

| Тип функции    | Форма | Переход          |
| -------------- | ----- | ---------------- |
| Треугольная    | ▲     | Линейный         |
| Трапециевидная | ⏢     | Линейный с плато |
| S-образная     | S     | Плавный рост     |
| Z-образная     | Z     | Плавное убывание |

---

### Экзаменационная формулировка

> Треугольные и трапециевидные функции принадлежности обеспечивают простое и наглядное задание нечётких множеств, тогда как S- и Z-образные функции позволяют моделировать плавные переходы между лингвистическими термами.
