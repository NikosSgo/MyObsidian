Этот проект представляет собой консольное приложение и нужен для миграции таблиц в postgres.

Проект содержит следующие зависимости:
- [[FluentMigrator]]
- [[Npgsql]]

В проекте содержится три файла:
- Program.cs
- [[MigrationRunner]].cs
- [[VersionTable]].cs
А также папка Scripts, содержащая сами миграции.

Program.cs одержит один метод Main. Он принимает строковые аргументы из консоли, если имеется параметр `--dryrun`, то код сразу прекращает своё действие. Если нет, то:
- Считывает переменную среды ASPNETCORE_ENVIRONMENT, отвечающую за окружение, с помощью пакета Enviroment из System.
- Далее с помощью этой переменной среды выбирается нужный конфиг под окружение
- Из конфига считывается ConnetctionString для подключения к БД
- Инстансируется [[MigrationRunner]] и запускаются миграции

В папке Scripts содержится следующие файлы:
- [[First Migration]] - с первой миграцией
