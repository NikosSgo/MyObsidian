Базовый абстрактный класс потребителей сообщений, который реализует батчевую обработку сообщений

Поля класса:
- connection - соединение с rabbit mq
- channel - канал для работы с очередью
- factory - фабрика соединений
- messageBuffer - буффер для батчевой обработки сообщений
- batchTimer - таймер, который принудительно запускает обработку батча через определённое время
- processingSemaphore - семафор для доступа к буфферу собщений

Методы:
- StartAsync - метод, который настраивает подключение к rabbitMq, очередь сообщений, семафор, префетч для батчевой обработки сообщений, очередь и асинхронного потребителя и подписывает для него обработчик
- OnMessageRecieved - асинхронный обработчик для каждого полученного сообщения, достаёт тело сообщения, добавляет сообщение в буффер и если буффер заполнился запускается обработку батча
- ProccessBatchByTimeout - функция, которая вызывается по таймеру, проверяет буффер и если в буффере есть сообщения запускает обработку батча
- ProccesBatch - функция обработки батча. Если буффер пуст, то ничего не происходит, иначе отправляет сообщения в абстрактную функцию обработки сообщений и отправляет подтверждение для всех сообщений. Если ошибка произошла делает BasicNack для возвращения всех сообщений в очередь
- ProcessMessage - абстрактный метод для обработки батча сообщений, который мы переопределяем в наследниках
