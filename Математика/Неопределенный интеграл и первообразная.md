# Неопределенный интеграл и первообразная

## Определение первообразной
Функция \(F(x)\) называется **первообразной** функции \(f(x)\) на отрезке, если \(F'(x) = f(x)\).

## Определение неопределенного интеграла
**Неопределенный интеграл** — множество всех первообразных:

$$\int f(x) \, dx = F(x) + C$$

где \(F'(x) = f(x)\), \(C\) — произвольная постоянная.

## Свойства
1. \(\left(\int f(x) \, dx\right)' = f(x)\)
2. \(\int F'(x) \, dx = F(x) + C\)
3. \(\int (f(x) \pm g(x)) \, dx = \int f(x) \, dx \pm \int g(x) \, dx\)
4. \(\int k f(x) \, dx = k \int f(x) \, dx\) (\(k \neq 0\))

## Таблица основных интегралов

| Подынтегральная функция | Интеграл |
|---|---|
| \(x^n\) (\(n \neq -1\)) | \(\frac{x^{n+1}}{n+1} + C\) |
| \(1/x\) | \(\ln|x| + C\) |
| \(e^x\) | \(e^x + C\) |
| \(a^x\) | \(\frac{a^x}{\ln a} + C\) |
| \(\sin x\) | \(-\cos x + C\) |
| \(\cos x\) | \(\sin x + C\) |
| \(1/\cos^2 x\) | \(\tan x + C\) |
| \(1/\sin^2 x\) | \(-\cot x + C\) |
| \(1/\sqrt{1-x^2}\) | \(\arcsin x + C\) |
| \(1/(1+x^2)\) | \(\arctan x + C\) |

## Примеры
1. \(\int 3x^2 \, dx = x^3 + C\)
2. \(\int (\sin x + e^x) \, dx = -\cos x + e^x + C\)
3. \(\int \frac{2x}{1+x^2} \, dx = \ln(1+x^2) + C\) (подстановка \(u = 1+x^2\))
