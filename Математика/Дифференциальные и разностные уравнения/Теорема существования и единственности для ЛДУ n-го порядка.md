## Теорема существования и единственности для ЛДУ n-го порядка

### Линейное дифференциальное уравнение n-го порядка
$$a_n(t)y^{(n)} + a_{n-1}(t)y^{(n-1)} + ... + a_1(t)y' + a_0(t)y = f(t)$$

### Задача Коши
$$y(t_0) = y_0, y'(t_0) = y'_0, ..., y^{(n-1)}(t_0) = y_0^{(n-1)}$$

### Теорема
Если $a_i(t)$ и $f(t)$ непрерывны на $[a, b]$ и $a_n(t) \neq 0$, то задача Коши имеет **единственное решение** на всём отрезке.

### Свойства решений линейных однородных уравнений

1. **Суперпозиция:** если $y_1, y_2$ — решения, то $\alpha y_1 + \beta y_2$ — решение
2. **Фундаментальная система решений (ФСР):** $n$ линейно независимых решений $y_1, ..., y_n$
3. **Вронскиан:** $W(y_1, ..., y_n) \neq 0 \Leftrightarrow$ решения линейно независимы

### Теорема о представлении общего решения
Общее решение: $y(t) = C_1 y_1(t) + C_2 y_2(t) + ... + C_n y_n(t)$

**Доказательство:** аналогично системам — линейная комбинация ФСР даёт любое решение, т.к. вектор-столбцы решений линейно независимы.
