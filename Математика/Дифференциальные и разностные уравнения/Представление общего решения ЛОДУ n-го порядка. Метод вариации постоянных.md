### Представление общего решения ЛОДУ n-го порядка с постоянными коэффициентами

Рассмотрим однородное уравнение с постоянными коэффициентами:
$$
y^{(n)} + a_1 y^{(n-1)} + \dots + a_n y = 0,\quad a_i \in \mathbb{C}
$$

Составляем **характеристическое уравнение**: $\lambda^n + a_1 \lambda^{n-1} + \dots + a_n = 0$.

Каждому корню $\lambda$ кратности $k$ соответствует $k$ линейно независимых решений:

| Корень $\lambda$ | Решения |
|---|---|
| $\lambda \in \mathbb{R}$, простой | $e^{\lambda x}$ |
| $\lambda \in \mathbb{R}$, кратности $k$ | $e^{\lambda x}, x e^{\lambda x}, \dots, x^{k-1} e^{\lambda x}$ |
| $\lambda = \alpha \pm i\beta$ (пара), простые | $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$ |
| $\lambda = \alpha \pm i\beta$, кратности $k$ | $e^{\alpha x}\cos\beta x,\ x e^{\alpha x}\cos\beta x,\ \dots$ и с $\sin$ |

**Общее решение** — линейная комбинация всех найденных фундаментальных решений.

**Пример:** $y''' - 3y'' + 3y' - y = 0$. Характеристическое: $\lambda^3 - 3\lambda^2 + 3\lambda - 1 = (\lambda-1)^3 = 0$.
$$
y(x) = (c_1 + c_2 x + c_3 x^2) e^x
$$

### Метод вариации произвольных постоянных (Лагранжа)

Для неоднородного уравнения $y^{(n)} + a_1(x) y^{(n-1)} + \dots + a_n(x) y = f(x)$.

Пусть $y_1,\dots,y_n$ — ФСР однородного уравнения. Частное решение ищем в виде:
$$
y_{\text{чн}}(x) = c_1(x) y_1(x) + \dots + c_n(x) y_n(x)
$$
где $c_i(x)$ — функции (вариации произвольных постоянных).

**Система для $c_i'(x)$:**
$$
\begin{cases}
c_1' y_1 + c_2' y_2 + \dots + c_n' y_n = 0 \\
c_1' y_1' + c_2' y_2' + \dots + c_n' y_n' = 0 \\
\vdots \\
c_1' y_1^{(n-2)} + c_2' y_2^{(n-2)} + \dots + c_n' y_n^{(n-2)} = 0 \\
c_1' y_1^{(n-1)} + c_2' y_2^{(n-1)} + \dots + c_n' y_n^{(n-1)} = f(x)
\end{cases}
$$

**Доказательство:** Дифференцируем $y_{\text{чн}}$ последовательно $n$ раз, каждый раз накладывая условие $\sum c_i' y_i^{(k)} = 0$ для $k = 0,\dots,n-2$. На $n$-м шаге получаем последнее уравнение с $f(x)$.

Определитель системы — вронскиан $W(x) \neq 0$, поэтому система имеет единственное решение $c_i'(x)$. Интегрируя, находим $c_i(x)$ и $y_{\text{чн}}(x)$.

**Пример для $y'' + y = \tg x$:** ФСР: $y_1 = \cos x$, $y_2 = \sin x$.
$$
\begin{cases}
c_1' \cos x + c_2' \sin x = 0 \\
-c_1' \sin x + c_2' \cos x = \tg x
\end{cases}
\Rightarrow c_1' = -\frac{\sin^2 x}{\cos x},\ c_2' = \sin x
$$
Интегрируем: $c_1 = -\int \frac{\sin^2 x}{\cos x}dx = \sin x - \ln|\sec x + \tg x|$, $c_2 = -\cos x$.
$$
y_{\text{чн}} = (\sin x - \ln|\sec x + \tg x|)\cos x - \cos x \sin x = -\cos x \ln|\sec x + \tg x|
$$
