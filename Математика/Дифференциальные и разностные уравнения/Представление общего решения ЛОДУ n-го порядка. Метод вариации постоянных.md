## Представление общего решения ЛОДУ n-го порядка

### Однородное уравнение с постоянными коэффициентами
$$a_n y^{(n)} + ... + a_1 y' + a_0 y = 0$$

### Характеристическое уравнение
$$a_n \lambda^n + ... + a_1 \lambda + a_0 = 0$$

**Случаи корней:**
- $\lambda_k$ — вещественное корень кратности $m$: $e^{\lambda_k t}, te^{\lambda_k t}, ..., t^{m-1}e^{\lambda_k t}$
- $\lambda = \alpha \pm i\beta$ — комплексные корни: $e^{\alpha t}\cos\beta t, e^{\alpha t}\sin\beta t$

### Метод вариации постоянных
Для неоднородного уравнения $L[y] = f(t)$:

1. Найти ФСР однородного уравнения $y_1, ..., y_n$
2. Ищем решение в виде: $y(t) = \sum_{k=1}^n C_k(t) y_k(t)$
3. Находим $C_k'(t)$ из системы:
$$\sum_{k=1}^n C_k'(t) y_k^{(j)}(t) = 0, \quad j = 0, 1, ..., n-2$$
$$\sum_{k=1}^n C_k'(t) y_k^{(n-1)}(t) = \frac{f(t)}{a_n(t)}$$

**Формула:** $C_k(t) = \int \frac{W_k(t)}{W(t)} dt$, где $W$ — Вронскиан, $W_k$ — определитель с заменой столбца.
