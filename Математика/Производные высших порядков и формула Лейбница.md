# Производные высших порядков и формула Лейбница

## Определение
**Вторая производная** — производная от производной: \(f''(x) = (f'(x))'\).

**n-я производная**: \(f^{(n)}(x) = (f^{(n-1)}(x))'\).

Обозначения: \(f''(x), f'''(x), f^{(n)}(x), y'', y^{(n)}\).

## Производные высших порядков элементарных функций

| Функция | \(n\)-я производная |
|---|---|
| \(e^{ax}\) | \(a^n e^{ax}\) |
| \(\sin(ax+b)\) | \(a^n \sin(ax+b + n\pi/2)\) |
| \(\cos(ax+b)\) | \(a^n \cos(ax+b + n\pi/2)\) |
| \(x^m\) | \(m(m-1)...(m-n+1) x^{m-n}\) |
| \(\ln x\) | \((-1)^{n-1} (n-1)! / x^n\) |

## Формула Лейбница
Для произведения двух функций:

$$(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}$$

где \(C_n^k = \frac{n!}{k!(n-k)!}\) — биномиальные коэффициенты.

**Аналогия:** как бином Ньютона \((a+b)^n = \sum C_n^k a^{n-k} b^k\).

## Примеры
1. \(y = x^2 e^x\): \(y'' = (x^2 + 4x + 2)e^x\)
2. \(y = \sin x \cdot \ln x\): по формуле Лейбница:
   \((\sin x \cdot \ln x)'' = \sin x \cdot (\ln x)'' + 2(\sin x)'(\ln x)' + (\sin x)'' \ln x\)
   \(= \sin x \cdot (-1/x^2) + 2\cos x \cdot (1/x) + (-\sin x) \ln x\)
3. \(y = x^{10}\): \(y^{(10)} = 10!\), \(y^{(11)} = 0\)
