# Производные от элементарных функций

## Таблица производных

| Функция \(f(x)\) | Производная \(f'(x)\) |
|---|---|
| \(c\) (константа) | \(0\) |
| \(x^n\) | \(n x^{n-1}\) |
| \(\sin x\) | \(\cos x\) |
| \(\cos x\) | \(-\sin x\) |
| \(\tan x\) | \(1/\cos^2 x\) |
| \(\cot x\) | \(-1/\sin^2 x\) |
| \(a^x\) | \(a^x \ln a\) |
| \(e^x\) | \(e^x\) |
| \(\log_a x\) | \(1/(x \ln a)\) |
| \(\ln x\) | \(1/x\) |
| \(\arcsin x\) | \(1/\sqrt{1-x^2}\) |
| \(\arccos x\) | \(-1/\sqrt{1-x^2}\) |
| \(\arctan x\) | \(1/(1+x^2)\) |

## Правила дифференцирования

### Сумма и разность
\((u \pm v)' = u' \pm v'\)

### Произведение
\((uv)' = u'v + uv'\)

### Частное
\((u/v)' = (u'v - uv')/v^2\), \(v \neq 0\)

### Формула цепочки
Если \(y = f(g(x))\), то \(y' = f'(g(x)) \cdot g'(x)\).

## Примеры
1. \(y = x^3 \sin x\): \(y' = 3x^2 \sin x + x^3 \cos x\)
2. \(y = e^{2x}\): \(y' = 2e^{2x}\) (цепочка)
3. \(y = \ln(x^2 + 1)\): \(y' = \frac{2x}{x^2 + 1}\)
4. \(y = \frac{\sin x}{x}\): \(y' = \frac{x \cos x - \sin x}{x^2}\)
