# Точки разрыва функции

## Определение
Точка \(x_0\) называется **точкой разрыва** функции \(f(x)\), если функция не непрерывна в этой точке.

## Классификация

### 1. Разрыв первого рода
Существуют конечные односторонние пределы: \(f(x_0 - 0)\) и \(f(x_0 + 0)\).

#### а) Устранимый разрыв
\(f(x_0 - 0) = f(x_0 + 0) \neq f(x_0)\) (или \(f(x_0)\) не определена).

**Пример:** \(f(x) = \frac{\sin x}{x}\) при \(x_0 = 0\): предел равен 1, но \(f(0)\) не определена.

#### б) Разрыв скачка
\(f(x_0 - 0) \neq f(x_0 + 0)\).

**Пример:** \(f(x) = \text{sgn}(x)\) при \(x_0 = 0\): \(f(0-0) = -1\), \(f(0+0) = 1\).

### 2. Разрыв второго рода
Хотя бы один из односторонних пределов не существует (или равен \(\pm\infty\)).

#### а) Бесконечный разрыв
\(f(x_0 - 0) = \pm\infty\) или \(f(x_0 + 0) = \pm\infty\).

**Пример:** \(f(x) = 1/x\) при \(x_0 = 0\): \(f(0+0) = +\infty\), \(f(0-0) = -\infty\).

#### б) Существенный разрыв
Односторонние пределы не существуют (колеблются).

**Пример:** \(f(x) = \sin(1/x)\) при \(x_0 = 0\): предел не существует.

## Свойства
- В точке разрыва функция может быть определена.
- Сумма, разность, произведение функций с разрывами первого рода — разрыв первого рода.
- Сумма функций с разрывами разного типа — разрыв второго рода.
