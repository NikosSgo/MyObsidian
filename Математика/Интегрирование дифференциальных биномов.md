# Интегрирование дифференциальных биномов

## Дифференциальный бином
Интеграл вида:

$$\int x^m (a + b x^n)^p \, dx$$

где \(m, n, p\) — рациональные числа, \(a, b \neq 0\).

## Подстановки Чебышева

### Случай 1: \(p\) — целое
Замена \(t = x^n\) (или \(x = t^{1/n}\)).

**Пример:** \(\int x^2 (1 + x^3)^4 \, dx\), \(p = 4\) — целое.
\(t = 1 + x^3\), \(dt = 3x^2 dx\), \(\int x^2 (1+x^3)^4 dx = \frac{1}{3} \int t^4 dt = \frac{t^5}{15} + C\).

### Случай 2: \(\frac{m+1}{n}\) — целое
Замена \(t = (a + b x^n)^{1/n}\) (или \(a + b x^n = t^n\)).

**Пример:** \(\int x^3 (1 + x^2)^{1/2} dx\), \(\frac{3+1}{2} = 2\) — целое.
\(t = (1 + x^2)^{1/2}\), \(t^2 = 1 + x^2\), \(2t dt = 2x dx\), \(x^2 = t^2 - 1\).
\(\int x^3 (1+x^2)^{1/2} dx = \int x^2 \cdot x \cdot t \, dx = \int (t^2-1) \cdot t \cdot t \, dt = \int (t^4 - t^2) dt\).

### Случай 3: \(\frac{m+1}{n} + p\) — целое
Замена \(t = (a + b x^n)^{1/n} / x\) (или \(a x^{-n} + b = t^n x^{-n}\)).

**Пример:** \(\int x^{-3} (1 + x^2)^{3/2} dx\), \(\frac{-3+1}{2} + 3/2 = -1 + 3/2 = 1/2\) — не целое. Попробуем другой пример.
\(\int x^{-2} (1 + x^2)^{1/2} dx\), \(\frac{-2+1}{2} + 1/2 = -1/2 + 1/2 = 0\) — целое.
\(t = \sqrt{1+x^2}/x\), \(t^2 = (1+x^2)/x^2 = x^{-2} + 1\), \(x^{-2} = t^2 - 1\).

## Замечание
Если ни одно условие не выполняется, интеграл не выражается через элементарные функции.
