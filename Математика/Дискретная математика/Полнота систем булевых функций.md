### Полнота систем булевых функций

**Система булевых функций** — это набор функций, например:
$$
\{ \land, \lor, \neg \}
$$
Система называется **полной** (функционально полной), если через неё можно выразить любую булеву функцию.

**Пример полной системы:** $\{ \land, \lor, \neg \}$ — через неё выражается любая функция (СДНФ/СКНФ).

**Пример неполной системы:** $\{ \land, \lor \}$ — нельзя выразить отрицание.

**Другие примеры полных систем:**
- $\{ \neg, \land \}$ (штрих Шеффера $x|y = \neg(x \land y)$ — один! единственный)
- $\{ \neg, \lor \}$ (стрелка Пирса $\downarrow$ — тоже один)
- $\{ \oplus, 1\}$ (сложение по модулю 2 и константа 1)

### Классы Поста

Для проверки полноты используют 5 классов Поста:

| Класс | Обозначение | Определение | Пример |
|---|---|---|---|
| Сохраняющие 0 | $T_0$ | $f(0,\dots,0) = 0$ | $x \land y$, $x \lor y$ |
| Сохраняющие 1 | $T_1$ | $f(1,\dots,1) = 1$ | $x \land y$, $x \lor y$ |
| Самодвойственные | $S$ | $f(\bar{x}_1,\dots,\bar{x}_n) = \overline{f(x_1,\dots,x_n)}$ | $x$, $\bar{x}$ |
| Монотонные | $M$ | $a \le b \Rightarrow f(a) \le f(b)$ | $x \land y$, $x \lor y$ |
| Линейные | $L$ | $f = a_0 \oplus a_1 x_1 \oplus \dots \oplus a_n x_n$ | $x \oplus y$, $x$ |

### Теорема Поста (о функциональной полноте)

**Формулировка:** Система булевых функций $B$ является полной **тогда и только тогда**, когда она содержит хотя бы одну функцию, не принадлежащую каждому из пяти классов $T_0, T_1, S, M, L$.

То есть в $B$ должна найтись функция:
- не из $T_0$ (не сохраняющая 0)
- не из $T_1$ (не сохраняющая 1)  
- не из $S$ (не самодвойственная)
- не из $M$ (не монотонная)
- не из $L$ (не линейная)

**Пример проверки:** Система $\{\land, \lor, \neg\}$:
- $\neg \notin T_0$ (так как $\neg 0 = 1$)
- $\neg \notin T_1$ (так как $\neg 1 = 0$)
- $\neg \in S$ (самодвойственная), но $\land \notin S$
- $\neg \notin M$ (немонотонная)
- $\land \notin L$ (нелинейная)

Все 5 классов «пробиты» — система полна.
