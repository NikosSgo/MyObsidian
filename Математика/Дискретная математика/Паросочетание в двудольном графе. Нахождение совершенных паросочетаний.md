## Паросочетание в двудольном графе

### Определения
**Двудольный граф** $G = (V_1 \cup V_2, E)$ — граф, вершины которого разделены на два непересекающихся множества, ребра соединяют вершины из разных множеств.

**Паросочетание** $M$ — множество рёбер, никакие два из которых не имеют общих вершин.

**Вершинное покрытие** — множество вершин, через которые проходит каждое ребро.

### Теорема Кёнига (для двудольных графов)
В двудольном графе размер максимального паросочетания равен размеру минимального вершинного покрытия.

### Алгоритм поиска максимального паросочетания

**Поиск augmenting path (алгоритм Куна):**
1. Начинаем с свободной вершины из $V_1$
2. Ищем путь чередования (через ребро не из M, затем из M, ...)
3. Если путь заканчивается свободной вершиной из $V_2$ — augmenting path найден
4. Инвертируем рёбра пути (добавляем в M, убираем из M)

**Сложность:** $O(|V| \cdot |E|)$

### Совершенное паросочетание
Паросочетание, в котором **все вершины** являются инцидентными рёбрам паросочетания.

**Теорема Холла:** В двудольном графе существует совершенное паросочетание $\Leftrightarrow$ для любого подмножества $S \subseteq V_1$ выполнено $|N(S)| \geq |S|$, где $N(S)$ — множество соседей $S$.
