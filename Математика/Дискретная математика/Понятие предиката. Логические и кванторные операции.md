## Предикат

**Предикат** — логическая функция, принимающая значения «истина» (T) или «ложь» (F) в зависимости от значений аргументов.

Обозначается: $P(x)$, $Q(x, y)$ и т.д.

**Пример:** $P(x): x > 5$ — истинно при $x = 7$, ложно при $x = 3$.

## Логические операции над предикатами

| Операция | Знак | Значение |
|----------|------|----------|
| Конъюнкция | $P \land Q$ | Истинна, если оба истинны |
| Дизъюнкция | $P \lor Q$ | Истинна, если хотя бы один истинен |
| Отрицание | $\lnot P$ | Инвертирует значение |
| Импликация | $P \rightarrow Q$ | Ложь только при $P = T, Q = F$ |
| Эквивалентность | $P \leftrightarrow Q$ | Истинна при совпадении значений |

**Свойства:** ассоциативность, коммутативность, дистрибутивность, законы де Моргана.

## Кванторы

### Универсальный квантор ($\forall$)

$\forall x \, P(x)$ — «для всех x выполняется P(x)»

**Пример:** $\forall x \in \mathbb{N}: x + 0 = x$ — истинно.

### Экзистенциальный квантор ($\exists$)

$\exists x \, P(x)$ — «существует хотя бы одно x, для которого P(x)»

**Пример:** $\exists x \in \mathbb{R}: x^2 = 4$ — истинно ($x = \pm 2$).

### Порядок кванторов

Порядок существенен: $\forall x \exists y \, P(x,y) \neq \exists y \forall x \, P(x,y)$

- $\forall x \exists y$: для каждого $x$ можно подобрать своё $y$
- $\exists y \forall x$: одно фиксированное $y$ работает для всех $x$

## Свободные и связанные переменные

- **Связанная переменная** — входит в область действия квантора: $\forall x (P(x) \rightarrow Q(x))$
- **Свободная переменная** — не связана никаким квантором: $P(x) \land \exists y \, Q(y)$ ($x$ свободна)

**Формула без свободных переменений** —.closed sentence (утверждение с определённым истинностным значением).

## Пример замены квантора

Утверждение: «Каждый студент сдаёт экзамен»

$$\forall x (\text{Студент}(x) \rightarrow \text{Сдаёт}(x))$$

Отрицание: $\exists x (\text{Студент}(x) \land \lnot \text{Сдаёт}(x))$ — «существует студент, который не сдаёт».
