Это способы записать булеву функцию по её таблице истинности. 

### CДНФ
---
**ДНФ** - это форма, где несколько булевых произведений соединены через или.
**СДНФ** - это такая ДНФ, где:
1. каждый элемент - это конъюнкция, то есть **И**
2. в каждой конъюнкции участвуют все переменные
3. каждая переменная входит сама либо с отрицанием
4. строится по строкам таблицы, где функция равна 1
