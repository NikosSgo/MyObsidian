Это способы записать булеву функцию по её таблице истинности. 

### CДНФ
---
**ДНФ** - это форма, где несколько булевых произведений соединены через или.
**СДНФ** - это такая ДНФ, где:
1. каждый элемент - это конъюнкция, то есть **И**
2. в каждой конъюнкции участвуют все переменные
3. каждая переменная входит сама либо с отрицанием
4. строится по строкам таблицы, где функция равна 1

#### Построение.
Правило следующее, проходим по всем строкам, где значение функции равно 1, если в таблице истинности 0, то берём с отрицанием, если 1, то без отрицания. 

### CКНФ
---
КНФ - это форма записи булевой функции, где несколько дизъюнкции соединены через конъюнкции
СКНФ - это такая КНФ, гдe:
1. каждый элемент - это дизъюнкции, то есть **ИЛИ**
2. в каждой дизъюнкции участвуют все переменные
3. каждая переменная входит сама либо с отрицанием
4. строится по строкам таблицы, где функция равна 0

#### Построение.
Правило следующее, проходим по всем строкам, где значение функции равно 0, если в таблице истинности 1, то берём с отрицанием, если 0, то без отрицания.


### Главное запомнить:

**СДНФ** строится по **единицам**
**СКНФ** строится по **нулям**
