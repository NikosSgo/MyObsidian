### Специальные комбинаторные числа

---

### Числа Стирлинга первого рода $s(n,k)$

**Обозначение:** $s(n,k)$ (или $c(n,k)$).

**Определение:** Коэффициенты в разложении убывающего факториала:
$$
x^{\underline{n}} = x(x-1)\dots(x-n+1) = \sum_{k=0}^n s(n,k) x^k
$$
(иногда со знаком $(-1)^{n-k}$ — signless Stirling numbers of the first kind).

**Комбинаторный смысл:** Количество перестановок $n$ элементов, содержащих ровно $k$ циклов.

**Пример:** $s(4,2) = 11$ — 11 перестановок 4 элементов с 2 циклами.

**Рекуррентность:**
$$
s(n,k) = s(n-1,k-1) - (n-1)s(n-1,k)
$$
с $s(0,0) = 1$, $s(n,0) = 0$ при $n>0$, $s(0,k) = 0$ при $k>0$.

---

### Числа Стирлинга второго рода $S(n,k)$

**Обозначение:** $S(n,k)$ (или $\left\{ {n \atop k} \right\}$).

**Определение:** Количество способов разбить множество из $n$ элементов на $k$ непустых подмножеств (неупорядоченных блоков).

**Пример:** $S(4,2) = 7$:
$$
\{1\}\{2,3,4\},\ \{2\}\{1,3,4\},\ \{3\}\{1,2,4\},\ \{4\}\{1,2,3\},\ \{1,2\}\{3,4\},\ \{1,3\}\{2,4\},\ \{1,4\}\{2,3\}
$$

**Рекуррентность:**
$$
S(n,k) = S(n-1,k-1) + k \cdot S(n-1,k)
$$
с $S(0,0) = 1$, $S(n,0) = 0$ при $n>0$, $S(0,k) = 0$ при $k>0$.

**Связь со степенями:** $x^n = \sum_{k=0}^n S(n,k) x^{\underline{k}}$

**Таблица значений $S(n,k)$:**
| n\k | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 0 | 1 | | | | | |
| 1 | 0 | 1 | | | | |
| 2 | 0 | 1 | 1 | | | |
| 3 | 0 | 1 | 3 | 1 | | |
| 4 | 0 | 1 | 7 | 6 | 1 | |
| 5 | 0 | 1 | 15 | 25 | 10 | 1 |

### Числа Бэлла $B_n$

**Определение:** Количество всех разбиений $n$-элементного множества на непустые подмножества:
$$
B_n = \sum_{k=1}^n S(n,k)
$$

**Первые значения:** $B_0=1$, $B_1=1$, $B_2=2$, $B_3=5$, $B_4=15$, $B_5=52$.

**Рекуррентность:**
$$
B_{n+1} = \sum_{k=0}^n \binom{n}{k} B_k
$$

**Производящая функция:**
$$
\sum_{n=0}^\infty B_n \frac{x^n}{n!} = e^{e^x - 1}
$$

### Числа Каталана $C_n$

**Определение:** Количество правильных скобочных последовательностей из $n$ пар скобок.

**Первые значения:** $C_0=1$, $C_1=1$, $C_2=2$, $C_3=5$, $C_4=14$, $C_5=42$.

**Рекуррентность:**
$$
C_n = \sum_{k=0}^{n-1} C_k C_{n-1-k},\quad C_0 = 1
$$

**Явная формула:**
$$
C_n = \frac{1}{n+1}\binom{2n}{n}
$$

**Производящая функция:** $C(x) = \frac{1 - \sqrt{1 - 4x}}{2x}$

**Другие интерпретации чисел Каталана:**
- Количество триангуляций выпуклого $(n+2)$-угольника
- Количество бинарных деревьев с $n$ внутренними вершинами
- Количество путей Дика (путь из $(0,0)$ в $(2n,0)$ с шагами $(1,1)$ и $(1,-1)$ без ухода ниже оси $Ox$)
- Количество способов расставить $n$ пар скобок

**Пример:** Для $n=3$:
$$
C_3 = \frac{1}{4}\binom{6}{3} = \frac{20}{4} = 5
$$
Пять правильных скобочных последовательностей: `((()))`, `(()())`, `(())()`, `()(())`, `()()()`.
