## Определения предела функции

### Определение по Коши (ε-δ определение)

Функция $f(x)$ имеет предел $A$ при $x \to x_0$, если для любого $\varepsilon > 0$ существует такое $\delta > 0$, что для всех $x \in D_f$, удовлетворяющих неравенству $0 < |x - x_0| < \delta$, выполняется неравенство:
$$|f(x) - A| < \varepsilon$$

Обозначается: $\lim_{x \to x_0} f(x) = A$

### Определение по Гейне (последовательное определение)

Функция $f(x)$ имеет предел $A$ при $x \to x_0$, если для любой последовательности $\{x_n\} \subset D_f$,such that $x_n \neq x_0$ и $\lim_{n \to \infty} x_n = x_0$, выполняется:
$$\lim_{n \to \infty} f(x_n) = A$$

### Эквивалентность определений

**Теорема:** Определение по Коши и определение по Гейне эквивалентны.

**Доказательство эквивалентности:**

1. **Из определения по Коши следует определение по Гейне:**
   Пусть выполнено ε-δ определение. Для последовательности $x_n \to x_0$ ($x_n \neq x_0$) при данном $\varepsilon > 0$ существует $N$, такое что при $n > N$: $|x_n - x_0| < \delta$, следовательно $|f(x_n) - A| < \varepsilon$.

2. **Из определения по Гейне следует определение по Коши:**
   Предположим, что ε-δ определение не выполнено. Тогда существует $\varepsilon_0 > 0$ такое, что для любого $\delta > 0$ найдется $x$ при $0 < |x - x_0| < \delta$, но $|f(x) - A| \geq \varepsilon_0$.

   Возьмем $\delta_n = 1/n$. Тогда существуют $x_n$ такие, что $0 < |x_n - x_0| < 1/n$ и $|f(x_n) - A| \geq \varepsilon_0$. Последовательность $x_n \to x_0$, но $f(x_n) \not\to A$, противоречие.

### Примеры

**Пример 1:** $\lim_{x \to 2} (3x - 1) = 5$

По Коши: при $|x - 2| < \varepsilon/3$ имеем $|3x - 1 - 5| = 3|x - 2| < \varepsilon$

**Пример 2:** $\lim_{x \to 0} \frac{\sin x}{x} = 1$

Для любой последовательности $x_n \to 0$, $x_n \neq 0$: $\lim_{n \to \infty} \frac{\sin x_n}{x_n} = 1$
