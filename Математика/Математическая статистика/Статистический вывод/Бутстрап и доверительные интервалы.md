**Бутстрап** — метод оценки неопределённости статистики с помощью повторной выборки с возвращением из имеющихся данных.

Порядок действий:

- из исходной выборки размера $n$ случайно выбирают $n$ наблюдений с возвращением;
- считают нужную статистику: среднее, медиану, разность средних, коэффициент модели;
- повторяют процедуру много раз;
- по распределению полученных статистик оценивают стандартную ошибку и интервал.

Бутстрап полезен, когда формула для стандартной ошибки сложна или неизвестна, например для медианы и сложных метрик. Он предполагает, что исходная выборка достаточно хорошо представляет генеральную совокупность; не устраняет смещение данных и зависимость наблюдений.

**Доверительный интервал** — диапазон возможных значений неизвестного параметра, построенный по выборке.

- При уровне доверия 95% около 95% интервалов, построенных одинаковым способом на повторных выборках, будут содержать истинный параметр.
- Более широкий интервал означает меньшую точность оценки.
- Интервал сужается при увеличении размера качественной выборки и уменьшается при большем разбросе данных.

Простой интервал для среднего при большой выборке имеет вид $\bar{x}\pm z\cdot SE(\bar{x})$, где $z$ — критическое значение. Если дисперсия неизвестна и выборка небольшая, обычно используют [[Дескриптивный анализ/Виды распределений данных/Распределение Стьюдента|t-распределение Стьюдента]].
