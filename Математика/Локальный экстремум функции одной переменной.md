# Локальный экстремум функции одной переменной

## Определения
Точка \(x_0\) называется **точкой локального максимума** (минимума), если существует окрестность, в которой \(f(x) \leq f(x_0)\) (\(f(x) \geq f(x_0)\)).

## Необходимое условие
Если \(f(x)\) дифференцируема в точке экстремума \(x_0\), то \(f'(x_0) = 0\).

**Замечание:** обратное неверно: \(f'(x_0) = 0\) не гарантирует экстремума (например, \(f(x) = x^3\) в \(x=0\)).

## Достаточные условия

### Первое sufficient условие (смена знака производной)
- Если \(f'(x)\) меняет знак с «+» на «-» в точке \(x_0\), то \(x_0\) — максимум.
- Если \(f'(x)\) меняет знак с «-» на «+» в точке \(x_0\), то \(x_0\) — минимум.

### Второе sufficient условие (знак второй производной)
Если \(f'(x_0) = 0\) и:
- \(f''(x_0) < 0\), то \(x_0\) — максимум.
- \(f''(x_0) > 0\), то \(x_0\) — минимум.
- \(f''(x_0) = 0\) — тест неинформативен.

## Алгоритм нахождения экстремумов
1. Найти область определения.
2. Найти \(f'(x)\).
3. Решить \(f'(x) = 0\) (стационарные точки).
4. Проверить знак \(f'(x)\) в окрестности или вычислить \(f''(x_0)\).
5. Вычислить значения функции в точках экстремума.

## Пример
\(f(x) = x^3 - 3x\):
1. \(f'(x) = 3x^2 - 3 = 3(x-1)(x+1)\)
2. \(f'(x) = 0\) при \(x = \pm 1\)
3. \(f''(x) = 6x\): \(f''(1) = 6 > 0\) (минимум), \(f''(-1) = -6 < 0\) (максимум)
4. \(f(1) = -2\) (минимум), \(f(-1) = 2\) (максимум)
