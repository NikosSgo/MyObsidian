# Предел последовательности

## Определение (ε-N)
Последовательность \(x_n\) имеет предел \(a\), если для любого \(\varepsilon > 0\) существует такое натуральное \(N\), что для всех \(n > N\) выполняется \(|x_n - a| < \varepsilon\).

Обозначение: \(\lim_{n \to \infty} x_n = a\) или \(x_n \to a\).

## Свойства пределов
1. **Единственность**: предел последовательности唯一。
2. **Арифметические операции**:
   - \(\lim (x_n + y_n) = \lim x_n + \lim y_n\)
   - \(\lim (x_n \cdot y_n) = \lim x_n \cdot \lim y_n\)
   - \(\lim (x_n / y_n) = \lim x_n / \lim y_n\) (если \(\lim y_n \neq 0\))
3. **Сохранение порядка**: если \(x_n \leq y_n\), то \(\lim x_n \leq \lim y_n\).

## Теорема о двух милиционерах (сжатия)
Если \(a_n \leq x_n \leq b_n\) и \(\lim a_n = \lim b_n = c\), то \(\lim x_n = c\).

## Примеры
- \(x_n = 1/n\) → 0 (поскольку для \(\varepsilon > 0\) берем \(N > 1/\varepsilon\))
- \(x_n = (1 + 1/n)^n\) → \(e \approx 2.71828\) (второй замечательный предел)
- \(x_n = (-1)^n\) не имеет предела (расходится)
