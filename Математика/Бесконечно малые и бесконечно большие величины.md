# Бесконечно малые и бесконечно большие величины

## Бесконечно малая величина
Функция \(\alpha(x)\) называется бесконечно малой при \(x \to a\), если \(\lim_{x \to a} \alpha(x) = 0\).

**Свойства:**
1. Конечное число бесконечно малых — бесконечно малая.
2. Произведение бесконечно малой на ограниченную функцию — бесконечно малая.
3. Сумма бесконечно малых — бесконечно малая.

## Порядок бесконечно малых
Пусть \(\alpha(x), \beta(x)\) — бесконечно малые при \(x \to a\).
- \(\beta(x) = o(\alpha(x))\) (много меньше), если \(\lim \beta/\alpha = 0\).
- \(\beta(x) = O(\alpha(x))\) (не более чем много меньше), если \(\lim \sup |\beta/\alpha| < \infty\).
- \(\beta(x) \sim \alpha(x)\) (эквивалентны), если \(\lim \beta/\alpha = 1\).

**Примеры:** при \(x \to 0\):
- \(x^2 = o(x)\), \(x = o(\sqrt{x})\)
- \(\sin x \sim x\), \(1 - \cos x \sim x^2/2\)

## Бесконечно большая величина
Функция \(f(x)\) называется бесконечно большой при \(x \to a\), если для любого \(M > 0\) существует \(\delta > 0\), что при \(0 < |x - a| < \delta\) выполняется \(|f(x)| > M\).

**Связь:** \(f(x)\) — бесконечно большая при \(x \to a\) тогда и только тогда, когда \(1/f(x)\) — бесконечно малая.

## Примеры
- При \(x \to 0\): \(1/x\) — бесконечно большая.
- При \(x \to \infty\): \(x^n\) (n>0) — бесконечно большая, \(e^x\) — бесконечно большая.
