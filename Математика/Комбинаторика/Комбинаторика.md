**Комбинаторика** изучает способы выбора и расположения элементов конечных множеств и методы подсчёта числа таких способов.

## Основные правила

- **Правило суммы**: если объект можно выбрать одним из нескольких взаимоисключающих способов, которых соответственно $m$ и $n$, то всего способов
  $$m+n.$$
- **Правило произведения**: если действие состоит из последовательных этапов, первый можно выполнить $m$ способами, а второй для каждого результата — $n$ способами, то всего
  $$m\cdot n.$$
- **Правило дополнения**: иногда проще вычесть число нежелательных вариантов из общего числа:
  $$N(\overline A)=N(\Omega)-N(A).$$
- **Принцип включения—исключения** для двух множеств:
  $$|A\cup B|=|A|+|B|-|A\cap B|.$$

Факториал:

$$n!=1\cdot2\cdot\ldots\cdot n, \qquad 0!=1.$$

## Перестановки

**Перестановка** — упорядочение всех $n$ элементов. Порядок важен, выбираются все элементы.

- Без повторений:
  $$P_n=n!.$$
- С повторениями, если среди $n$ элементов есть группы одинаковых размеров $n_1,\ldots,n_m$:
  $$P(n_1,\ldots,n_m)=\frac{n!}{n_1!\cdots n_m!}.$$

Пример: пять разных книг можно расставить на полке $5!=120$ способами.

## Размещения

**Размещение из $n$ по $k$** — выбор и упорядочение $k$ элементов из $n$. Порядок важен, выбирается часть элементов.

- Без повторений:
  $$A_n^k=\frac{n!}{(n-k)!}.$$
- С повторениями:
  $$\overline A_n^k=n^k.$$

Пример: золотую, серебряную и бронзовую медали среди десяти участников можно распределить

$$A_{10}^3=10\cdot9\cdot8$$

способами.

## Сочетания

**Сочетание из $n$ по $k$** — выбор $k$ элементов из $n$ без учёта порядка.

- Без повторений:
  $$C_n^k=\binom nk=\frac{n!}{k!(n-k)!}.$$
- С повторениями:
  $$\overline C_n^k=\binom{n+k-1}{k}.$$

Пример: команду из трёх человек среди десяти выбирают

$$C_{10}^3$$

способами, поскольку порядок участников не важен.

## Как выбрать формулу

- Выбираются все элементы и важен порядок — перестановки.
- Выбирается $k$ элементов из $n$ и важен порядок — размещения.
- Выбирается $k$ элементов из $n$ и порядок не важен — сочетания.
- Затем отдельно определить, разрешены ли повторения.

Связь размещений и сочетаний:

$$A_n^k=C_n^k\cdot k!,$$

поскольку каждую выбранную группу из $k$ элементов можно упорядочить $k!$ способами.
