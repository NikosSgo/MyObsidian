# Метод множителей Лагранжа

## Задача

Найти **условный экстремум** функции $f(x, y)$ при ограничении $g(x, y) = 0$.

## Функция Лагранжа

$$L(x, y, \lambda) = f(x, y) + \lambda \cdot g(x, y)$$

где $\lambda$ — множитель Лагранжа.

## Необходимые условия

Стационарная точка $L$:

$$\frac{\partial L}{\partial x} = f_x + \lambda g_x = 0$$
$$\frac{\partial L}{\partial y} = f_y + \lambda g_y = 0$$
$$\frac{\partial L}{\partial \lambda} = g(x, y) = 0$$

> **Смысл:** $\nabla f = -\lambda \nabla g$ — градиенты параллельны на экстремуме.

## Геометрическая интерпретация

На экстремуме градиент $\nabla f$ **параллелен** градиенту $\nabla g$ (нормали к кривой ограничения). Точки экстремума — точки, где линия уровня $f = c$ **касается** кривой $g = 0$.

## Множественные ограничения

Для $m$ ограничений $g_1 = 0, \dots, g_m = 0$:

$$L = f + \lambda_1 g_1 + \dots + \lambda_m g_m$$

## Достаточные условия

Обычно проверяют **второе приближение** — знак выражения через вторые производные $L$ на касательном пространстве. На экзамене достаточно проверить несколько точек и сравнить значения $f$.

## Пример 1: Без ограничений по краям

Найти экстремум $f(x,y) = xy$ при $x^2 + y^2 = 1$.

$L = xy + \lambda(x^2 + y^2 - 1)$

$y + 2\lambda x = 0$, $x + 2\lambda y = 0$, $x^2 + y^2 = 1$.

Из первых двух: $x^2 = y^2$, т.е. $x = \pm y$. С учётом 3-го: точки $(±\frac{1}{\sqrt{2}}, ±\frac{1}{\sqrt{2}})$.

Максимум: $f = \frac{1}{2}$ в $(\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}})$ и $(-\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}})$.

Минимум: $f = -\frac{1}{2}$ в $(\frac{1}{\sqrt{2}}, -\frac{1}{\sqrt{2}})$ и $(-\frac{1}{\sqrt{2}}, \frac{1}{\sqrt{2}})$.

## Пример 2: Задача о максимальном объёме

Максимизировать $V = xyz$ при $\frac{x}{a} + \frac{y}{b} + \frac{z}{c} = 1$ ($x, y, z > 0$).

$L = xyz + \lambda(\frac{x}{a} + \frac{y}{b} + \frac{z}{c} - 1)$

Решение: $x = \frac{a}{3}$, $y = \frac{b}{3}$, $z = \frac{c}{3}$, $V_{\max} = \frac{abc}{27}$.
