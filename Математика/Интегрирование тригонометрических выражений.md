# Интегрирование тригонометрических выражений

## Интегралы вида \(\int \sin^m x \cos^n x \, dx\)

### Случай 1: хотя бы один показатель нечетный
Если \(m\) нечетно: \(m = 2k+1\), выделяем \(\sin x\), замена \(t = \cos x\).
Если \(n\) нечетно: \(n = 2k+1\), выделяем \(\cos x\), замена \(t = \sin x\).

**Пример:** \(\int \sin^3 x \cos^2 x \, dx = \int \sin^2 x \cos^2 x \sin x \, dx\)
\(t = \cos x\), \(dt = -\sin x dx\): \(-\int (1-t^2) t^2 dt = -\frac{t^3}{3} + \frac{t^5}{5} + C\).

### Случай 2: оба показателя четные
Используем формулы понижения степени:
- \(\sin^2 x = (1 - \cos 2x)/2\)
- \(\cos^2 x = (1 + \cos 2x)/2\)

**Пример:** \(\int \sin^2 x \cos^2 x \, dx = \int \frac{1 - \cos 2x}{2} \cdot \frac{1 + \cos 2x}{2} dx = \frac{1}{4} \int (1 - \cos^2 2x) dx\).

## Интегралы с тангенсами и секансами

### \(\int \tan^m x \sec^n x \, dx\)
Если \(n\) четно: замена \(t = \tan x\), используя \(\sec^2 x = 1 + \tan^2 x\).
Если \(m\) нечетно: замена \(t = \sec x\), выделяя \(\sec x \tan x\).

**Пример:** \(\int \tan x \sec^2 x \, dx\), \(t = \tan x\): \(\int t \, dt = t^2/2 + C = \tan^2 x / 2 + C\).

## Универсальная подстановка Коши (подстановка Вейерштрасса)
Для рациональных функций от \(\sin x, \cos x\):

$$t = \tan\frac{x}{2}$$

Тогда:
- \(\sin x = \frac{2t}{1+t^2}\)
- \(\cos x = \frac{1-t^2}{1+t^2}\)
- \(dx = \frac{2 \, dt}{1+t^2}\)

**Пример:** \(\int \frac{dx}{1 + \cos x} = \int \frac{1}{1 + \frac{1-t^2}{1+t^2}} \cdot \frac{2 \, dt}{1+t^2} = \int \frac{2 \, dt}{2} = t + C = \tan\frac{x}{2} + C\).
