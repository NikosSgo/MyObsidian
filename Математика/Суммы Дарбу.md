# Суммы Дарбу

## Разбиение
Разбиение отрезка \([a, b]\) на \(n\) частей: \(P = \{a = x_0, x_1, \ldots, x_n = b\}\).

## Верхняя и нижняя суммы Дарбу
Для каждого отрезка \([x_{i-1}, x_i]\):
- \(m_i = \inf_{x \in [x_{i-1}, x_i]} f(x)\) (infimum)
- \(M_i = \sup_{x \in [x_{i-1}, x_i]} f(x)\) (supremum)

**Нижняя сумма Дарбу:**
$$L(f, P) = \sum_{i=1}^n m_i \Delta x_i$$

**Верхняя сумма Дарбу:**
$$U(f, P) = \sum_{i=1}^n M_i \Delta x_i$$

## Свойства
1. \(L(f, P) \leq \int_a^b f(x) dx \leq U(f, P)\) (если интеграл существует)
2. При уточнении разбиения \(P'\) ( \(P \subset P'\) ): \(L(f, P) \leq L(f, P')\) и \(U(f, P') \leq U(f, P)\)
3. Для любых разбиений \(P_1, P_2\): \(L(f, P_1) \leq U(f, P_2)\)

## Теорема Дарбу
Предел нижних сумм равен пределу верхних сумм при диаметре разбиения \(||P|| \to 0\):

$$\lim_{||P|| \to 0} L(f, P) = \lim_{||P|| \to 0} U(f, P) = \int_a^b f(x) dx$$

## Критерий интегрируемости Римана
Функция \(f(x)\) интегрируема на \([a, b]\) тогда и только тогда, когда:

$$\lim_{||P|| \to 0} (U(f, P) - L(f, P)) = 0$$

Или эквивалентно: для любого \(\varepsilon > 0\) существует разбиение \(P\), такое что \(U(f, P) - L(f, P) < \varepsilon\).

## Пример
\(f(x) = x\) на \([0, 1]\), равномерное разбиение: \(x_i = i/n\).
- \(m_i = (i-1)/n\), \(M_i = i/n\)
- \(L = \sum_{i=1}^n \frac{i-1}{n} \cdot \frac{1}{n} = \frac{1}{n^2} \sum_{i=0}^{n-1} i = \frac{n-1}{2n}\)
- \(U = \sum_{i=1}^n \frac{i}{n} \cdot \frac{1}{n} = \frac{n+1}{2n}\)
- \(U - L = \frac{1}{n} \to 0\), значит, \(\int_0^1 x dx = 1/2\) ✓
