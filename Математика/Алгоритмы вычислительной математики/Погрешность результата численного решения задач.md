### Погрешность результата численного решения задач

#### Источники и классификация погрешности

1. **Неустранимая погрешность** — обусловлена неточностью исходных данных (погрешность измерений, констант).
2. **Погрешность метода** — связана с заменой исходной задачи приближённой (замена производной конечной разностью, отбрасывание членов ряда).
3. **Вычислительная погрешность (ошибка округления)** — связана с конечной разрядной сеткой ЭВМ.

**Полная погрешность** = неустранимая + погрешность метода + вычислительная.

---

### Предельная абсолютная и относительная погрешности

Пусть $a$ — точное значение, $\tilde{a}$ — приближение.

**Абсолютная погрешность:** $\Delta = |a - \tilde{a}|$.

Так как $a$ неизвестно, вводят **предельную абсолютную погрешность** $\Delta_a$ — число, заведомо не меньшее истинной погрешности:
$$
|a - \tilde{a}| \le \Delta_a
$$
Тогда $a = \tilde{a} \pm \Delta_a$.

**Относительная погрешность:** $\delta = \Delta_a / |\tilde{a}|$ (часто в процентах).

**Предельная относительная погрешность:** $\delta_a = \Delta_a / |\tilde{a}|$, так что:
$$
\left|\frac{a - \tilde{a}}{\tilde{a}}\right| \le \delta_a
$$

### Погрешность арифметических действий

Пусть $\tilde{x} = x \pm \Delta_x$, $\tilde{y} = y \pm \Delta_y$.

| Операция | Абсолютная погрешность | Относительная погрешность |
|---|---|---|
| Сложение | $\Delta_{x+y} \le \Delta_x + \Delta_y$ | $\delta_{x+y} \le \max(\delta_x, \delta_y)$ при $x,y > 0$ |
| Вычитание | $\Delta_{x-y} \le \Delta_x + \Delta_y$ | $\delta_{x-y} \le \frac{\Delta_x + \Delta_y}{\|x-y\|}$ (может расти катастрофически) |
| Умножение | $\Delta_{xy} \le \|y\|\Delta_x + \|x\|\Delta_y$ | $\delta_{xy} \le \delta_x + \delta_y$ |
| Деление | $\Delta_{x/y} \le \frac{\|x\|\Delta_y + \|y\|\Delta_x}{y^2}$ | $\delta_{x/y} \le \delta_x + \delta_y$ |

**Катастрофическая потеря точности:** при вычитании близких чисел относительная погрешность резко возрастает. Пример: $1.000001 - 1.000000 = 0.000001$ — при точности $10^{-6}$ получаем ноль значащих цифр.
