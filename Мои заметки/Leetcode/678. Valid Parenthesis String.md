# [678. Valid Parenthesis String](https://leetcode.com/problems/valid-parenthesis-string/)
---
### Task
---
Given a string `s` containing only three types of characters: `'('`, `')'` and `'*'`, return `true` _if_ `s` _is **valid**_.

The following rules define a **valid** string:

- Any left parenthesis `'('` must have a corresponding right parenthesis `')'`.
- Any right parenthesis `')'` must have a corresponding left parenthesis `'('`.
- Left parenthesis `'('` must go before the corresponding right parenthesis `')'`.
- `'*'` could be treated as a single right parenthesis `')'` or a single left parenthesis `'('` or an empty string `""`.

**Example 1:**

**Input:** s = "()"
**Output:** true

**Example 2:**

**Input:** s = "(*)"
**Output:** true

**Example 3:**

**Input:** s = "(*))"
**Output:** true

**Example 4:**

**Input:** s = "("
**Output:** false

**Constraints:**

- `1 <= s.length <= 100`
- `s[i]` is `'('`, `')'` or `'*'`.

### Solution

``` C#
public class Solution {

    public bool CheckValidString(string s) {
        int low = 0;
        int high = 0;

        foreach ( char c in s) {
            if (c == '('){
                low ++; high ++;
            }
            else if ( c == ')') {
                low --; high --;
            }
            else {
               low --; high ++;
            }
            if (high < 0 ) return false;
            if (low  < 0) low = 0;
        }
        return low == 0;
    }

    private bool PreviousVersion(string s)
    {
        int queueCount = 0;
        int jokerCount = 0;
        int closeJokerCount = 0;

        foreach ( char c in s) {
            if (c == '(') queueCount ++;
            else if ( c == '*' && queueCount == 0) closeJokerCount ++;
            else if ( c == '*') jokerCount ++;
            else {
                if (queueCount == 0 && jokerCount == 0 && closeJokerCount == 0) return false;
                if (closeJokerCount != 0 ) closeJokerCount --;
                else if (queueCount != 0 ) queueCount --;
                else jokerCount --;
            }

  

        }

  

        return queueCount <= jokerCount;

    }

}
```
