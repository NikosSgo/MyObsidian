### **Команды Linux для управления файлами и каталогами**

**Базовые команды навигации и управления:**
*   `pwd` — показать текущий каталог.
*   `ls` — список файлов и каталогов.
    *   `ls -l` — подробный список.
    *   `ls -a` — показать скрытые файлы.
*   `cd` — сменить каталог.
    *   `cd ~` — перейти в домашний каталог.
    *   `cd ..` — перейти на уровень выше.
*   `mkdir` — создать каталог.
*   `rmdir` — удалить пустой каталог.
*   `rm` — удалить файл.
    *   `rm -r` — удалить каталог рекурсивно.
*   `cp` — копировать.
*   `mv` — переместить или переименовать.
*   `cat` — просмотреть содержимое файла.
*   `less`, `more` — постраничный просмотр.
*   `head`, `tail` — показать начало/конец файла.
*   `find` — найти файлы по имени, размеру, дате.
*   `grep` — поиск текста в файлах.

**Команды для работы с процессами и системой:**
*   `ps` — список процессов.
    *   `ps aux` — все процессы.
*   `top`, `htop` — монитор процессов.
*   `kill` — завершить процесс.
*   `systemctl` — управление службами (systemd).
*   `df` — информация о свободном месте на дисках.
*   `du` — размер файлов и каталогов.
*   `mount`, `umount` — монтирование/размонтирование ФС.
*   `fdisk`, `gdisk`, `parted` — управление разделами.
*   `chmod` — изменить права доступа.
*   `chown` — изменить владельца.

### **Файловые системы Linux**

**Основные файловые системы:**
1.  **ext4 (Fourth Extended Filesystem)** — стандартная для большинства дистрибутивов. Надёжная, журналируемая, поддерживает большие тома и файлы.
2.  **XFS** — высокопроизводительная, лучше для больших файлов. Использует журналирование метаданных.
3.  **Btrfs** — современная, с поддержкой снапшотов, сжатия, RAID. Альтернатива LVM.
4.  **FAT32**, **NTFS**, **exFAT** — для совместимости с Windows и съёмных носителей.
5.  **swap** — раздел подкачки.

**Особенности:**
*   В Linux всё монтируется в единое дерево каталогов.
*   Журналирование — запись изменений в журнал перед внесением в ФС для сохранности при сбоях.
*   **Inode** — структура, хранящая метаданные файла (права, владельца, время, указатели на блоки данных). Имя файла хранится отдельно в каталоге.

### **Таблицы разделов MBR и GPT**

**MBR (Master Boot Record) — устаревающий стандарт.**
*   Расположен в **первом секторе** диска (512 байт).
*   **Структура:** Загрузчик (446 байт) + Таблица разделов (64 байта, 4 записи) + Сигнатура (2 байта).
*   **Ограничения:**
    *   Максимум **4 первичных** раздела (или 3 первичных + 1 расширенный, внутри которого можно создавать логические).
    *   Максимальный размер диска — **2.2 ТБ**.
    *   Хранится только одна копия таблицы, повреждение ведёт к потере данных.
*   Использует **цилиндр/головку/сектор (CHS)** и **логические блоки (LBA)**.

**GPT (GUID Partition Table) — современный стандарт (часть UEFI).**
*   Расположен в **начале и конце** диска (для избыточности).
*   **Структура:**
    *   **Protective MBR** — для совместимости со старыми системами.
    *   **Заголовок GPT** — содержит сигнатуру, CRC32, расположение таблицы.
    *   **Таблица разделов** — массив записей (обычно 128), каждая содержит GUID типа, уникальный GUID раздела, имя, атрибуты.
*   **Преимущества:**
    *   Поддержка дисков **более 2.2 ТБ** (до 9.4 ЗБ).
    *   До **128 разделов** (стандартно) без деления на первичные/логические.
    *   **Избыточность** — копия таблицы и заголовка в конце диска.
    *   **CRC32** для проверки целостности.
    *   **GUID** для уникальной идентификации разделов и их типов.
*   Требует **UEFI** для загрузки (хотя данные можно хранить и с BIOS, но загрузка сложнее).

**Ключевые отличия:**

| Параметр                 | **MBR**               | **GPT**                   |
| ------------------------ | --------------------- | ------------------------- |
| **Макс. размер диска**   | 2.2 ТБ                | ~9.4 ЗБ (эксабайты)       |
| **Макс. число разделов** | 4 (или 3+расширенный) | 128 (стандартно)          |
| **Избыточность**         | Нет (одна копия)      | Да (копия в конце диска)  |
| **Контроль целостности** | Нет                   | CRC32 заголовка и таблицы |
| **Совместимость**        | Все системы           | Требует UEFI для загрузки |

**Практика:**
*   Для **дисков >2 ТБ** или **UEFI-систем** — только GPT.
*   Для **старых систем с BIOS** на маленьких дисках — можно MBR.
*   **Инструменты:** `fdisk` — для MBR, `gdisk` (`parted`) — для GPT.
