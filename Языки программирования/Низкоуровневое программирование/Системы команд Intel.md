**Система команд Intel x86-64**

ISA процессоров Intel насчитывает сотни инструкций, делящихся на категории: пересылка данных, арифметика, управление потоком и строковые операции. Архитектура CISC — команды переменной длины (1–15 байт), поддержка прямой работы с памятью.

Формат команды: `[метка:] префикс opcode операнды`. В синтаксисе Intel первый операнд — приемник, второй — источник. Запись `mov rax, rbx` означает копирование из RBX в RAX.

**Описание данных**

Данные определяются через директивы в секции .data или резервируются в .bss:
 - db (byte) 8 бит  
 - dw (word) 16 бит  
 - dd (double word) 32 бита  
 - dq (quad word) 64 бита  

Пример: `message db "Hello", 10, 0`.  
Для неинициализированных буферов: `resb`, `resw`, `resd`, `resq`.

**Команды пересылки данных**

`mov` — копирует из источника в приемник:  
`mov rax, 10` — константа в регистр.  
`mov rbx, [rsp]` — из памяти в регистр.  
`mov [rdi], rcx` — из регистра в память.  
Важно: память → память напрямую невозможна, только через регистр.

`movzx` — загрузка с обнулением старших бит.  
`movsx` — загрузка с расширением знака.

`lea` — вычисляет адрес, не читая память:  
`lea rax, [rbx + rcx*4]` → RAX = RBX + RCX*4.

`xchg` — обмен значениями: `xchg rax, rbx`.

`push` / `pop` — работа со стеком:  
`push rax` — уменьшает RSP на 8, записывает RAX.  
`pop rbx` — читает в RBX, увеличивает RSP на 8.

**Арифметические команды**

Сложение и вычитание:  
`add rax, rbx` — RAX += RBX.  
`sub rax, rbx` — RAX -= RBX.  
`inc rax` — RAX++.  
`dec rbx` — RBX--.  
Устанавливают флаги ZF, SF, OF, CF (inc/dec не трогают CF).

Умножение:  
`mul rcx` — беззнаковое, RAX * RCX → RDX:RAX.  
`imul rax, rbx, 10` — знаковое, RAX = RBX * 10.

Деление:  
`div rcx` — беззнаковое, RDX:RAX / RCX → частное в RAX, остаток в RDX.  
`idiv` — знаковое. Перед делением обязательно обнулить RDX (`xor rdx, rdx`) или использовать `cqo` для знакового расширения.

Сравнение:  
`cmp rax, rbx` — вычисляет RAX - RBX, устанавливает флаги, результат не сохраняет.  
`test rax, rax` — логическое И, устанавливает ZF если RAX == 0.

**Команды управления**

Безусловный переход:  
`jmp метка` — передает управление.  
Косвенный: `jmp [rax]` — переход по адресу из памяти.

Условные переходы (после cmp или test):  

- По равенству: `je` / `jz` (ZF=1), `jne` / `jnz` (ZF=0).  
- Для знаковых: `jg` (больше), `jl` (меньше), `jge` (больше или равно), `jle` (меньше или равно).  
- Для беззнаковых: `ja` (выше), `jb` (ниже), `jae`, `jbe`.  
- По флагам: `js` (отрицательное), `jns` (неотрицательное), `jc` (перенос), `jo` (переполнение).

Вызовы:  
`call функция` — сохраняет RIP в стеке, переходит к функции.  
`ret` — восстанавливает RIP из стека.

`loop метка` — уменьшает RCX, переход если RCX != 0. Короче, но медленнее `dec rcx` + `jne`.

`nop` — пустая команда, используется для выравнивания.

**Синтаксис Intel vs AT&T**

Intel (NASM, MASM, IDA): `mov rax, rbx`, регистры без `%`, память в `[]`.  
AT&T (GCC, GDB по умолчанию): `mov %rbx, %rax`, регистры с `%`, память в `()`.  
В GDB переключение: `set disassembly-flavor intel`.
