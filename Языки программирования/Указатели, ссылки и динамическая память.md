# Указатели, ссылки и динамическая память

## Указатели (C/C++)

Указатель — переменная, хранящая **адрес** другого объекта в памяти.

```cpp
int x = 10;
int* p = &x;     // p хранит адрес x
int y = *p;      // разыменование: y = 10
*p = 20;         // x = 20
```

### Арифметика указателей

```cpp
int arr[] = {10, 20, 30};
int* p = arr;       // p → arr[0]
p++;                 // p → arr[1]
p += 2;              // p → arr[3] (выход за границы — UB!)
```

- `p + n` сдвигает на `n * sizeof(type)` байт
- Разность указателей = количество элементов между ними

## Ссылки (C++)

Ссылка — **псевдоним** существующего объекта, неотделимая от него.

```cpp
int x = 10;
int& ref = ref;  // ref —别名 x
ref = 20;        // x = 20
```

**Отличия от указателя:**
- Обязательна инициализация, не может быть `null`
- Не может быть перенаправлена на другой объект
- Не нужен оператор `*` для доступа

## Динамическое выделение памяти

### C: malloc / free

```cpp
int* p = (int*)malloc(5 * sizeof(int));  // выделение
// ... использование ...
free(p);                                  // освобождение
p = NULL;                                 // обнуление
```

### C++: new / delete

```cpp
int* p = new int(42);          // один объект
int* arr = new int[100];       // массив
delete p;                      // удаление объекта
delete[] arr;                  // удаление массива
```

## Проблемы памяти

### Утечки памяти (Memory Leaks)
Выделенная память не освобождена → рост потребления памяти.

```cpp
void leak() {
    int* p = new int[1000];
    // нет delete — утечка!
}
```

### Висячие указатели (Dangling Pointers)
Указатель ссылается на освобождённую память.

```cpp
int* p = new int(42);
delete p;
// *p — неопределённое поведение (UB)
```

## RAII (C++)

Идиома: привязка生命周期 ресурса к объекту. Деструктор автоматически освобождает память.

```cpp
{
    std::unique_ptr<int> p = std::make_unique<int>(42);
    // ...
}  // автоматический delete
```
