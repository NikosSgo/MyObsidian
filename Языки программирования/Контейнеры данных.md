# Контейнеры данных

## Последовательные контейнеры

| Контейнер | Описание | Доступ | Вставка (конец) | Вставка (середина) |
|-----------|----------|--------|------------------|---------------------|
| **Vector** | Динамический массив | O(1) | O(1) амортиз. | O(n) |
| **List** | Двусвязный список | O(n) | O(1) | O(1) после поиска |
| **Deque** | Двойная очередь | O(1) | O(1) | O(n) |

### Vector (std::vector)
- Непрерывный блок памяти, автоматическое расширение
- Быстрый случайный доступ, медленная вставка в середину

### List (std::list)
- Элементы в куче, связаны указателями
- Быстрая вставка/удаление, медленный доступ по индексу

### Deque (std::deque)
- Буферы фиксированного размера, «расширяемая» очередь
- Быстрый доступ с обоих концов

## Ассоциативные контейнеры

| Контейнер | Структура | Поиск | Вставка |
|-----------|-----------|-------|---------|
| **Set** | Красно-чёрное дерево | O(log n) | O(log n) |
| **Map** | Красно-чёрное дерево | O(log n) | O(log n) |
| **HashSet** | Хеш-таблица | O(1) амортиз. | O(1) амортиз. |
| **HashMap** | Хеш-таблица | O(1) амортиз. | O(1) амортиз. |

- **Set/Map** — упорядоченные, на деревьях
- **HashSet/HashMap** — неупорядоченные, на хеш-таблицах

## Адаптеры контейнеров

- **Stack** — LIFO (стек): `push`, `pop`, `top`
- **Queue** — FIFO (очередь): `push`, `pop`, `front`
- **Priority Queue** — извлекается элемент с наивысшим приоритетом

```cpp
std::stack<int> s;
s.push(1); s.push(2);
int top = s.top();  // 2

std::priority_queue<int> pq;
pq.push(3); pq.push(1);
int mx = pq.top();  // 3
```

## Итераторы

Итератор — объект для обхода контейнера (аналог указателя).

```cpp
std::vector<int> v = {1, 2, 3};
for (auto it = v.begin(); it != v.end(); ++it) {
    std::cout << *it << " ";
}
```

Типы итераторов по мощности:
1. **Input** — одноразовое чтение (istream)
2. **Forward** — многократный проход вперёд (forward_list)
3. **Bidirectional** — вперёд и назад (list, set, map)
4. **Random Access** — произвольный доступ (vector, deque)

## Выбор контейнера

- Нужен доступ по индексу → **vector**
- Частые вставки/удаления в середину → **list**
- Поиск/вставка по ключу → **map** / **hash_map**
- Только последний элемент → **stack**
- Приоритетная очередь → **priority_queue**
