# Типы данных в языках программирования

## Простые (атомарные) типы

| Тип | Описание | Пример |
|-----|----------|--------|
| `int` | Целое число | `42`, `-7` |
| `float` / `double` | Число с плавающей точкой | `3.14`, `2.718` |
| `char` | Символ | `'A'`, `'я'` |
| `bool` | Логический | `true`, `false` |

## Составные (сложные) типы

- **Array (массив)** — упорядоченная коллекция элементов одного типа. `int arr[5] = {1,2,3,4,5};`
- **Struct (структура)** — группа полей разных имён. `struct Point { int x; int y; };`
- **Class (класс)** — структура + методы + инкапсуляция. Основа ООП.

## Системы типов

### Статическая vs Динамическая

| Система | Когда проверяется | Языки |
|---------|-------------------|-------|
| **Статическая** | Компиляция | C, C++, Java, Go, Rust |
| **Динамическая** | Выполнение | Python, JavaScript, Ruby |

### Сильная vs Слабая

- **Сильная** — компилятор/интерпретатор запрещает неявные приведения (`Python`, `Java`)
- **Слабая** — неявные приведения разрешены (`C`, `JavaScript`: `"5" + 3 = "53"`)

## Вывод типов (Type Inference)

Автоматическое определение типа переменной без явного указания:

```cpp
// C++11
auto x = 42;        // int
auto s = "hello";   // const char*

// Java
var list = new ArrayList<String>(); // ArrayList<String>
```

## Ковариантность и контравариантность

- **Ковариантность**: `Sub` подтип `Base` → `Container<Sub>` подтип `Container<Base>` (массивы в Java)
- **Контравариантность**: обратное направление (параметры функций)
