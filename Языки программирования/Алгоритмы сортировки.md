# Алгоритмы сортировки

## Простые сортировки — O(n²)

### Пузырьковая (Bubble Sort)
- Сравниваем соседние элементы, меняем местами если порядок неверен
- Проход повторяется n-1 раз
- **Сложность**: O(n²) все случаи, **стабильная**

### Выбором (Selection Sort)
- На каждом шаге ищем минимум в неотсортированной части, ставим в начало
- **Сложность**: O(n²) все случаи, **не стабильная**
- Минимум обменов: n-1

### Вставками (Insertion Sort)
- Каждый элемент вставляем в правильную позицию отсортированной части
- **Сложность**: O(n²) в худшем, O(n) в лучшем (почти отсортированный массив)
- **Стабильная**, хороша для малых массивов

## Эффективные сортировки — O(n log n)

### Быстрая (Quicksort)
- Выбираем опорный элемент (pivot), разделяем массив на две части
- **Средняя**: O(n log n), **худшая**: O(n²) (уже отсортированный массив)
- **Не стабильная**, on-place, самая быстрая на практике

### Слиянием (Merge Sort)
- Делим массив пополам рекурсивно, сливаем отсортированные части
- **Сложность**: O(n log n) во всех случаях
- **Стабильная**, но требует O(n) дополнительной памяти

### Пирамидальная (Heap Sort)
- Строим max-heap, последовательно извлекаем максимум
- **Сложность**: O(n log n) все случаи
- **Не стабильная**, in-place

## Сравнительная таблица

| Алгоритм | Лучшая | Средняя | Худшая | Память | Стабильность |
|----------|--------|---------|--------|--------|--------------|
| Пузырьком | O(n) | O(n²) | O(n²) | O(1) | ✓ |
| Выбором | O(n²) | O(n²) | O(n²) | O(1) | ✗ |
| Вставками | O(n) | O(n²) | O(n²) | O(1) | ✓ |
| Быстрая | O(n log n) | O(n log n) | O(n²) | O(log n) | ✗ |
| Слиянием | O(n log n) | O(n log n) | O(n log n) | O(n) | ✓ |
| Пирамидальная | O(n log n) | O(n log n) | O(n log n) | O(1) | ✗ |

## Когда что использовать

- **Малый массив (n < 50)** — вставками
- **Общее назначение** — быстрая
- **Нужна стабильность** — слиянием
- **Ограничена память** — пирамидальная
