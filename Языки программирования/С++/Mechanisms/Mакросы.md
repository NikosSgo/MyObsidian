Макрос в C++ — это директива препроцессора, которая выполняет **текстовую подстановку до компиляции**. Препроцессор обрабатывает макросы до того, как код попадёт в компилятор, поэтому макросы не подчиняются правилам языка C++ как такового.

Макрос объявляется с помощью `#define`. Простейший вариант — подстановка значения:

```cpp
#define PI 3.14159
```

При компиляции все вхождения `PI` будут буквально заменены на `3.14159`.

Существуют параметризованные макросы, которые внешне похожи на функции:

```cpp
#define SQR(x) ((x) * (x))
```

Здесь `SQR(a + b)` превратится в `((a + b) * (a + b))`. Скобки критичны, иначе легко получить ошибку из-за приоритетов операторов.

Также макросы часто используются для условной компиляции:

```cpp
#ifdef DEBUG
    std::cout << "Debug mode\n";
#endif
```

Такой код либо полностью попадёт в итоговый бинарник, либо будет удалён на этапе препроцессора.

Ключевые особенности макросов:

- они не имеют типов; 
- не проверяются компилятором;
- не учитывают области видимости;
- работают как чистая текстовая замена.
    

Из-за этого макросы считаются небезопасным механизмом. В современном C++ их обычно заменяют:

- `const` или `constexpr` вместо числовых макросов;
- `inline` функции вместо функциональных макросов;
- `enum class` вместо наборов констант;
- шаблоны и `constexpr`-выражения для логики.

Тем не менее макросы остаются необходимыми в низкоуровневых задачах: include guard’ы (`#ifndef / #define`), платформо-зависимый код, взаимодействие с C API и конфигурация сборки.
