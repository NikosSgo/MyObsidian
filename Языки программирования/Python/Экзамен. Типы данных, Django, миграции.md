### Типы данных в Python

**Изменяемые (mutable):** список (`list`), словарь (`dict`), множество (`set`)
**Неизменяемые (immutable):** число (`int, float`), строка (`str`), кортеж (`tuple`), frozenset

**Список (list):** упорядоченный, изменяемый.
```python
list = [1, 2, 3]
list.append(4)       # [1,2,3,4]
list.sort()           # сортировка
list.pop()            # удалить последний
```

**Кортеж (tuple):** упорядоченный, НЕизменяемый.
```python
t = (1, 2, 3)
x, y, z = t  # распаковка
```

### Лямбда-функции

Анонимные функции:
```python
square = lambda x: x**2
list(map(lambda x: x*2, [1,2,3]))  # [2,4,6]
list(filter(lambda x: x > 2, [1,2,3,4]))  # [3,4]
```

### Генераторы и итераторы

**Итератор** — объект с методами `__iter__()` и `__next__()`.
**Генератор** — функция с `yield`, возвращает итератор лениво:
```python
def count_up_to(n):
    i = 0
    while i < n:
        yield i
        i += 1

for x in count_up_to(3):  # 0, 1, 2
    print(x)
```

**Генераторные выражения:**
```python
squares = (x**2 for x in range(10))  # лениво
sum(x**2 for x in range(10))         # без создания списка
```

### Фреймворк Django

**Django** — полнофункциональный веб-фреймворк на Python (MTV — Model-Template-View).

**Модели (Models)** — описание структуры БД через классы Python:
```python
from django.db import models

class Book(models.Model):
    title = models.CharField(max_length=100)
    author = models.ForeignKey(Author, on_delete=models.CASCADE)
    published = models.DateField()
```
Каждая модель = таблица в БД.

**Миграции** — способ синхронизации моделей с БД:
```bash
python manage.py makemigrations   # создать миграцию (файл изменений)
python manage.py migrate          # применить к БД
```
Миграции позволяют версионировать схему БД и откатывать изменения.

**Ключевые компоненты Django:**
- **ORM** — работа с БД через Python-объекты
- **Admin-панель** — автоматическая генерация CRUD-интерфейса
- **URL-диспетчер** — маршрутизация запросов
- **Шаблонизатор (Templates)** — HTML-шаблоны с Django Template Language
- **Middleware** — обработка запросов до/после view
