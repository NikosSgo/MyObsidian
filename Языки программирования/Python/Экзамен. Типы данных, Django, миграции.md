## Python. Типы данных, Django, миграции

### Типы данных в Python

**Простые:** int, float, bool, complex

**Коллекции:**
- **list** — изменяемая последовательность: `[1, 2, 3]`
- **tuple** — неизменяемая последовательность: `(1, 2, 3)`
- **dict** — словарь: `{"key": "value"}`
- **set** — множество: `{1, 2, 3}`
- **str** — строка: `"hello"`

### Основные методы списков
```python
lst = [1, 2, 3]
lst.append(4)      # [1, 2, 3, 4]
lst.insert(0, 0)   # [0, 1, 2, 3, 4]
lst.pop()           # [0, 1, 2, 3]
lst.remove(2)       # [0, 1, 3]
lst.sort()          # сортировка на месте
```

### Лямбда-функции
```python
square = lambda x: x ** 2
add = lambda x, y: x + y
```

### Генераторы
```python
def fib():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
```

### Итераторы
```python
my_list = [1, 2, 3]
it = iter(my_list)
print(next(it))  # 1
```

### Django. Модели
```python
from django.db import models

class Article(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
```

### Миграции
```bash
python manage.py makemigrations  # создание миграции
python manage.py migrate         # применение миграции
python manage.py showmigrations  # просмотр миграций
python manage.py sqlmigrate 0001 # SQL-запрос миграции
```
