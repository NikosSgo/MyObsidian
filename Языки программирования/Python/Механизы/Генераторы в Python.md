**Генераторы в Python** — это механизм ленивых вычислений, позволяющий создавать последовательности значений без хранения их целиком в памяти. Они особенно полезны при работе с большими объёмами данных, потоками и бесконечными последовательностями.

Генератор — это объект-итератор, который возвращает значения по одному, по требованию, и запоминает своё состояние между вызовами.

Ключевые свойства:
1. Вычисления происходят по мере запроса следующего элемента.
2. Память используется минимально, так как значения не накапливаются.
3. Генератор можно пройти только один раз.

Создание генератора через функцию с `yield`:

```python
def count_up_to(n):
    i = 1
    while i <= n:
        yield i
        i += 1

gen = count_up_to(3)

print(next(gen))  # 1
print(next(gen))  # 2
print(next(gen))  # 3
```

Ключевое отличие `yield` от `return`:  
`return` завершает функцию, а `yield` приостанавливает её выполнение и сохраняет контекст (локальные переменные, позицию выполнения).

Генераторные выражения — краткая форма, аналог list comprehension, но без создания списка:

```python
squares = (x * x for x in range(5))

for s in squares:
    print(s)
```

Разница между списком и генератором:

```python
lst = [x * x for x in range(5)]   # создаёт список в памяти
gen = (x * x for x in range(5))   # создаёт генератор
```

`lst` занимает память под все элементы сразу, `gen` — нет.

Типичные операции с генераторами:
- Итерация через `for`
- Получение следующего элемента через `next()`
- Использование в функциях `sum`, `any`, `all`, `max`, `min`

```python
total = sum(x for x in range(1_000_000))
```

Генераторы и исключение `StopIteration`:  
Когда значения заканчиваются, генератор автоматически выбрасывает `StopIteration`. Обычно это не обрабатывают вручную, так как `for` делает это сам.

Пример бесконечного генератора:

```python
def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
```

Использовать такие генераторы следует осторожно, обязательно ограничивая потребление:

```python
import itertools

for x in itertools.islice(fibonacci(), 10):
    print(x)
```

Генераторы часто применяются:
- при чтении файлов построчно,
- в пайплайнах обработки данных,
- в асинхронных и потоковых системах,
- при работе с очередями и большими выборками.


Пример использования генераторов в [[FastApi]]
 
Dependencies с `yield` (жизненный цикл ресурсов)
    
Самое типичное и важное применение. Генератор используется для инициализации ресурса и его корректного освобождения после обработки запроса.

```python
from fastapi import Depends
from sqlalchemy.orm import Session

def get_db() -> Session:
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()
```

Как это работает концептуально:

- код до `yield` — setup (создание ресурса),
- значение, возвращённое через `yield`, инжектится в endpoint,
- код после `yield` — teardown (cleanup), вызывается всегда, даже при исключениях.
    
Это по сути `try/finally`, встроенный в dependency injection.
