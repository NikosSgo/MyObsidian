**Объект первого класса** - это значение, с которым в языке можно обращаться свободно: хранить, передавать и возвращать.

Несмотря на название, это не обязательно экземпляр `class`. Правильнее говорить **значение первого класса**.

Значение считается первоклассным, если его можно:

- записать в переменную;
- передать функции;
- вернуть из функции;
- поместить в массив или коллекцию;
- создать во время выполнения.


### Функции первого класса

Если функции являются первоклассными значениями, если можно:

Записать функцию в переменную:

```
def add_one(x):
    return x + 1

operation = add_one
result = operation(10)
```

Передать функцию другой функции:

```
def apply(operation, value):
    return operation(value)

result = apply(add_one, 10)
```

Вернуть функцию из функции:

```
def make_multiplier(multiplier):
    def multiply(value):
        return value * multiplier

    return multiply

double = make_multiplier(2)
print(double(10))  # 20
```

`double` здесь хранит функцию, а не результат её вызова. Более того, эта функция помнит значение `multiplier`. Поэтому она является **замыканием**.

Функции первого класса позволяют создавать:

- обработчики событий;
- функции обратного вызова;
- замыкания;
- `map`, `filter` и `reduce`;
- стратегии и цепочки обработки.

Например:

```
numbers = [1, 2, 3]

result = map(lambda x: x * 2, numbers)
```

Функция `lambda x: x * 2` передаётся в `map` как обычное значение.

Коротко: **первый класс — это не вид объекта, а набор возможностей языка**. Если функцию можно положить в переменную и передать куда-нибудь без немедленного вызова, то функция в этом языке является значением первого класса.
