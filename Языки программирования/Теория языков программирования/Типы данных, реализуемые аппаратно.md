**Аппаратно реализуемые типы** — это типы, для которых в системе команд процессора (ISA) есть **специализированные регистры и машинные инструкции**. Все остальное (строки, списки, классы) — это программная надстройка над этими "кирпичиками".


### Целочисленные типы (Integer)
Процессор оперирует целыми числами в **двоичном дополнительном коде** (two's complement).

- **Размеры:** 8 бит (`byte`), 16 бит (`short`), 32 бита (`int`), 64 бита (`long`). В некоторых архитектурах (ARM, x86-64) есть 128-битные (`__int128`).
- **Аппаратные операции:** `ADD`, `SUB`, `MUL`, `DIV`, `SHL` (сдвиг влево), `CMP` (сравнение), побитовые `AND/OR/XOR/NOT`.
- **Статус:** Процессор после каждой операции автоматически выставляет флаги в регистре статуса (`ZF` — ноль, `CF` — перенос, `OF` — переполнение). Именно на этих флагах строятся условные переходы (`if`).
- **Важно:** Процессор **не знает**, знаковое у него число или беззнаковое. Одно и то же машинное слово `0xFF` для процессора просто байты. А будет это `255` (unsigned) или `-1` (signed) — решают **разные инструкции сравнения** (`JA` для беззнаковых vs `JG` для знаковых).

### Числа с плавающей точкой (Floating-point)
Реализуются через **математический сопроцессор** (FPU), который сейчас встроен прямо в ядро CPU.

- **Стандарт:** Повсеместно используется **IEEE 754**.
- **Размеры:** `float` (32 бита, одинарная точность) и `double` (64 бита, двойная точность). В некоторых архитектурах есть 80-битные (extended) и 128-битные (quad) для научных расчетов.
- **Аппаратные операции:** `FADD`, `FMUL`, `FDIV`, `FSQRT`, `FCOMP` (сравнение). Тригонометрия (`SIN`, `COS`) и логарифмы тоже часто реализованы аппаратно (специальные инструкции).
- **Специфика:** У чисел с плавающей точкой есть специальные битовые комбинации для `+Infinity`, `-Infinity` и `NaN` (Not a Number). Процессор умеет их генерировать и обрабатывать (обычно через исключения/ловушки).


### Логический тип (Boolean)
Сам процессор **не имеет** выделенного типа `bool`. В железе логическое значение — это просто целое число:

- **0** = `false`.
- **Любое ненулевое значение** = `true`.
- **Аппаратно:** Сравнение (`CMP`) выставляет флаги, а инструкции условного перехода (`JZ` — Jump if Zero, `JNZ` — Jump if Not Zero) работают с этими флагами.
- **В языках:** Компилятор часто выделяет под `bool` целый байт или даже 4 байта (для скорости), потому что процессор не умеет адресовать отдельные биты в памяти (минимальная адресуемая единица — байт).


### Адресные типы (Указатели / Ссылки)
Указатель — это не магический объект, а просто **целое число**, в котором хранится номер ячейки оперативной памяти (или виртуального адресного пространства).

- **Размер:** Зависит от разрядности архитектуры. 32-битный CPU — указатель 4 байта. 64-битный CPU — указатель 8 байт.
- **Аппаратные операции:** Процессор умеет:
  - Читать по адресу (`MOV eax, [0x7FFF...]`).
  - Писать по адресу.
  - Вычислять адрес со смещением (индексные регистры): `[ebx + eax*4 + 16]` — это основа для доступа к элементам массива (масштабирование).
- **Segmentation fault:** Попытка прочитать/записать по адресу, которого у процесса нет, вызывает аппаратное прерывание (Page Fault), которое операционная система превращает в сигнал `SIGSEGV` (ошибка сегментации).

### Символьный тип (Char)
На уровне процессора символов не существует. Есть только **коды**:

- **ASCII / UTF-8:** Это просто 8-битные (`char` в C) или 16-битные целые числа.
- **Аппаратно:** Символы хранятся как целые числа. Операции над ними — это операции сравнения целых чисел (`CMP`). Никаких специальных "символьных" инструкций у процессора нет. Даже перевод регистра (верхний/нижний регистр) делается через сложение/вычитание чисел (в ASCII 'A' vs 'a' отличаются на 32).

### Векторные типы / SIMD (Single Instruction, Multiple Data)
Это отдельный класс аппаратных типов для высокопроизводительных вычислений (графика, AI, обработка медиа).

- **Регистры:** `XMM` (128 бит), `YMM` (256 бит), `ZMM` (512 бит) в архитектуре x86 (расширения SSE, AVX).
- **Типы внутри:** Процессор умеет класть в один регистр упакованные (`packed`) данные: например, **4 числа float** одновременно (128 бит / 32 бита = 4 штуки).
- **Аппаратные операции:** Одна инструкция может сложить сразу 4 числа с плавающей точкой (векторное сложение) за один такт. Это называется **SIMD**.
- **Пример:** `VADDPS` — сложить 4 пары `float` одновременно. Это дает огромный прирост скорости в играх и машинном обучении.

### Десятичные типы (BCD - Binary-Coded Decimal)
Редкий гость в современных CPU, но исторически важен.

- **Идея:** Каждая десятичная цифра (0-9) кодируется 4 битами (полубайтом). Это нужно для финансовых систем, чтобы избежать ошибок округления двоичных дробей (0.1 + 0.2).
- **Аппаратная поддержка:** В x86 процессорах есть специальные инструкции для коррекции BCD-арифметики (`DAA` — Decimal Adjust after Addition), но сейчас они считаются устаревшими (в современных языках это делают программно через `decimal` в C# или `BigDecimal` в Java).
