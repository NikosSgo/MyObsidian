#### Git reset
---
Откатывание изменений коммита.
Есть три флага. 
soft - убирает изменения из коммита, но они уже добавлены в индекс и готовы для коммита и изменения остаются на диске.
mixed - убирает изменения из коммита, и убирает из индекса, файлы как будто только изменены
hard - убирает изменения и откатывает на диске
