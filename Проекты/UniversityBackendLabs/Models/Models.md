Этот проект представляет собой набор классов и содержит [[DTO]].
Есть общие (Common) классы и классы для первой версии API.

Общие классы:
- OrderUnit, который представляет собой заказ и содержит следующие поля: id, id заказчика, строковое представление адреса доставки, общая стоимость заказа, (TotalPriceCurrency), время создания и обновления, список всех позиций заказа.
- OrderItemUnit, который представляет собой позицию в заказе и содержит следующие поля: id, id заказа, id продукта, количество, заголовок продукта, url продукта, цена, (Price Currency), время создания и обновления

Классы для первой версии API делятся на Requests и Respons DTO.
Requests:
- V1CreateOrderRequest, который представляет собой запрос на создания заказа и содержит следующие поля: заказы, класс заказа с полями: id заказчика, адрес доставки, общая стоимость, (TotalPriceCurrency), список позиций заказа, класс позиции заказа с полями: id продукта, количество, , заголовок продукта, url продукта, цена, (Price Currency)
- V1QueryOrdersRequest, который представляет запрос на получение списка созданных заказов и содержит следующие поля: список id, список id заказчиков, страницу, размер страницы и поле отвечающие за надобность в списке позиций заказа.

Response:
- V1CreateOrderResponse, который представляет собой ответ на запрос создания заказа и содержит одно поле с списком заказов. Заказ представляет собой DTO OrderUnit.
- V1QueryOrdersResponse, который представляет ответ на запрос на получение списка созданных заказов и содержит одно поле с списком заказов. Заказ представляет собой DTO OrderUnit.
