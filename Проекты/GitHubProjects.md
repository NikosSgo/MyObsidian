Текущий проект: 
Проект дипломной работы [Director](https://github.com/NikosSgo/Director). Видеоредактор, который может и должен управляться LLM. Что хочется реализовать. Cloud редактор, с распределёнными вычислениями для максимальной скорости рендеринга. Полная кроссплатформенность: приложения для desktop, web, mobile, при это ui часть не содержит вообще никаких состояний (ну почти), вся логика в backend части. Обязательная часть что должен быть llm агент, который может в автоматическом или управляемом режиме работать над проектом. 

Законченные или не очень проекты:
Проект для первой курсовой работы [light_source_detection](https://github.com/NikosSgo/light_source_detection).  Программа должна находить и кластеризировать источники света на изображениях. Делалось это кастомными методами кластеризации и в итоге получалось, что на изображении находились источники света, а также направление лучей. На гите вроде как старая версия без tkinter приложения.

Проект по изучению паттернов проектирования на Ruby [Ruby-Design-Patterns](https://github.com/NikosSgo/Ruby-Design-Patterns). 

Проект для изучения Ruby on Rails и использования архитектурных паттернов [Rails_Project](https://github.com/NikosSgo/Rails_Project).

Проект по изучению методов оптимизации [Optimization](https://github.com/NikosSgo/Optimization). Программа представляет из себя MVC PyQT6 приложения, в котором можно выбрать один из 8 популярных методов оптимизации, задать нужные параметры и посмотреть 3d визуализацию работы этого метода с помощью OpenGL отрисовки.

Проект для лабораторных занятий по университетскому предмету "Администрирование серверов" с простым примером работы Docker и Ci/Cd [Docker](https://github.com/NikosSgo/Docker) 
Проект по университетскому предмету "Функционально и логическое программирование" [PrologAkinator](https://github.com/NikosSgo/PrologAkinator). В данном проекте был реализован акинатор, который должен угадать игрока из базы футболистов по ответам пользователя. Логика работы акинатора была реализована с помощью функционального языка F# и логического языка SWI Prolog. Фронтенд сделан с помощью Next JS.

Проект с OCR моделью, написанной на PyTorch [DeatailOCR](https://github.com/NikosSgo/DeatailOCR). Модель должна определять маркировку с металлических деталей РЖД.

Проект с телеграмм ботом, который работает с LLM для ответов и инициализации заказов различных вин [WineAgent](https://github.com/NikosSgo/WineAgent). В проекте использована yandex_gpt, rag по винам и function calling для работы с корзиной вин.

Проект мобильное приложение чат бот с LLM на Kotlin[AndroidChatBot](https://github.com/NikosSgo/AndroidChatBot)
Проект бэкэнд часть мобильного приложения чат с LLM [ChatBotBackend](https://github.com/NikosSgo/ChatBotBackend).

Проект по изучение многопоточной разработки на Java с помощью MPJ [Java_MPI](https://github.com/NikosSgo/Java_MPI).

Проект по университетскому предмету "Backend разработка" [YandexLavka](https://github.com/NikosSgo/YandexLavka). Планировалось сделать свою яндекс лавку, много хотелось, но не успели доделать, поэтому пока недоделано.

Проект для лабораторных заняттй по университетскому предмету "Backend разработка" [LabsBackend](https://github.com/NikosSgo/LabsBackend). Были изучены паттерны микросервисной backend разработки с использование брокеров сообщений rabbitmq и kafka.

Проект для университета (computer-vision-tests)[https://github.com/NikosSgo/computer-vision-tests]. По просьбе преподавателей нужно было сделать автоматическую систему тестирования лабораторных работ по предмету "Компьютерное зрение" для первого курса. Тесты были написаны на C++ с использованием gtest. Само автотестирование реализуется за счёт форка студентами репозитория  и в дальнейшем автозапуске тестов выполненых лабораторных работ через gitlab ci-cd.

Проект по университетскому предмету "Модели интеллектуальных систем" [InformationalSystems](https://github.com/NikosSgo/InformationalSystems). Здесь была реализована интеллектуальная система на основе ttl онтологии для подбора оптимального алгоритма обработки данных.

Ну и мои заметки в obsidian в гите для синхронизации с мобильным устройством [MyObsidian](https://github.com/NikosSgo/MyObsidian).
