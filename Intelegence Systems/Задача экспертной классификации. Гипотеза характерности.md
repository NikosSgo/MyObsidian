Пусть задано пространство состояний m = Q1 x … x Qn, и эти множества соответствуют понятиям (атрибутам) объектов области знания.

На множествах Qi определено отношение линейного порядка <, ≤, >, ≥, =, ≠. Это позволяет использовать стандартный набор сравнений.

Для постановки диагноза (σ1, …, σn) ∈ m+ справедлива **гипотеза характерности**: упорядочивание каждого из множеств по отдельности (отношение ≤) означает возрастание уверенности в попадании наборов σ1, …, σn в m+ при возрастании положения элементов множеств в отношении ≤.

1) (σ1, … σi,…, σn)

2) (σ1, … δi,…, σn)

σi ≤ δi

Сформулированное множество позволяет определить отношение частичного порядка на пространстве состояний, который называется отношением _предпочтения_:

R ⊆ m x m

Случай n = 2:
Q1 = {a, b, c, d}

Q2 = {1, 2, 3, 4}

a ≤ b ≤ c ≤ d

1 ≤ 2 ≤ 3 ≤ 4

Наборы – пары ().

Решётка:
Использованное отношение порядка основано на двух свойствах:

1) Если α ∈ m+ & α R β => β ∈ m+ (сохраняется положительный диагноз).

2) Если α ∈ m- & β R α => β ∈ m-.
