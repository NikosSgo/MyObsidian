Функциональная Сеть (ФС) – специальная семантическая сеть, которая отражает множество функциональных зависимостей, существующих в сети.

Пусть задана предметная область

А = {a1, a2, … , an},

которая оперирует множеством атрибутов (понятий). Каждый из ai принимает значение из множеств Qi ({Q1, Q2, … , Qn}). Также задано семейство функциональных соотношений F = {f1, … , fn}. Каждая функция имеет вид: aj = fi(ai1,…, ais).

Семантическая сеть множества знаний, представленного элементами множеств А и F, составляется из фрагментов, представляющие отдельные функциональные зависимости. Для приведённой ФЗ имеет вид:
ФС – это двудольный граф, одну часть вершин которого образуют вершины, размеченные атрибутами, а другую – вершины, размеченные функциями. Чтоб посчитать значение **a****j** надо убедиться что **a****i1**, **а****i2**, ..., **а****is** посчитаны и применить функцию **f****i**.

С помощью ФС можно решать следующие виды задач:

1. Прямая задача – (что-то посчитать с использованием функциональных соотношений). Зная <ai1 = c1, …, ais = cs> найти значение <aj1…ajr> используя для этого элементы F. (у первых a в индексе i, у вторых – в индексе j)
    
2. Обратная задача – (если вы знаете результат, то какие были исходные данные). Зная <aj1 = c1’… ajr = cr’> найти <ai1, … , ais>, по которым с помощью элементов F вычисляются начальные данные обратной задачи. {Это можно называть задачей планирования, так как мы знаем, что хотим получить, осталось понять, с чего нужно начать}.
    

**Прямая задача****:**

Пусть решается следующая задача: зная , найти , используя функции .

Алгоритм решения прямой задачи:

1) Выпишем функциональные соотношения .

2) Припишем вершинам атрибутов  значения этих атрибутов.

3) Рассматриваем список функций до тех пор, пока не найдём первую такую функцию fj, для которой значения атрибутов начальных данных заданы (известны) (то есть они размечают соответствующие вершины, из которых идут дуги в вершину, которая размечена как jj), а атрибут значения этой функции ещё не задан (не посчитан).

4) Если такая функция найдена, то вычисляется значение этой функции от значений её исходных данных в соответствующих вершинах сети и вычисленное значение приписывается соответствующей вершине атрибутов.

5) Если такой вершины нет, то алгоритм решения прямой задачи завершает свою работу.

6) По завершении действий 1-5 выдаётся ответ, который составляют значения атрибутов , который были назначены этим атрибутам.

Замечания:

1. Механизм прямого вывода заканчивает свою работу за конечное число шагов. Это так, поскольку на каждом шаге применяется новая функция, а количество функций конечно.
    
2. Решение задачи может быть полным, когда посчитаны все значения атрибутов  или неполным (частичным), когда посчитаны не все (может даже оказаться, что ни один атрибут не посчитан).
    
3. Если задача решена частично, то можно запросить дополнительные исходные данные для вычисления недостающих параметров.
    
4. Для уменьшения избыточности приведённой схемы можно воспользоваться схемой обратного вывода, позволяющей построить деревья обратного вывода от  до . Это позволяет ограничить множество применяемых функций теми , которые позволяют вычислить из исходных данных значение цели.
    
5. Схема обратного вывода позволяет подобрать недостающие значения параметров, если по исходным данным все значения цели не могут быть вычислены (если исходных параметров мало).
    

Прямую задачу можно решать, используя аналоги прямого и обратного вывода для продукционных систем.
