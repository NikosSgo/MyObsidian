Процесс решения задач на основе знаний представленной продукции осуществляется с помощью специальной схемы, которая разбивает процесс на этапы, которые выполняются последовательно, и с каждым этапом связан элемент сценария, который получает имя, описание БЗ и область результатов.

![[Сценарная модель продукций.excalidraw]]


Этапы собираются в сценарий.
1) Композиция (операция)
2) Вариант – возможность выполнения одного из нескольких этапов
3) Параллельный процесс:

Существуют ещё 3 операции конструирования сценариев.
1) Элементарный сценарий.
2) Вставка – вместо узла вставляем сценарий.
3) Итерация – вариант, когда есть рефлексия самого на себя.
Замечание: сценарий позволяет разрешать продукции системы через построение схемы прохождения этапов.
