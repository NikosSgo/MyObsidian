### Системы адресации в ЭВМ

Способы задания операндов в машинных командах:

| Способ адресации | Формат | Адрес операнда | Пример (NASM) |
|---|---|---|---|
| **Непосредственная** | Операнд в команде | Сам операнд | `mov ax, 5` |
| **Прямая (абсолютная)** | Адрес в команде | `address` | `mov ax, [0x100]` |
| **Регистровая** | Регистр в команде | Регистр | `mov ax, bx` |
| **Косвенная регистровая** | Регистр-указатель | `[reg]` | `mov ax, [bx]` |
| **Базовая** | Базовый регистр + смещение | `[base + disp]` | `mov ax, [bx+4]` |
| **Индексная** | Индекс + масштаб | `[index*scale + disp]` | `mov ax, [si*4]` |
| **Базовая индексная** | База + индекс + смещение | `[base + index*scale + disp]` | `mov ax, [bx+si*2+8]` |

**Структура машинной команды Intel:** `[префиксы] opcode [modrm] [sib] [disp] [imm]`

---

### Регистры Intel x86 (32-bit)

| Регистры | Назначение |
|---|---|
| **EAX, EBX, ECX, EDX** | Общего назначения (данные, счётчики) |
| **ESI, EDI** | Индексные (для строковых операций) |
| **EBP** | Базовый указатель стекового кадра |
| **ESP** | Указатель вершины стека |
| **EIP** | Счётчик команд (адрес следующей инструкции) |
| **EFLAGS** | Флаги (CF, ZF, SF, OF, IF, ...) |
| **CS, DS, ES, FS, GS, SS** | Сегментные регистры |

16-битные части: AX (AH/AL), BX (BH/BL), CX (CH/CL), DX (DH/DL)

### Язык ассемблера Intel (NASM)

**Описание данных:**
```nasm
section .data
    msg     db 'Hello', 0    ; байты
    num     dw 100           ; word (2 байта)
    array   dd 1, 2, 3       ; double word (4 байта)
    ptr     dq 0             ; quad word (8 байт)
```

**Арифметические команды:**
```nasm
add  ax, bx      ; ax = ax + bx
sub  ax, 5       ; ax = ax - 5
mul  cx          ; dx:ax = ax * cx (беззнаковое)
imul bx          ; dx:ax = ax * bx (знаковое)
div  cx          ; ax = dx:ax / cx, dx = остаток
inc  ax          ; ax++
dec  bx          ; bx--
```

**Команды управления:**
```nasm
cmp  ax, bx      ; сравнить (устанавливает флаги)
je   label       ; jump if equal (ZF=1)
jne  label       ; jump if not equal
jg   label       ; jump if greater (знаковое)
jl   label       ; jump if less
jmp  label       ; безусловный переход
call func        ; вызов подпрограммы
ret              ; возврат из подпрограммы
loop label       ; dec ecx, если ecx != 0 → jump
```

**Пример (сумма массива):**
```nasm
section .data
    arr  dd 1, 2, 3, 4, 5
    n    equ 5

section .text
    mov  ecx, n        ; счётчик
    xor  eax, eax      ; обнуляем сумму
    xor  esi, esi      ; обнуляем индекс
loop_start:
    add  eax, [arr + esi*4]
    inc  esi
    loop loop_start
    ; результат в eax
```
