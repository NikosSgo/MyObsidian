### Понятие формальной грамматики

**Формальная грамматика** — способ задания формального языка. Определяется четвёркой $G = (T, N, P, S)$, где:
- $T$ — алфавит терминальных символов (конечные символы языка)
- $N$ — алфавит нетерминальных символов (вспомогательные)
- $P$ — множество продукционных правил (правил вывода) вида $\alpha \to \beta$
- $S \in N$ — начальный символ (аксиома)

**Продукционное правило (продукция):** $A \to \gamma$, где $A \in N$, $\gamma \in (T \cup N)^*$.

**Вывод (деривация):** последовательность строк, где каждая следующая получена заменой нетерминала по одному из правил. Обозначение: $\alpha \Rightarrow^* \beta$ (за 0 или более шагов).

**Сентенциальная форма:** любая строка, выводимая из $S$, содержащая нетерминалы.

**Предложение:** сентенциальная форма, не содержащая нетерминалов (только $T$).

**Язык:** множество всех предложений: $L(G) = \{w \in T^* \mid S \Rightarrow^* w\}$.

---

### Синтаксическое дерево

Дерево, где:
- Корень = $S$
- Листья = терминалы (конечная строка)
- Внутренние узлы = нетерминалы
- Дети узла = правая часть применённого правила

**Пример грамматики для выражений:**
```
E → E + T | T
T → T * F | F
F → (E) | id
```
Для входа `id + id * id` строится дерево:
```
      E
     /|\
    E + T
    |   /|\
    T  T * F
    |  |   |
    F  F  id
    |  |
   id id
```

**Связь вывода и дерева:** одному дереву могут соответствовать разные последовательности вывода (левый, правый).
