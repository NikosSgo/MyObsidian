**eXtensible Markup Language** - текстовый формат для хранения и передачи структурированных данных. Машиночитаемый и понятный человеку.
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!-- Комментарий -->
<библиотека xmlns="http://example.com/library">
    <книга id="b001" жанр="фантастика">
        <название>Дюна</название>
        <автор>Фрэнк Герберт</автор>
        <год>1965</год>
    </книга>
</библиотека>
```
**Элементы структуры:**

- Пролог — версия и кодировка (обязательно)
- Комментарии — `<!-- текст -->`    
- Корневой элемент — **строго один** на документ
- Элементы (теги) — пользовательские имена
- Атрибуты — только в открывающем теге, в кавычках
- Текст — между открывающим и закрывающим тегом
- Инструкции обработки — указывают конкретной программе, что делать (начинаются с `<?` и заканчиваются `?>`). \<?php echo "hello"?>

## Правила синтаксиса

| Правило             | Правильно           | Неправильно           |
| :------------------ | :------------------ | :-------------------- |
| Закрывать все теги  | `<tag></tag>`       | `<tag>`               |
| Пустые теги         | `<tag />`           | `<tag>`               |
| Атрибуты в кавычках | `id="1"`            | `id=1`                |
| Один корень         | один корневой тег   | два на верхнем уровне |
| Регистр важен       | `<Book>` ≠ `<book>` | —                     |
## Пространства имён (xmlns)

Нужны, когда смешиваете теги из разных словарей (чтобы не путать `<title>` из книги и `<title>` из статьи):

```xml
<root xmlns:book="http://books.com" xmlns:article="http://articles.com">
    <book:title>Дюна</book:title>
    <article:title>Как писать код</article:title>
</root>
```

Без префикса — используется **namespace по умолчанию**:
```xml
<root xmlns="http://default.com">
    <element>значение</element>  <!-- принадлежит default.com -->
</root>
```

## XPath — навигация по дереву

Язык запросов для выборки узлов.

```xpath
/библиотека/книга[1]/название          # первая книга
//книга[@жанр="фантастика"]            # все книги с атрибутом жанр
//книга[год > 2000]                    # фильтрация по значению
//книга/название/text()                # только текст внутри названия
//*[@id]                               # любой элемент с атрибутом id
```

**Основные оси:**
- `//` — на любой глубине
- `/` — только прямой потомок
- `..` — родитель
- `@` — атрибут
- `*` — любой узел

## XSLT — трансформация

Язык преобразования XML в другой XML/HTML/текст. Сам XSLT — тоже XML.

```xml
<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:template match="/">
        <html>
            <body>
                <h2>Список книг</h2>
                <xsl:for-each select="//книга">
                    <p><xsl:value-of select="название"/></p>
                </xsl:for-each>
            </body>
        </html>
    </xsl:template>
</xsl:stylesheet>
```

**Где используют:** генерация HTML-отчётов из XML-данных, конвертация из одного XML-формата в другой, рендеринг на серверной стороне.
## Валидация (проверка структуры)

XML можно проверить на соответствие схеме:

1. **DTD** — старый, простой, но ограниченный
2. **XSD (XML Schema)** — современный, поддерживает типы данных (string, integer, date), сложные ограничения

```xml
<xsd:schema xmlns:xsd="http://www.w3.org/2001/XMLSchema">
    <xsd:element name="книга">
        <xsd:complexType>
            <xsd:sequence>
                <xsd:element name="название" type="xsd:string"/>
                <xsd:element name="год" type="xsd:integer"/>
            </xsd:sequence>
            <xsd:attribute name="жанр" type="xsd:string" use="required"/>
        </xsd:complexType>
    </xsd:element>
</xsd:schema>
```
