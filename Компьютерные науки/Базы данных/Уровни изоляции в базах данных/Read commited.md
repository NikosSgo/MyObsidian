Чтение возможно только из зафиксированных (`COMMIT`) данных.  
Каждый `SELECT` видит актуальное состояние данных на момент выполнения запроса.

Допускаемые аномалии:
- Non-Repeatable Read
- Phantom Read
- Lost Update

Предотвращает:
- Dirty Read

Это **уровень по умолчанию** во многих СУБД (PostgreSQL, Oracle).
