# Соединения таблиц (JOIN)

## Типы соединений

### INNER JOIN — внутреннее соединение
- Возвращает строки, **совпадающие** в обеих таблицах
```sql
SELECT e.name, d.dept_name
FROM employees e
INNER JOIN departments d ON e.dept_id = d.id;
```
- Эквивалентно: `FROM employees e, departments d WHERE e.dept_id = d.id`

### LEFT (OUTER) JOIN — левое внешнее
- **Все** строки из левой таблицы + совпадения из правой
- Несовпадения → `NULL` для правой таблицы
```sql
SELECT e.name, d.dept_name
FROM employees e
LEFT JOIN departments d ON e.dept_id = d.id;
```

### RIGHT (OUTER) JOIN — правое внешнее
- **Все** строки из правой таблицы + совпадения из левой
```sql
SELECT e.name, d.dept_name
FROM employees e
RIGHT JOIN departments d ON e.dept_id = d.id;
```

### FULL (OUTER) JOIN — полное внешнее
- **Все** строки из обеих таблиц
- Несовпадения → `NULL`
```sql
SELECT e.name, d.dept_name
FROM employees e
FULL OUTER JOIN departments d ON e.dept_id = d.id;
```

### CROSS JOIN — декартово произведение
- Каждая строка первой × каждая строка второй
```sql
SELECT e.name, p.project
FROM employees e CROSS JOIN projects p;
```
- Результат: m × n строк

### SELF JOIN — соединение таблицы с собой
```sql
SELECT e.name AS employee, m.name AS manager
FROM employees e
LEFT JOIN employees m ON e.manager_id = m.id;
```

### NATURAL JOIN — естественное соединение
- Автоматически соединяет по **одноимённым столбцам**
```sql
SELECT * FROM employees NATURAL JOIN departments;
```
- ⚠️ Опасно: может соединить по непредвиденным столбцам

## Эквивалентные записи
```sql
-- ANSI-синтаксис (рекомендуется)
SELECT * FROM A INNER JOIN B ON A.id = B.a_id;

-- Старый синтаксис (неявное соединение)
SELECT * FROM A, B WHERE A.id = B.a_id;
```

## Визуальная схема

```
INNER JOIN:        A ∩ B
LEFT JOIN:         A + (A ∩ B)
RIGHT JOIN:        (A ∩ B) + B
FULL OUTER JOIN:   A ∪ B
CROSS JOIN:        A × B
```

## Сравнение

| Тип | Строки из A | Строки из B | NULL-ы |
|-----|-------------|-------------|--------|
| INNER | Только совпавшие | Только совпавшие | Нет |
| LEFT | Все | Только совпавшие | Да (B) |
| RIGHT | Только совпавшие | Все | Да (A) |
| FULL | Все | Все | Да (обе) |
| CROSS | Все × n | n × все | Нет |
| SELF | Как LEFT/INNER | — | Зависит от типа |
