# SQL SELECT — полный синтаксис

## Базовый синтаксис
```sql
SELECT [DISTINCT] столбцы
FROM таблица
[WHERE условие]
[GROUP BY столбцы]
[HAVING условие_группы]
[ORDER BY столбец [ASC|DESC]]
[LIMIT n OFFSET m];
```

## Порядок выполнения
1. FROM / JOIN
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. DISTINCT
7. ORDER BY
8. LIMIT / OFFSET

## SELECT

### Проекция столбцов
```sql
SELECT *                          -- все столбцы
SELECT name, age                  -- конкретные
SELECT salary * 1.1 AS new_salary -- вычисляемый столбец
```

### Псевдонимы (Aliases)
```sql
SELECT name AS Имя FROM users;
SELECT name Имя FROM users;       -- без AS
```

### DISTINCT — уникальные значения
```sql
SELECT DISTINCT city FROM users;
SELECT DISTINCT ON (department) * FROM employees;
```

## WHERE — фильтрация строк

### Операторы сравнения
- `=`, `<>` / `!=`, `<`, `>`, `<=`, `>=`
- `BETWEEN ... AND ...`
- `IN (значение1, значение2, ...)`
- `LIKE` (`%` — любые символы, `_` — один символ)
- `IS NULL`, `IS NOT NULL`

### Логические операторы
- `AND`, `OR`, `NOT`
- Приоритет: NOT > AND > OR

```sql
SELECT * FROM users
WHERE age BETWEEN 18 AND 30
  AND city IN ('Москва', 'Питер')
  AND name LIKE 'А%';
```

## GROUP BY — группировка
```sql
SELECT city, COUNT(*) AS cnt
FROM users
GROUP BY city;
```

### Агрегатные функции
| Функция | Описание |
|---------|----------|
| `COUNT(*)` | Число строк |
| `COUNT(DISTINCT col)` | Число уникальных |
| `SUM(col)` | Сумма |
| `AVG(col)` | Среднее |
| `MIN(col)` | Минимум |
| `MAX(col)` | Максимум |

## HAVING — фильтрация групп
```sql
SELECT city, COUNT(*) AS cnt
FROM users
GROUP BY city
HAVING COUNT(*) > 5;
```
- `WHERE` фильтрует **строки**, `HAVING` — **группы**

## ORDER BY — сортировка
```sql
SELECT * FROM users
ORDER BY age DESC, name ASC;
```

## LIMIT / OFFSET — ограничение
```sql
SELECT * FROM users
LIMIT 10 OFFSET 20;   -- строки 21–30
-- или
SELECT * FROM users
LIMIT 10 OFFSET 20;   -- PostgreSQL
SELECT * FROM users
LIMIT 20, 10;          -- MySQL
```

## Полезные функции
```sql
COALESCE(col, default)   -- значение или default
NULLIF(a, b)              -- NULL если a = b
CASE WHEN ... THEN ... ELSE ... END
EXTRACT(YEAR FROM date)
```
