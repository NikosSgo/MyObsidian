# Функциональные зависимости

## Определение
**Функциональная зависимость (ФЗ):** X → Y
- Для каждого значения X существует **ровно одно** значение Y
- Если значения X совпадают, значения Y тоже совпадают
- X — детерминант, Y — зависимый атрибут

## Виды зависимостей

### Тривиальная
- Y ⊆ X (все атрибуты Y входят в X)
- **Пример:** {A, B} → A — всегда истинна

### Нетривиальная
- Y не является подмножеством X
- **Пример:** StudentID → Name

### Полная
- Y нетривиально зависит от X, и **ни один** собственный подмножество X не детерминирует Y
- **Пример:** {Name, BirthDate} → BirthYear — неполная (достаточно BirthDate)

### Транзитивная
- X → Z через промежуточный атрибут: X → Y, Y → Z
- **Пример:** StudentID → DepartmentID → DepartmentName

## Аксиомы Армстронга (Armstrong's Axioms)

### Основные аксиомы
1. **Рефлексивность:** Если Y ⊆ X, то X → Y
2. **Аугментация:** Если X → Y, то XZ → YZ
3. **Транзитивность:** Если X → Y и Y → Z, то X → Z

### Выводные правила
- **Объединение:** X → Y и X → Z ⟹ X → YZ
- **Разложение:** X → YZ ⟹ X → Y и X → Z
- **Псевдо-транзитивность:** X → Y и WY → Z ⟹ WX → Z

## Замыкание множества атрибутов (X+)
- Множество всех атрибутов, детерминируемых X
- **Алгоритм:**
  1. result = X
  2. Для каждой ФЗ A → B: если A ⊆ result, добавить B в result
  3. Повторять, пока result не изменится

**Пример:** Реляция R(A,B,C,D), ФЗ: A→B, B→C
- {A}+ = {A, B, C}

## Кандидатские ключи
- **Ключ (candidate key):** минимальное множество атрибутов K, такое что K → всех атрибутов
- Проверка: K+ = все атрибуты, и ни собственное подмножество не обладает этим свойством
- **Первичный ключ** — один из кандидатских, выбирается пользователем
- **Суперключ** — любое множество, содержащее ключ

## Нормализация
| НФ | Требование |
|----|-----------|
| 1НФ | Атомарные значения |
| 2НФ | Нет частичных зависимостей от PK |
| 3НФ | Нет транзитивных зависимостей от PK |
| BCNF | Каждый детерминант — ключ |
