# Основные теги HTML

## Структурные теги

| Тег | Назначение |
|-----|-----------|
| `<html>` | Корневой элемент документа |
| `<head>` | Метаданные (title, meta, link, script) |
| `<body>` | Видимое содержимое |
| `<header>` | Шапка страницы/секции |
| `<main>` | Основное содержимое (один на страницу) |
| `<footer>` | Подвал страницы/секции |
| `<section>` | Тематическая секция |
| `<article>` | Самостоятельный контент (статья, пост) |
| `<nav>` | Навигационные ссылки |
| `<aside>` | Боковая панель |
| `<div>` | Блочный контейнер (общего назначения) |

## Текстовые теги

| Тег | Назначение |
|-----|-----------|
| `<h1>`–`<h6>` | Заголовки (1 — главный, 6 — наименьший) |
| `<p>` | Абзац |
| `<span>` | Строчный контейнер (для стилизации) |
| `<br>` | Перенос строки |
| `<hr>` | Горизонтальная линия (разделитель) |
| `<pre>` | Предварительно отформатированный текст |
| `<blockquote>` | Цитата |

## Инлайновые теги

| Тег | Назначение |
|-----|-----------|
| `<a href="...">` | Ссылка |
| `<img src="..." alt="...">` | Изображение (самозакрывающийся) |
| `<strong>` | Жирный (важный контент) |
| `<em>` | Курсив (акцент) |
| `<code>` | Код |
| `<a>` + `<a download>` | Ссылка на скачивание |

## Формы

| Тег | Назначение |
|-----|-----------|
| `<form>` | Контейнер формы |
| `<input type="...">` | Поле ввода (text, email, password, checkbox, radio, number, date) |
| `<select>` + `<option>` | Выпадающий список |
| `<textarea>` | Многострочное текстовое поле |
| `<button>` | Кнопка (submit, reset, button) |
| `<label>` | Подпись к полю (for="id") |
| `<fieldset>` + `<legend>` | Группировка полей |

## Списки

```html
<!-- Маркированный -->
<ul>
  <li>Элемент 1</li>
  <li>Элемент 2</li>
</ul>

<!-- Нумерованный -->
<ol>
  <li>Первый</li>
  <li>Второй</li>
</ol>
```

## Таблицы

| Тег | Назначение |
|-----|-----------|
| `<table>` | Контейнер таблицы |
| `<tr>` | Строка |
| `<td>` | Ячейка данных |
| `<th>` | Заголовочная ячейка (жирная, центрирована) |
| `<thead>` / `<tbody>` / `<tfoot>` | Семантические группы строк |
| `<caption>` | Заголовок таблицы |

## Семантические vs Несемантические
- **Семантические:** `<header>`, `<nav>`, `<article>`, `<footer>` — понятны браузеру и поисковикам
- **Несемантические:** `<div>`, `<span>` — только контейнеры, без смысла
