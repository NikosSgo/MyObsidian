# Экзамен. AJAX, Callback, Promise

## Синхронные vs асинхронные веб-приложения

| Параметр | Синхронные | Асинхронные |
|----------|-----------|-------------|
| Загрузка страницы | Полная перезагрузка | Частичное обновление DOM |
| Опыт пользователя | Блокирующий UI | Плавный, без задержек |
| Трафик | Большой (вся страница) | Минимальный (только данные) |
| Пример |传统 PHP-формы | Gmail, SPA |

## AJAX

**AJAX** = Asynchronous JavaScript And XML — технология асинхронного обмена данными с сервером без перезагрузки страницы.

### XMLHttpRequest
```javascript
const xhr = new XMLHttpRequest();
xhr.open('GET', '/api/data', true);
xhr.onreadystatechange = function() {
    if (xhr.readyState === 4 && xhr.status === 200) {
        const data = JSON.parse(xhr.responseText);
    }
};
xhr.send();
```

- `readyState`: 0 → 1 → 2 → 3 → **4** (завершено)
- `status`: 200 OK, 404 Not Found, 500 Server Error

### Fetch API (современный подход)
```javascript
fetch('/api/data')
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));
```

- Возвращает **Promise**
- Удобнее, чем XMLHttpRequest
- Поддерживает методы, заголовки, POST/PUT/DELETE

## Callback (колбэк)

**Callback** — функция, переданная как аргумент другой функции, вызывается после завершения операции.

```javascript
function loadData(url, callback) {
    const xhr = new XMLHttpRequest();
    xhr.onload = function() { callback(null, xhr.responseText); };
    xhr.onerror = function() { callback(new Error("Ошибка")); };
    xhr.open('GET', url);
    xhr.send();
}

loadData('/api', function(err, data) {
    if (err) { console.error(err); return; }
    console.log(data);
});
```

### Callback Hell (ад колбэков)
- Вложенные callback'и на 5+ уровней → нечитаемый код
- Сложно обрабатывать ошибки
- Решение → **Promise**

```javascript
getData(function(a) {
    getMoreData(a, function(b) {
        getEvenMore(b, function(c) {
            // ...
        });
    });
});
```

## Promise

**Promise** — объект, представляющий результат асинхронной операции.

### Три состояния
| Состояние | Описание |
|-----------|----------|
| **Pending** | Ожидание завершения |
| **Fulfilled** | Операция успешна (resolve) |
| **Rejected** | Ошибка (reject) |

### Методы
```javascript
const promise = new Promise((resolve, reject) => {
    setTimeout(() => resolve("Готово!"), 1000);
});

promise
    .then(result => console.log(result))    // "Готово!"
    .catch(error => console.error(error))   // при ошибке
    .finally(() => console.log("Завершено")); // всегда
```

### Promise.all() и Promise.race()
```javascript
// Все промисы должны выполниться успешно
Promise.all([fetch('/a'), fetch('/b'), fetch('/c')])
    .then(([a, b, c]) => { /* все ответы */ });

// Первый завершится (успех или ошибка)
Promise.race([fetch('/fast'), fetch('/slow')])
    .then(first => { /* самый быстрый */ });
```

| Метод | Поведение |
|-------|-----------|
| `Promise.all()` | Resolve когда **все** OK; Reject при **любой** ошибке |
| `Promise.allSettled()` | Resolve когда **все** завершены (успех/ошибка неважны) |
| `Promise.race()` | Первый завершившийся (resolve или reject) |
| `Promise.any()` | Первый **resolve**; Reject если все failed |

## Async/Await

**Async/await** — синтаксический сахар над Promise. Код выглядит синхронным.

```javascript
async function loadData() {
    try {
        const response = await fetch('/api/data');
        const data = await response.json();
        console.log(data);
    } catch (error) {
        console.error(error);
    }
}
```

- `async` перед функцией → всегда возвращает Promise
- `await` можно использовать **только** внутри `async`-функции
- `try/catch`替代 `.catch()`

## Сравнение подходов

| Подход | Читаемость | Обработка ошибок | Поддержка |
|--------|-----------|-------------------|-----------|
| Callback | Низкая | Сложная | IE9+ |
| Promise | Средняя | `.catch()` | IE10+ (полифилл) |
| Async/Await | Высокая | `try/catch` | ES2017+ |
