# Экзамен. Уязвимости WEB-страниц и методы борьбы

## XSS (Cross-Site Scripting)

Инъекция **вредоносного JavaScript** в контекст доверенного сайта.

### Reflected XSS
- Код внедряется через **параметры URL** или формы
- `<script>alert(document.cookie)</script>` в URL
- Требует **клиентского перехода** по заражённой ссылке

### Stored XSS
- Код сохраняется **на сервере** (БД, комментарии, профиль)
- Атакует **всех пользователей**, просматривающих страницу
- Самый опасный тип — не требует социальной инженерии

### DOM-based XSS
- Уязвимость в **клиентском JavaScript**
- `document.getElementById('output').innerHTML = location.hash`
- Данные берутся из `document.location`, `window.name` и т.д.

### Защита от XSS
| Метод | Описание |
|-------|----------|
| **Output encoding** | `htmlspecialchars()` / `textContent` вместо `innerHTML` |
| **CSP** | Content-Security-Policy — ограничение источников скриптов |
| **Input validation** | Белый список допустимых символов |
| **HttpOnly cookies** | Запрет доступа к cookie через JavaScript |

## SQL Injection (SQL-инъекция)

Внедрение SQL-кода через **непроверенные входные данные**.

```sql
-- Атака: username = ' OR '1'='1' --
SELECT * FROM users WHERE login='' OR '1'='1' --' AND pass='...'
```

### Защита
| Метод | Описание |
|-------|----------|
| **Prepared statements** | Параметризованные запросы (PDO, MySQLi) |
| **ORM** | Абстракция запросов (Eloquent, Doctrine) |
| **Минимизация прав** | Запрет DROP/DELETE для приложения |
| **Фильтрация** | Экранирование спецсимволов (`mysql_real_escape_string`) |

## CSRF (Cross-Site Request Forgery)

Принуждение пользователя к **выполнению нежелательных действий** на доверенном сайте.

```html
<!-- Скрытая форма на вредоносном сайте -->
<form action="https://bank.example.com/transfer" method="POST">
    <input type="hidden" name="to" value="attacker">
    <input type="hidden" name="amount" value="10000">
</form>
```

### Защита от CSRF
| Метод | Описание |
|-------|----------|
| **CSRF-токен** | Уникальный токен в форме, сверяется с серверным |
| **SameSite cookies** | `SameSite=Strict/Lax` — запрет отправки кросс-доменных cookie |
| **Проверка заголовков** | `Origin`, `Referer` — откуда пришёл запрос |
| **CAPTCHA/2FA** | Дополнительная верификация |

## Clickjacking

Скрытие интерактивных элементов под **прозрачным iframe** жертвы.

- Пользователь думает, что кликает на одну кнопку, а на самом деле — на другой
- Пример: подмена кнопки «Play» на кнопку перевода денег

### Защита
- **X-Frame-Options**: `DENY` / `SAMEORIGIN`
- **CSP**: `frame-ancestors 'none'` (более современный)
- JavaScript-проверка: `window.top !== window.self`

## Directory Traversal (Path Traversal)

Доступ к **файлам за пределами** веб-корня через `../` в URL.

```
GET /files?name=../../../../etc/passwd
```

### Защита
- **Валидация путей**: `realpath()` + проверка начала пути
- **Запрет `../`** в входных данных
- **Chroot / sandbox** — изоляция файловой системы
- Минимальные права на файлы (права 644, каталоги 755)

## Другие уязвимости

| Уязвимость | Описание | Защита |
|------------|----------|--------|
| **XXE** | Инъекция XML-сущностей | Отключение внешних сущностей |
| **SSRF** | Запросы на внутренние ресурсы | Валидация URL, белый список |
| **Insecure Deserialization** | Выполнение кода при десериализации | Валидация, подпись данных |

## Общие методы защиты

| Метод | Описание |
|-------|----------|
| **Валидация входных данных** | Белый список допустимых значений |
| **HTTPS** | Шифрование трафика (TLS) |
| **Security headers** | CSP, X-Content-Type, X-Frame-Options |
| **Регулярные обновления** | Патчи зависимостей (composer, npm audit) |
| **Аудит кода** | OWASP Top 10 checklist |
