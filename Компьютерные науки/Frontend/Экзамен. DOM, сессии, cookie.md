### DOM (Document Object Model)

**DOM** — объектное представление HTML-документа в виде дерева. Каждый HTML-тег — узел (node) дерева.

**Программная навигация по DOM:**

```javascript
// Навигация
document.getElementById('id')
document.querySelector('.class')        // первый CSS-селектор
document.querySelectorAll('div span')   // все совпадения
element.parentElement           // родитель
element.children                // дочерние элементы
element.closest('.wrapper')    // ближайший родитель по селектору
element.nextElementSibling     // следующий сосед

// Изменение
element.textContent = 'text'
element.innerHTML = '<b>bold</b>'
element.setAttribute('disabled', '')
element.classList.add('active')
element.style.display = 'none'

// Создание
const div = document.createElement('div')
parent.append(div)       // в конец
parent.prepend(div)      // в начало
element.remove()
```

### Сессии

**Сессия** — последовательность запросов от одного клиента, объединённых общим состоянием на сервере.

**Механизм работы:**
1. Клиент отправляет запрос (логин)
2. Сервер создаёт сессию (уникальный ID), сохраняет данные (корзина, auth)
3. Сервер отправляет клиенту SessionID (обычно в cookie)
4. Клиент при каждом запросе отправляет SessionID
5. Сервер находит сессию по ID

**Защита сессий:**
- Использовать HTTPS (перехват cookie)
- Установка `HttpOnly` (недоступен JS) и `Secure` (только HTTPS) флагов
- `SameSite=Strict` (защита от CSRF)
- Регенерация SessionID после логина (защита от session fixation)
- Ограничение времени жизни сессии

### Cookie

**Cookie** — небольшие данные (до 4KB), хранящиеся на клиенте.

**Назначение:**
- Идентификация пользователя (SessionID)
- Хранение настроек (тема, язык)
- Трекинг (аналитика, реклама)

**Хеш (в контексте веба):**
- Фрагмент URL после `#`
- Не отправляется на сервер
- Используется для SPA-роутинга (hash-based routing)
- Навигация по якорям на странице

**Сравнение:**

| Хранилище | Объём | Сервер | Срок | Доступность |
|---|---|---|---|---|
| Cookie | 4KB | Да (автоматически) | Задан | Клиент+сервер |
| Session Storage | 5-10MB | Нет | До закрытия вкладки | Клиент (JS) |
| Local Storage | 5-10MB | Нет | Постоянно | Клиент (JS) |
