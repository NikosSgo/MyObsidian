В Bootstrap layout — это система построения страницы на основе контейнеров, строк и колонок. Он реализован поверх flexbox и построен по принципу mobile-first.

Основные элементы layout — это три уровня: container → row → col.

Контейнер — ограничивает ширину контента и центрирует его.  
Типы контейнеров:

- `container` — адаптивная фиксированная ширина (меняется на разных breakpoints).    
- `container-fluid` — всегда 100% ширины.
- `container-{breakpoint}` — становится фиксированным только начиная с указанного breakpoint’а (например, `container-lg`).

Контейнер задаёт горизонтальные паддинги и управляет максимальной шириной через media queries.

Row — это обёртка для колонок.  
`row`:
- включает `display: flex`
- задаёт `flex-wrap: wrap`
- добавляет отрицательные margin’ы по бокам, чтобы компенсировать паддинги колонок
- управляет горизонтальными и вертикальными gutter’ами (через `g-*`, `gx-*`, `gy-*`)

Колонки — это flex-элементы внутри row.  
Сетка делится на 12 частей. Колонка может:
- занимать фиксированную долю (`col-6`, `col-4`)
- автоматически распределяться (`col`)
- менять ширину на разных breakpoints (`col-12 col-md-6 col-lg-4`)

Принцип работы колонок:
- Если указано число — это `width: N/12 * 100%`.
- Если просто `col` — используется `flex: 1 0 0`, пространство делится поровну.
- Если колонок больше 12 в строке — лишние переносятся на следующую строку (за счёт `flex-wrap`).

Breakpoints (адаптивность).  
Bootstrap использует фиксированные точки перелома:
- sm
- md
- lg
- xl
- xxl

Классы без префикса (`col-6`) работают для всех размеров.  
Классы с префиксом (`col-md-6`) применяются начиная с указанной ширины и выше. Это mobile-first модель: сначала задаётся поведение для мобильных, затем расширяется.

Gutters — отступы между колонками.  
Управляются классами:
- `g-3` — и по горизонтали, и по вертикали
- `gx-2` — только по X
- `gy-4` — только по Y  
    Реализуются через padding колонок + отрицательные margin’ы у row.
    

Вертикальное и горизонтальное выравнивание.  
Поскольку row — это flex-контейнер, доступны:
- `justify-content-*` — выравнивание по основной оси
- `align-items-*` — по поперечной
- `align-self-*` — для отдельной колонки

Offset и порядок.  
Можно смещать колонку:
- `offset-3` — добавляет левый отступ в 3/12  
    Можно менять порядок:
- `order-1`, `order-md-2`

Вложенные сетки.  
Внутри колонки можно создать новый `row` и строить сетку второго уровня. Это нормальная практика.

Типичный паттерн layout:

container  
→ row  
→ несколько col  
→ внутри col — контент или вложенный row

Концептуально layout в Bootstrap — это тонкий слой абстракции над flexbox + media queries, где 12-колоночная модель служит удобной метрикой пропорций.
