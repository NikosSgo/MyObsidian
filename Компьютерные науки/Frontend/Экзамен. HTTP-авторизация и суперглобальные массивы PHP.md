# Экзамен. HTTP-авторизация и суперглобальные массивы PHP

## HTTP-авторизация

### Basic Auth
- Клиент отправляет `Authorization: Basic base64(login:password)`
- Данные передаются **в открытом виде** (base64 — не шифрование!)
- Требует **HTTPS** для безопасности
- Сервер отвечает `401 Unauthorized` + заголовок `WWW-Authenticate: Basic realm="..."`

### Digest Auth
- Пароль **не передаётся** в открытом виде — используется хеш (MD5/SHA)
- Сервер отправляет `nonce` (одноразовый код), клиент вычисляет `hash(login:realm:password:nonce)`
- Устойчивее к перехвату, но **уязвим к атакам** при отсутствии HTTPS
- Медленнее Basic из-за вычислений хеша

### Bearer Token (OAuth 2.0)
- Клиент передаёт `Authorization: Bearer <token>`
- Токен выдаётся сервером авторизации после аутентификации
- Не привязан к логину/паролю — можно **отозвать** без смены пароля
- Используется в SPA, REST API, OpenID Connect

### Как работает HTTP Auth
1. Клиент запрашивает защищённый ресурс
2. Сервер возвращает `401` с `WWW-Authenticate`
3. Браузер показывает окно ввода логина/пароля
4. Клиент повторяет запрос с заголовком `Authorization`
5. Сервер проверяет и возвращает `200` или снова `401`

## Суперглобальные массивы PHP

### `$_GET`
- Параметры из **URL** (query string): `?name=Ivan&id=5`
- `$_GET['name']` → `"Ivan"`

### `$_POST`
- Данные из **тела HTTP-запроса** (Content-Type: `application/x-www-form-urlencoded`)
- Используется при отправке форм (`method="post"`)

### `$_REQUEST`
- Объединение `$_GET`, `$_POST`, `$_COOKIE`
- **Не рекомендуется** — сложно определить источник данных

### `$_SESSION`
- Хранение данных **на сервере** между запросами
- Требует `session_start()`; идентификатор передаётся через cookie `PHPSESSID`

### `$_COOKIE`
- Данные из HTTP-заголовка `Cookie`
- Устанавливаются через `setcookie()` **до** вывода任何 HTML

### `$_SERVER`
- Информация о сервере и запросе:
  - `$_SERVER['REQUEST_METHOD']` — GET/POST
  - `$_SERVER['REMOTE_ADDR']` — IP клиента
  - `$_SERVER['HTTP_USER_AGENT']` — строка браузера
  - `$_SERVER['REQUEST_URI']` — URI запроса

### `$_FILES`
- Загруженные файлы (`enctype="multipart/form-data"`)
- Содержит имя, тип, размер, временное имя и код ошибки
- Обрабатывается через `move_uploaded_file()`

## Сравнение таблица

| Массив | Источник | Типичное использование |
|---------|----------|----------------------|
| `$_GET` | URL query string | Пагинация, фильтры |
| `$_POST` | Тело запроса | Формы, API |
| `$_SESSION` | Серверная сессия | Авторизация, корзина |
| `$_COOKIE` | Заголовок Cookie | Запоминание настроек |
| `$_SERVER` | Серверные переменные | Логирование, редирект |
| `$_FILES` | Загрузка файлов | Аватар, документы |

## Безопасность
- Всегда **валидируйте** и **экранируйте** данные из суперглобальных массивов
- `htmlspecialchars()` — защита от XSS
- Prepared statements — защита от SQL-инъекций
- `filter_input()` — фильтрация на входе
