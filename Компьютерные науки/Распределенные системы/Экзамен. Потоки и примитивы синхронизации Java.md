# Потоки и примитивы синхронизации Java

## Создание потоков

### Класс Thread
```java
class MyThread extends Thread {
    public void run() { /* код потока */ }
}
new MyThread().start();
```

### Интерфейс Runnable
```java
Runnable task = () -> { /* код потока */ };
new Thread(task).start();
```

### Интерфейс Callable + Future
```java
Callable<Integer> task = () -> 42;
ExecutorService exec = Executors.newSingleThreadExecutor();
Future<Integer> result = exec.submit(task);
```

## Примитивы синхронизации

### synchronized
- Метод или блок — эксклюзивный доступ к объекту
```java
synchronized(lock) {
    // критическая секция
}
```

### wait() / notify() / notifyAll()
- Вызываются только внутри `synchronized`
- `wait()` — освобождает монитор и ждёт
- `notify()` — будит один поток
- `notifyAll()` — будит все потоки в очереди

### volatile
- Гарантирует видимость переменной между потоками
- Не даёт атомарности, но запрещает кэширование

## java.util.concurrent

### Lock interface / ReentrantLock
```java
Lock lock = new ReentrantLock();
lock.lock();
try { /* критическая секция */ }
finally { lock.unlock(); }
```
- Поддерживает `tryLock()`, таймауты, справедливость

### Semaphore
```java
Semaphore sem = new Semaphore(3); // 3 разрешения
sem.acquire();
try { /* работа */ }
finally { sem.release(); }
```

### CountDownLatch
```java
CountDownLatch latch = new CountDownLatch(n);
latch.countDown(); // уменьшает счётчик
latch.await();     // ждёт, пока не станет 0
```
- Одноразовый барьер

### CyclicBarrier
```java
CyclicBarrier barrier = new CyclicBarrier(n, () -> { /* action */ });
barrier.await(); // ждёт n потоков
```
- Переиспользуемый барьер

## Сравнение

| Примитив | Назначение |
|----------|-----------|
| synchronized | Простая блокировка объекта |
| ReentrantLock | Расширенная блокировка с опциями |
| Semaphore | Ограничение числа потоков |
| CountDownLatch | Ожидание завершения n событий |
| CyclicBarrier | Синхронизация n потоков на точке |
| volatile | Видимость переменной (без атомарности) |
