# Сети Петри

## Определение

**Сеть Петри** — математическая модель для описания дискретных распределённых систем с параллельными, конкурентными и асинхронными процессами.

### Структура (5-tuple)

$$C = (P, T, F, W, M_0)$$

- **P** — множество мест (places), обозначаются кружками ○
- **T** — множество переходов (transitions), обозначаются прямоугольниками □
- **F ⊆ (P × T) ∪ (T × P)** — множество дуг (flow relation)
- **W: F → ℕ** — веса дуг
- **M₀: P → ℕ** — начальная маркировка (распределение фишек)

## Маркировка (marking)

**Маркировка M** — функция, указывающая количество фишек в каждом месте.

Пример: 3 места, 2 перехода:

```
○ p1  --t1-->  ○ p2  --t2-->  ○ p3
●●         ●           (пусто)
M = (2, 1, 0)
```

## Правило срабатывания (firing rule)

Переход **t** может сработать (enabled), если:
- Каждое входное место p ∈ •t содержит не менее W(p, t) фишек

При срабатывании:
- Из каждого входного места p забирается W(p, t) фишек
- В каждое выходное место q ∈ t• добавляется W(t, q) фишек

## Основные свойства

| Свойство | Определение | Значение |
|----------|-------------|----------|
| **Живость (Liveness)** | Из любого可达 маркировки можно достичь срабатывания каждого перехода | Нет «мёртвых» переходов |
| **Ограниченность (Boundedness)** | Существует k: в каждом месте ≤ k фишек | Конечность ресурсов |
| **Свобода от тупиков (Deadlock-free)** | Всегда существует хотя бы один активный переход | Система не зависает |
| **Достижимость (Reachability)** | Целевая маркировка достижима из M₀ | Корректность сценария |

## Свойства безопасности

- **1-безопасность** — в каждом месте не более 1 фишки (ограниченность с k=1)
- **k-безопасность** — в каждом месте не более k фишек

## Пример: модель «производитель-потребитель»

```
M₀ = (n, 0, 0)

○○○ p1 (сырьё)  →  [t1: произвести]  →  ○ p2 (буфер)  →  [t2: потребить]  →  ○ p3 (результат)
                    ↑                                      ↓
                    └──────────── p1 ←─────────────────────┘
```

- Если n = 1 и буфер 1-безопасен — модель синхронизации

## Пример: взаимное исключение

```
○ p0 (свободен)  →  [t1: войти]  →  ○ p1 (занят A)
                   →  [t2: войти]  →  ○ p2 (занят B)
```

p0 содержит 1 фишки → только один из t1 или t2 может сработать → гарантия взаимного исключения.

## Применение

- Моделирование производственных линий
- Протоколы передачи данных (TCP, token ring)
- Базы данных (operational semantics)
- Анализ deadlock'ов в распределённых системах
