**OpenMP (Open Multi-Processing)** — это стандартизированная спецификация (набор директив компилятора, библиотечных функций и переменных окружения) для реализации параллельных вычислений на **одном узле** с **общей памятью**.

**Fork-Join — модель параллельного выполнения**

Ключевые идеи взаимодействия:
- Один узел (единое адресное пространство)
- Общая память (все потоки видят одни и те же данные)
- Потоки, а не процессы (легковесные единицы выполнения)
- Параллелизм на уровне циклов и задач (директивы компилятора)

```c
#include <omp.h>
#include <stdio.h>

int main() {
    int i;
    int arr[1000];
    
    #pragma omp parallel for
    for (i = 0; i < 1000; i++) {
        arr[i] = i * i;
    }
    
    return 0;
}
```
