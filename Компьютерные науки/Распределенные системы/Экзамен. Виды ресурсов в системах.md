# Виды ресурсов в распределённых системах

## Определение
**Ресурс** — любая сущность, которую процессы могут использовать для выполнения задач.

## Классификация по типу

### Аппаратные ресурсы
- **CPU** — процессоры, ядра, потоки исполнения
- **Память** — оперативная (RAM), кэш, виртуальная
- **Устройства ввода/вывода** — диски, сетевые адаптеры, принтеры

### Программные ресурсы
- **Файлы** — данные на диске, логи, конфигурации
- **Семафоры** — примитивы синхронизации
- **Сообщения** — данные в очередях между процессами

## Классификация по активности

| Тип | Описание | Пример |
|-----|----------|--------|
| **Активные** | Имеют собственный поток исполнения | Процессы, потоки |
| **Пассивные** | Сами не выполняются, используются активными | Данные, файлы, переменные |

## Классификация по доступу

- **Локальные** — доступны только одному процессу (локальная переменная)
- **Разделяемые** — доступны нескольким процессам (общая память, файлы)

## Классификация по времени жизни

- **Постоянные** — существуют всё время работы системы (диски, файловая система)
- **Временные** — создаются и уничтожаются в ходе работы (процессы, потоки)

## Классификация по критичности

- **Критические** — требуют механизма взаимного исключения (счётчик семафора, общий файл)
- **Некритические** — доступ без ограничений (read-only данные)

## Ключевые проблемы
- **Гонка за ресурсом** (race condition) — неопределённость при конкурентном доступе
- **Взаимная блокировка** (deadlock) — циклическое ожидание ресурсов
- **Недостаток** (starvation) — бесконечное ожидание критического ресурса
