# Экзамен. Процессы и их состояния

## Определение процесса

**Процесс** — программа в.execution state: код + данные + стек + множество регистров + PCB.

Отличие от программы:
- Программа — пассивный файл на диске
- Процесс — активная единица выполнения с выделенными ресурсами

## PCB (Process Control Block)

Блок управления процессом — структура данных в ядре ОС, содержащая:

| Поле | Описание |
|------|----------|
| PID | Уникальный идентификатор |
| Состояние | new, ready, running, waiting, terminated |
| Счётчик команд | Адрес следующей инструкции |
| Регистры | Состояние регистров процесса |
| Расписание | Приоритет, время CPU |
| Список открытых файлов | Дескрипторы файлов |
| Сегменты памяти | Код, данные, стек |

### Новые состояния

| Состояние | Описание |
|-----------|----------|
| **New** | Процесс создан, ещё не загружен в память |
| **Ready** | Готов к выполнению, ждёт CPU |
| **Running** | Инструкции выполняются на процессоре |
| **Waiting (Blocked)** | Ожидает события (ввод/вывод, сигнал) |
| **Terminated** | Завершён, ресурсы освобождаются |

## Переходы состояний

| Переход | Условие |
|---------|---------|
| new → ready | Диспетчер создал процесс |
| ready → running | CPU назначен процессу (dispatch) |
| running → ready | Таймер (preemption) |
| running → waiting | Запрос I/O или ожидание события |
| waiting → ready | I/O завершено / событие получено |
| running → terminated | `exit()` или нормальное завершение |

## Многозадачность

- **Превентивная (preemptive)**: ОС принудительно переключает процесс (таймер)
- **Кооперативная (cooperative)**: Процесс сам отдаёт CPU (устарела)
