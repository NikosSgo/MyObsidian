# Экзамен. Уровни распараллеливания

## Уровень инструкций (ILP)

**Instruction-Level Parallelism** — параллелизм на уровне отдельных инструкций процессора.

- **Пайплайニング**: разные стадии выполнения разных инструкций одновременно
- **Суперскалярность**: несколько исполнительных устройств, выполнение N инструкций за такт
- **Out-of-order execution**: процессор переупорядочивает инструкции для загрузки устройств
- **Speculative execution**: предсказание ветвлений и выполнение инструкций «впрок»

Ограничен **依赖性 между инструкциями** и **предсказанием ветвлений**.

## Уровень данных (SIMD)

**Data-Level Parallelism** — одно действие, множество данных.

- **SIMD** (Single Instruction, Multiple Data): одна инструкция применяется к массиву данных
- Примеры: SSE, AVX, NEON в CPU; потоковые ядра GPU

```c
// SIMD: 4 числа обрабатываются одновременно
__m128 a = _mm_set_ps(1.0, 2.0, 3.0, 4.0);
__m128 b = _mm_set_ps(5.0, 6.0, 7.0, 8.0);
__m128 c = _mm_add_ps(a, b);  // {6, 8, 10, 12}
```

- GPU: тысячи потоков выполняют одну программу на разных данных

## Уровень задач (TLP)

**Task-Level Parallelism** — параллелизм независимых задач.

| Механизм | Описание |
|----------|----------|
| **Потоки (threads)** | Общее адресное пространство, дешёвый контекстный переключ |
| **Процессы (processes)** | Изолированное адресное пространство, безопасность |
| **Async/await** | Неблокирующее выполнение (Go routines, Kotlin coroutines) |

## Распределённые вычисления

Множество компьютеров работают над одной задачей через сеть.

- **MapReduce** — обработка大数据 в кластере
- **Spark** — обработка данных в памяти
- **Microservices** — распределение бизнес-логики

## Закон Амдала

Определяет **максимальное ускорение** при параллелизации:

```
S(p) = 1 / ((1 - p) + p/p)

где p — доля параллельного кода
    p — число процессоров
```

**Пример:** если 75% кода параллелизуется, на 4 ядрах:
```
S = 1 / (0.25 + 0.75/4) = 1 / 0.4375 ≈ 2.29x
```

**Вывод:** ускорение ограничено **последовательной частью** программы. Даже при бесконечном числе ядер, S ≤ 1/(1-p).
