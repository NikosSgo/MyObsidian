# Принципы работы MPI и OpenMP

## MPI (Message Passing Interface)

### Суть

Стандарт интерфейса для передачи сообщений в распределённой (distributed memory) среде. Каждый процесс имеет собственное адресное пространство.

### Точечная коммуникация (Point-to-Point)

```c
// Отправка
MPI_Send(&data, count, MPI_DOUBLE, dest, tag, MPI_COMM_WORLD);

// Приём
MPI_Recv(&data, count, MPI_DOUBLE, src, tag, MPI_COMM_WORLD, &status);
```

### Коллективные операции

| Операция | Описание |
|----------|----------|
| `MPI_Bcast` | Рассылка данных от одного процесса всем |
| `MPI_Reduce` | Агрегация данных (SUM, MAX, MIN...) от всех к корневому |
| `MPI_Scatter` | Разделение массива на части по процессам |
| `MPI_Gather` | Сбор данных от всех процессов в один массив |

### Группировка: MPI_Comm

`MPI_COMM_WORLD` — коммуникатор, объединяющий все процессы. Можно создавать подгруппы:

```c
MPI_Comm_split(MPI_COMM_WORLD, color, key, &new_comm);
```

### Запуск

```bash
mpirun -np 4 ./program
```

## OpenMP

### Суть

API для программирования с общей памятью (shared memory). Использует директивы компилятора.

### Модель Fork-Join

```
主线程:  ═══════╗  parallel  ╔══════════  (продолжение)
                 ║  ║  ║  ║
Потоки:          ║  ║  ║  ║  (выполняют итерации)
                 ╚══╩══╩══╝
```

### Основные директивы

```c
// Параллельный цикл
#pragma omp parallel for
for (int i = 0; i < N; i++) {
    a[i] = b[i] + c[i];
}

// Критическая секция
#pragma omp critical
{ sum += local_sum; }

// Одноразовое выполнение
#pragma omp single
{ init_data(); }
```

### Клаузы распределения данных

| Клауза | Описание |
|--------|----------|
| `shared` | Переменная разделяемая между потоками (по умолчанию) |
| `private` | Копия переменной для каждого потока |
| `firstprivate` | Копия с инициализацией из внешней области |
| `reduction(op:v)` | Агрегация через оператор (например, `+:sum`) |

## Сравнение MPI и OpenMP

| Критерий | MPI | OpenMP |
|----------|-----|--------|
| Память | Распределённая | Разделяемая |
| Коммуникация | Явная передача сообщений | Неявная (через shared-переменные) |
| Масштабирование | Кластеры, суперкомпьютеры | Многоядерные серверы |
| Сложность кода | Выше (управлениеrank'ами) | Ниже (директивы) |
| Переносимость | Кроссплатформенная | Зависит от компилятора |
| Гранулярность | Грубая (процессы) | Тонкая (потоки) |
| Типичная область | HPC, расчётные сетки | NumPy, scientific computing |
