### Распределенная система (РС)

**Определение:** Набор независимых компьютеров, представляющийся пользователю единой системой (По Tanenbaum).

**Требования к РС (от 4 до 7, по разным классификациям):**

1. **Прозрачность** — пользователь не видит, что система распределена (доступ, расположение, миграция, репликация, параллелизм, отказ)
2. **Открытость** — стандартные интерфейсы, возможность расширения
3. **Масштабируемость** — рост числа узлов не снижает производительность
4. **Надёжность/отказоустойчивость** — сбой одного узла не валит всю систему
5. **Безопасность** — аутентификация, авторизация, шифрование
6. **Гетерогенность** — разные ОС, железо, языки должны взаимодействовать
7. **Согласованность (Consistency)** — данные на разных узлах не противоречат друг другу

### Функции логических программных слоёв РС

Типичная архитектура:

| Слой | Функция | Примеры |
|---|---|---|
| **Приложений** | Пользовательский интерфейс | Web UI, мобильное приложение |
| **Бизнес-логики** | Обработка данных, правила | Микросервисы, бизнес-процессы |
| **Распределения** | Координация, RPC, обмен сообщениями | Kafka, RabbitMQ, gRPC |
| **Системный** | ОС, сетевое взаимодействие | TCP/IP, HTTP, DNS |
