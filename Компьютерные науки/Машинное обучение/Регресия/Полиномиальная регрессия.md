**Полиномиальная регрессия** - это параметрический метод [[Статистическое обучение|статистического обучения с учителем]] для прогноза числовой целевой переменной. По сути, это [[Линейная регрессия|линейная регрессия]], но с **добавлением степеней** исходных признаков.

Модель предполагает, что среднее значение ответа **полиномиально** зависит от признаков.

Для одного признака $X$ полином степени $d$ выглядит так:
$$Y = \beta_0 + \beta_1X + \beta_2X^2 + \ldots + \beta_dX^d + \varepsilon.$$
$Y$ - целевая переменная; $X$ - исходный признак; $X^2, \ldots, X^d$ - возведённые в степень признаки (новые фичи); $\beta$ - коэффициенты; $\varepsilon$ - [[Разложение ошибки на компоненты#Случайная ошибка. Irreducible Error|случайная ошибка]].

**Важно:** модель остаётся **линейной по коэффициентам** $\beta$, поэтому обучается теми же методами, что и линейная регрессия.

Коэффициенты подбирают **МНК** (методом наименьших квадратов). Минимизируют сумму квадратов остатков:
$$RSS = \sum_{i=1}^{n}(y_i - \hat y_i)^2.$$

Коэффициенты **не интерпретируются** так же просто, как в линейной регрессии, из-за корреляции между $X, X^2, X^3, \ldots$. **Знак** отдельного коэффициента не отражает направление влияния признака на целевую переменную. Основная цель — **качество предсказания**, а не интерпретация.

Главная задача — выбрать оптимальную степень $d$:
- Слишком **низкая** ($d=1$) -> **недообучение**: модель не улавливает нелинейность
- **Оптимальная** -> лучший баланс смещения и дисперсии
- Слишком **высокая** -> **переобучение**: модель подстраивается под шум

Для выбора степени используют [[Кросс-валидация|кросс-валидацию]].

**Сильно подвержена переобучению** при высоких степенях, **чувствительна к выбросам**, при высоких степенях коэффициенты становятся **нестабильными** (проблема мультиколлинеарности). Плохо экстраполирует — поведение за пределами данных может быть непредсказуемым.

Перед обучением признаки **стандартизируют**, чтобы избежать проблем с масштабом. На практике редко используют степени выше 3-4 из-за риска переобучения.
