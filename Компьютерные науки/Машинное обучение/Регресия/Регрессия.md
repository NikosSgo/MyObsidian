**Регрессия** — это группа **параметрических** методов машинного обучения с учителем для решения задач **предсказания** числовых значений.

К регрессионным методам относятся:
- [[Линейная регрессия]]
- [[Полиномиальная регрессия]]

А **[[Логистическая регрессия]]**, несмотря на название, — это метод для решения задач **классификации**.
