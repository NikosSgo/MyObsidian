Метод локтя заключается в следующем, изначально выбирается некое множество значений $K$, например от 1 до 0:
1. Запускаем алгоритм k-means для каждого $K$.
2. Вычисляем внутрикластерную дисперсию для каждого значения $K$.
3. **Строим график**
	- на X откладываем значения $K$
	- на Y соответствующие значения внутрикластерной дисперсии.
4. **Ищем «локоть» на графике**: это точка, где дальнейшее увеличение числа кластеров не приводит к значительному снижению внутрикластерной дисперсии.
