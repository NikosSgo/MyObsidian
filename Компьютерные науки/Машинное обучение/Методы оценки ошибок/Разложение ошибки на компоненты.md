## Формула

```
Общая ошибка модели = Смещение² + Дисперсия + Случайная ошибка
```
$$\mathbb{E}[(y - \hat{f}(x))^2] = \underbrace{(\mathbb{E}[\hat{f}(x)] - f(x))^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Noise}}$$
## Смещение. Bias
Ошибка из-за того, что **модель слишком простая** и из-за этого **не улавливает истинную закономерность**.
- Высокое смещение -> **недообучение**
- Выявляется, если ошибка: 
	- на обучающей выборке -> низкая 
	- так же на **тестевой выборке** -> низкая 
- Решением **недообучения** -> 
	- усложнить модель
	- добавить признаков

## Дисперсия. Variance
Ошибка из-за того, что **модель слишком простая** и из-за этого **подстраивается под шумы**.
- Высокая дисперсия -> **переобучение**.
- Выявляется, если ошибка:
	- на обучающей выборке -> низкая
	- на тестовой выборке -> высокая
- Решение **переобучения** -> 
	- упрощение модели
	- добавление регуляризации
	- увеличение обучающих данные.
## Случайная ошибка. Irreducible Error
Часть общей ошибки модели, которая возникает из-за:
- некой неученности 
- природного шума
- невозможности предсказать некоторые факторы
