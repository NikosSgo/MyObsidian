[[Виды регрессий]]

**Логистическая регрессия** — параметрический метод [[Статистическое обучение|обучения с учителем]] для классификации. Несмотря на название, она предсказывает не числовое значение, а вероятность принадлежности объекта к классу.

Чаще всего используется для бинарной классификации: $Y \in \{0, 1\}$, например «спам / не спам» или «клиент уйдёт / не уйдёт».

## Модель вероятности

Линейная регрессия не подходит для вероятности напрямую: её прогноз может оказаться меньше 0 или больше 1. В логистической регрессии линейная комбинация признаков пропускается через сигмоиду:

$$P(Y=1\mid X) = \sigma(z) = \frac{1}{1 + e^{-z}},$$

где

$$z = \beta_0 + \beta_1X_1 + \ldots + \beta_pX_p.$$

Поэтому прогноз всегда находится в интервале от 0 до 1.

Эквивалентная запись через **логарифм шансов** (logit):

$$\log\frac{p}{1-p} = \beta_0 + \beta_1X_1 + \ldots + \beta_pX_p,$$

где $p = P(Y=1\mid X)$, а $\frac{p}{1-p}$ — шансы положительного класса.

## От вероятности к классу

Модель возвращает вероятность $p$. Чтобы получить метку класса, выбирают порог $t$:

- $p \geq t$ — прогнозируют класс 1;
- $p < t$ — прогнозируют класс 0.

Порог $0{,}5$ используют по умолчанию, но он не всегда оптимален. Если опасно пропустить положительный случай, порог понижают; если ложная тревога дорога — повышают.

## Обучение

Коэффициенты подбирают методом максимального правдоподобия. На практике минимизируют **логарифмическую потерю** (binary cross-entropy):

$$LogLoss = -\frac{1}{n}\sum_{i=1}^{n}\left[y_i\log p_i + (1-y_i)\log(1-p_i)\right].$$

В отличие от обычной линейной регрессии, здесь нет простой общей формулы МНК; коэффициенты обычно находят итеративной оптимизацией, например градиентным спуском.

## Интерпретация коэффициентов

- При увеличении $X_j$ на единицу логарифм шансов класса 1 меняется на $\beta_j$, при неизменных остальных признаках.
- Величина $e^{\beta_j}$ показывает, во сколько раз меняются шансы класса 1 при увеличении $X_j$ на единицу.
- Коэффициенты не означают прямое изменение вероятности на фиксированную величину: эффект зависит от исходного значения признаков и вероятности.
- Как и в линейной регрессии, связь в модели не доказывает причинность.

## Многоклассовая классификация

- **One-vs-rest**: строят отдельную бинарную модель для каждого класса «этот класс / все остальные».
- **Мультиномиальная логистическая регрессия**: оценивает вероятности всех классов одновременно с помощью функции softmax.

## Предпосылки и ограничения

- Наблюдения должны быть независимы или их зависимость должна быть учтена.
- Логарифм шансов предполагается линейной функцией признаков. Нелинейность можно добавить преобразованиями и взаимодействиями признаков.
- Нет строгой мультиколлинеарности; сильная корреляция признаков делает коэффициенты нестабильными.
- Для редкого положительного класса accuracy может создавать ложное впечатление хорошей модели.

Для снижения переобучения применяют L1- или L2-[[Регуляризация|регуляризацию]].

## Оценка качества

- При равных классах и одинаковой цене ошибок используют accuracy.
- При важности положительного класса — precision, recall и F1.
- Для выбора порога и оценки ранжирования — ROC-кривую, ROC-AUC; при редком положительном классе также PR-AUC.
- Для качества самих вероятностей — log loss и калибровку.

Подробнее: [[Метрики оценки качества моделей машинного обучения]].

## Плюсы и минусы

- Плюсы: быстрая, интерпретируемая, выдаёт вероятности, хорошо работает как базовая модель.
- Минусы: по умолчанию описывает только линейную границу решений; чувствительна к качеству и представлению признаков; может уступать более гибким моделям при сложной нелинейной структуре данных.
