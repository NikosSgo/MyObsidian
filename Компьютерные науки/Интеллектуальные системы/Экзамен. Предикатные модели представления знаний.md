### Модели представления знаний

**Знания** в интеллектуальных системах — формализованная информация, используемая для решения задач.

**Основные модели:** продукционные, семантические сети, фреймы, логические (предикатные).

---

### Предикатные продукции

**Атомарная продукционная система:**
- Правила вида: `ЕСЛИ A ТО B`
- $A$ (антецедент) — условие (атом)
- $B$ (консеквент) — действие/вывод
- Без переменных, только конкретные факты

**Предикатная продукционная система (расширение):**
- Правила с переменными и предикатами:
  `ЕСЛИ Родитель(x, y) И Родитель(y, z) ТО Дедушка(x, z)`
- Унификация переменных (сопоставление с фактами)
- Прямой и обратный вывод

**Продукционная система с исключениями из правил:**
- Правила вида: `ЕСЛИ A ТО B ИСКЛЮЧАЯ A'`
- $A'$ — условие-исключение (если истинно, правило не срабатывает)
- Используется для немонотонного вывода (неполнота знаний)

**Иерархическая модель продукций:**
- Продукции организованы в иерархию (абстрактные → конкретные)
- Наследование правил от вышестоящих уровней
- Пример: `Птица → Летает`, `Пингвин → Не летает` (наследование с переопределением)

**Сценарная модель продукций:**
- Правила, описывающие последовательность типовых ситуаций
- Пример: сценарий «Ресторан» → вход, заказ, еда, оплата, выход
- Ожидания: если A то B и C, причём B перед C
- Используется в планировании и понимании текстов

**Сравнение моделей:**

| Модель | Переменные | Исключения | Иерархия | Сценарии |
|---|---|---|---|---|
| Атомарная | Нет | Нет | Нет | Нет |
| Предикатная | Да | Нет | Нет | Нет |
| С исключениями | Да | Да | Нет | Нет |
| Иерархическая | Да | Да | Да | Нет |
| Сценарная | Да | Нет | Нет | Да |
