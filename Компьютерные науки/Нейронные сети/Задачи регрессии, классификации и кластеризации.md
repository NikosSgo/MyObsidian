[[Статистическое обучение]]

Задача задаёт, **какой результат нужен от данных**. Алгоритм — это способ её решить. Например, классификация — задача, а логистическая регрессия, SVM и дерево решений — алгоритмы классификации.

## Два назначения модели

- **Предсказательное**: по признакам $X$ получить точный прогноз $Y$ для нового объекта. Важнее всего ошибка на новых данных.
- **Описательное (инференциальное)**: понять, как признаки связаны с $Y$, какие из них важны и в каком направлении действует связь. Здесь важны интерпретация модели и статистическая неопределённость.

Одна и та же модель может использоваться для обеих целей, но критерий выбора будет разным.

## Задачи с учителем

В данных известна целевая переменная $Y$. Модель учится по парам $(X, Y)$.

- **Регрессия** — $Y$ числовая непрерывная величина.
  - Примеры: цена квартиры, температура, время доставки.
  - Методы: линейная и полиномиальная регрессия, деревья решений, случайный лес, бустинг.
- **Классификация** — $Y$ принимает один из классов.
  - Примеры: спам/не спам, диагноз, категория товара.
  - Бывает бинарной и многоклассовой.
  - Методы: логистическая регрессия, SVM, деревья, нейронные сети.
- **Ранжирование** — нужно упорядочить объекты по релевантности или ожидаемой полезности.
  - Примеры: выдача поиска, рекомендации, приоритизация заявок.

## Задачи без учителя

Целевой переменной нет. Нужно обнаружить структуру самих признаков $X$.

- **Кластеризация** — разделить объекты на похожие группы.
  - Примеры: сегментация клиентов, группы документов, типы поведения пользователей.
- **Снижение размерности** — представить данные меньшим числом признаков, сохранив существенную структуру.
  - Примеры: визуализация многомерных данных, сжатие признаков, подготовка к моделированию.
- **Поиск аномалий** — найти редкие или нетипичные объекты.
  - Примеры: мошеннические операции, сбои оборудования, ошибки в данных.
- **Оценка плотности распределения** — оценить, как распределены наблюдения в пространстве признаков.

## Как определить тип задачи

- Есть известный правильный ответ $Y$ для объектов обучения — задача с учителем.
- $Y$ число — регрессия; $Y$ класс — классификация.
- Ответов нет, нужно исследовать структуру — задача без учителя.
- Требуется выбрать действие в изменяющейся среде и есть сигнал награды — [[Обучение с подкреплением]].

Далее для выбранной задачи определяют класс модели: [[Параметрические и непараметрические модели]].
