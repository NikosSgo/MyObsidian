# Экзамен. Вероятностная нейронная сеть (PNN)

## Определение

**Вероятностная нейронная сеть (PNN)** — сеть на основе **ядерного оценщика плотности** (окна Парзена). Классифицирует объекты по **правилу Байеса** с минимальной вероятностью ошибки.

## Архитектура (4 слоя)

| Слой | Функция |
|------|---------|
| **Входной** | Передаёт вектор признаков x |
| **Паттернов** | Каждый нейрон = один обучающий образец; вычисляет расстояние до x |
| **Суммирования** | Суммирует выходы паттернов по каждому классу (взвешенная сумма) |
| **Выходной** | Выбирает класс с максимальным значением (softmax / max) |

## Ядерное оценка плотности

$$f_i(x) = \frac{1}{N_i h^d} \sum_{j=1}^{N_i} K\left(\frac{x - x_j}{h}\right)$$

- K — **ядерная функция** (обычно гауссово): $K(u) = \frac{1}{(2\pi)^{d/2}} e^{-\|u\|^2/2}$
- h — **параметр сглаживания** (σ) — определяет ширину окна
- Nᵢ — число образцов класса i

## Классификация по правилу Байеса

$$\text{class} = \arg\max_i \left[ P_i \cdot f_i(x) \right]$$

где Pᵢ — априорная вероятность класса i.

## Преимущества

- **Однопроходное обучение** — не требует итераций
- Не имеет **локальных минимумов**
- Работа с **многоклассовой** классификацией «из коробки»
- Интерпретируемый результат (плотности вероятностей)
- Подходит для **малых и средних** выборок

## Недостатки

- Большое потребление памяти (все образцы = нейроны)
- Замедление при очень больших.datasetах
- Чувствительность к параметру σ
