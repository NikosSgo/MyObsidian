# Нейронные сети Кохонена (Self-Organizing Maps)

## Определение
**SOM (Self-Organizing Map)** — тип самоорганизующейся нейронной сети, обучение без учителя (unsupervised learning), предназначенная для **кластеризации** и **визуализации** данных.

## Архитектура

### Слой Кохонена (Kohonen Layer)
- **Двумерная решётка** нейронов (обычно 2D)
- Каждый нейрон имеет **вектор весов** той же размерности, что и вход
- Нейроны **соревнуются** за право отклика на входной вектор

### Competitive Learning (соревновательное обучение)
- При подаче входного вектора **x**:
  1. Вычисляется расстояние (евклидово) до каждого нейрона
  2. **Побеждает** нейрон с минимальным расстоянием — **BMU** (Best Matching Unit)
  3. Победитель и его соседи **обновляют** веса

### Winner-Take-All (победитель забирает всё)
- Только BMU (и соседи) получают обновление весов
- Остальные нейроны не изменяются

## Функция соседства (Neighborhood Function)

### Формула
```
h(t) = exp(-d² / (2·σ(t)²))
```
- **d** — расстояние от BMU до нейрона на решётке
- **σ(t)** — радиус соседства, уменьшается со временем

### Свойства
- В начале обучения: **большой радиус** (все нейроны меняются)
- В конце: **малый радиус** (только BMU и ближайшие)
- Свойство **топологической сохранности:** близкие на входе → близкие на карте

## Алгоритм обучения

```
1. Инициализация весов (случайно или PCA)
2. Повторять N итераций:
   a. Выбрать случайный входной вектор x
   b. Найти BMU: j* = argmin_j ||x - w_j||
   c. Для каждого нейрона j в окрестности BMU:
      w_j(t+1) = w_j(t) + η(t) · h(t) · (x - w_j(t))
   d. Уменьшить η(t) (скорость обучения) и σ(t) (радиус)
```

## Параметры

| Параметр | Влияние |
|----------|---------|
| Размер решётки | Количество кластеров, детализация карты |
| Скорость обучения η(t) | Скорость сходимости |
| Радиус соседства σ(t) | Топологическая сохранность |
| Число итераций | Качество обучения |

## Метрики

### Квантизационная ошибка (QE)
- Среднее расстояние от каждого входного вектора до его BMU
- **Меньше QE → лучше кластеризация**

### Топографическая ошибка (TE)
- Доля векторов, для которых второй BMU не является соседом первого
- **Меньше TE → лучше сохранена топология**

## Применения
- **Кластеризация:** группировка похожих данных без.labels
- **Визуализация:** U-Matrix (расстояния между нейронами) показывает границы кластеров
- **Анализ данных:** самоорганизация профилей покупателей, сегментация рынка
- **Обнаружение аномалий:** данные далеко от всех BMU

## Преимущества и ограничения

| + | − |
|---|---|
| Визуализация высокоразмерных данных | Фиксированный размер решётки |
| Топологическая сохранность | Зависимость от гиперпараметров |
| Не требует разметки | Не оптимизирует кластеризацию напрямую |
| Быстрое обучение | Большие данные → long training |
