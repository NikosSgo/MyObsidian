# Функции активации нейронных сетей

## Зачем нужны
Вносят **нелинейность**, позволяя сети моделировать сложные зависимости.

## Основные функции

### Sigmoid (σ)
- **Формула:** σ(x) = 1 / (1 + e^(-x))
- **Диапазон:** (0, 1)
- **Производная:** σ(x)(1 − σ(x))
- **Применение:** Выходной слой (бинарная классификация)
- **Проблема:** Vanishing gradient (затухающие градиенты), не центрирована в 0

### Tanh
- **Формула:** tanh(x) = (e^x − e^(−x)) / (e^x + e^(−x))
- **Диапазон:** (−1, 1)
- **Производная:** 1 − tanh²(x)
- **Применение:** Скрытые слои RNN
- **Преимущество:** Центрирована в 0 (лучше, чем sigmoid)
- **Проблема:** Vanishing gradient

### ReLU (Rectified Linear Unit)
- **Формула:** f(x) = max(0, x)
- **Производная:** 0 (x < 0), 1 (x > 0), не определена в 0
- **Применение:** Скрытые слои (по умолчанию)
- **Плюсы:** Быстрая, нет vanishing gradient для x > 0
- **Минус:** "Мёртвые нейроны" (output = 0, gradient = 0)

### Leaky ReLU
- **Формула:** f(x) = max(αx, x), α = 0.01
- **Производная:** α (x < 0), 1 (x > 0)
- **Преимущество:** Решает проблему мёртвых нейронов

### ELU (Exponential Linear Unit)
- **Формула:** f(x) = x (x > 0), α(e^x − 1) (x ≤ 0)
- **Преимущество:** Отрицательные значения ненулевые, среднее ближе к 0
- **Минус:** Вычислительно дороже ReLU

### Softmax
- **Формула:** softmax(x_i) = e^(x_i) / Σ e^(x_j)
- **Диапазон:** (0, 1), сумма = 1
- **Применение:** Выходной слой (многоклассовая классификация)
- **Особенность:** Зависит от всех выходов слоя

### Swish
- **Формула:** f(x) = x · σ(x)
- **Плюсы:** Гладкая, нет мёртвых нейронов, лучше ReLU в глубоких сетях
- **Минус:** Вычислительно дороже

## Сравнение

| Функция | Диапазон | Vanishing gradient | Мёртвые нейроны | Скорость |
|---------|----------|--------------------|-----------------|----------|
| Sigmoid | (0, 1) | Да | Нет | Низкая |
| Tanh | (-1, 1) | Да | Нет | Низкая |
| ReLU | [0, ∞) | Нет (x>0) | Да | Высокая |
| Leaky ReLU | (-∞, ∞) | Нет | Нет | Высокая |
| ELU | (-α, ∞) | Нет | Нет | Средняя |
| Softmax | (0, 1) | Зависит | Нет | Средняя |
| Swish | ≈(-0.28, ∞) | Нет | Нет | Средняя |

## Когда какую использовать
- **Выход (бинарная классификация):** Sigmoid
- **Выход (многоклассовая):** Softmax
- **Скрытые слои (по умолчанию):** ReLU
- **Глубокие сети:** Swish, ELU
- **RNN:** Tanh
