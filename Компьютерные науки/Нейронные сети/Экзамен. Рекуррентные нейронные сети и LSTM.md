# Экзамен. Рекуррентные нейронные сети и LSTM

## RNN (Recurrent Neural Network)

### Принцип работы
- Обрабатывает **последовательности** (тексты, временные ряды)
- **Скрытое состояние** hₜ зависит от текущего входа xₜ и предыдущего hₜ₋₁:

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$$

- Одни и те же веса используются на **каждом шаге** (weight sharing)

### Проблема затухающего градиента

- При обратном распространении через T шагов: $\frac{\partial L}{\partial h_1} = \frac{\partial L}{\partial h_T} \cdot \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}}$
- Произведение **множителей < 1** → градиент **экспоненциально затухает**
- Сеть «забывает» **долгосрочные** зависимости

## LSTM (Long Short-Term Memory)

### Архитектура
- **Cell state** (cₜ) — «шоссе» для передачи информации без изменений
- Три **ворота** управляют потоком информации:

| Ворота | Функция | Формула |
|--------|---------|---------|
| **Forget** | Что **забыть** из cell state | fₜ = σ(W_f · [hₜ₋₁, xₜ] + b_f) |
| **Input** | Что **добавить** в cell state | iₜ = σ(W_i · [hₜ₋₁, xₜ] + b_i) |
| **Output** | Что **вывести** из cell state | oₜ = σ(W_o · [hₜ₋₁, xₜ] + b_o) |

### Обновление cell state

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

$$h_t = o_t \odot \tanh(c_t)$$

- **Вместо** затухающего градиента → линейный поток через cₜ
- Запоминает зависимости на **сотни** шагов

---

## GRU (Gated Recurrent Unit)

- Упрощённая версия LSTM: **2 ворота** (reset, update)
- Cell state и hidden state **объединены**
- **Меньше параметров**, быстрее обучение
- По качеству ≈ LSTM на многих задачах

$$z_t = \sigma(W_z [h_{t-1}, x_t]) \quad \text{(update)}$$
$$r_t = \sigma(W_r [h_{t-1}, x_t]) \quad \text{(reset)}$$
$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tanh(W [r_t \odot h_{t-1}, x_t])$$

---

## Bidirectional RNN

- **Два** скрытых слоя: forward (t=1→T) и backward (t=T→1)
- Выход на каждом шаге: **конкатенация** → [h⃗ₜ, h⃖ₜ]
- Учитывает **контекст в обе стороны**
- Применение: NER, перевод, классификация предложений

## Сравнение

| Модель | Запоминание | Параметры | Параллелизм |
|--------|-------------|-----------|-------------|
| RNN | Краткосрочное | Мало | Нет |
| LSTM | Долгосрочное | Много | Нет |
| GRU | Долгосрочное | Средне | Нет |
| BiRNN | Двустороннее | ×2 | Нет |
