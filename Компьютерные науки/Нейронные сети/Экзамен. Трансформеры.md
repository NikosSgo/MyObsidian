# Экзамен. Трансформеры

## Определение

**Трансформер** — архитектура без рекуррентности и свёрток, основанная полностью на **механизме внимания (self-attention)**. Работает параллельно на всей последовательности.

## Self-Attention (Механизм внимания)

### Query, Key, Value

Для каждого токена создаются три вектора:
- **Query (q)** — «что я ищу?»
- **Key (k)** — «что я знаю?»
- **Value (v)** — «что я отдаю?»

### Формула внимания

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

- $\sqrt{d_k}$ — нормировка для стабильности градиентов
- softmax даёт **веса внимания** между всеми парами токенов

## Multi-Head Attention

- Несколько **независимых** голов внимания (h голов)
- Каждая голова учит свой **аспект** отношений
- Результаты **конкатенируются** и проходят линейное преобразование:

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, ..., \text{head}_h) W^O$$

## Позиционное кодирование (Positional Encoding)

- Self-attention **не учитывает порядок** токенов
- Добавляются синусоидальные (или обучаемые) векторы позиций:

$$PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d}), \quad PE_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d})$$

## Архитектура Encoder-Decoder

### Encoder (L слоёв)
- Multi-Head Self-Attention + Add & Norm + Feed-Forward + Add & Norm
- Закодированное представление входной последовательности

### Decoder (L слоёв)
- **Masked** Self-Attention (не видит будущие токены)
- Cross-Attention к выходу encoder
- Feed-Forward + residual connections

### Masked Attention
- В softmax маскируются позиции > текущей → **-diagonal mask**
- Обеспечивает авторегрессионную генерацию

## Ключевые модели

| Модель | Тип | Особенность |
|--------|-----|-------------|
| **BERT** | Encoder-only | Двусторонний, MLM (маскированный LM) |
| **GPT** | Decoder-only | Авторегрессионный, предсказание следующего токена |
| **T5** | Encoder-Decoder | «Text-to-Text» — все задачи как генерация текста |
| **ViT** | Encoder-only | Трансформер для изображений (патчи 16×16) |

## Преимущества над RNN

| Критерий | RNN | Трансформер |
|----------|-----|-------------|
| Параллелизм | Последовательно | **Полностью параллельно** |
| Длинные зависимости | Затухающий градиент | **Прямая связь** между любыми токенами |
| Вычислительная сложность | O(T·d) | O(T²·d) — внимание quadratic |
| Масштабирование | Ограничено | Масштабируется до **сотен млрд** параметров |
