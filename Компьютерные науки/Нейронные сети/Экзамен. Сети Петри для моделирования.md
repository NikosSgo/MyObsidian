# Экзамен. Сети Петри для моделирования

## Определение
Сеть Петри — математическая модель для описания **параллельных**, **распределённых** и **конкурирующих** систем. Графическое представление: бипартитный граф.

## Структура сети Петри

### Элементы
- **P** — множество **п Places** (круги): состояние системы, хранят токены
- **T** — множество **transitions** (прямоугольники): события/действия
- **M** — функция **маркировки** (marking): распределение токенов по places
- **W** — веса рёбер: сколько токенов потребляется/производится

### Правило запуска
Transition $t$ может сработать, если **каждый** входной place содержит ≥ веса соответствующего ребра. При срабатывании:
1. Токены **удаляются** из входных places (по весам рёбер)
2. Токены **добавляются** в выходные places (по весам рёбер)

## Свойства

### Основные свойства
- **Безопасность (Safeness):** не более 1 токена в каждом place (0-сеть)
- **Ограниченность:** число токенов в каждом place ограничено
- **Живучесть (Liveness):** из каждого состояния достижимо срабатывание transition
- **Отсутствие тупиков:** всегда существует доступное срабатывание

### Классы по выразительности
| Класс | Характеристика |
|-------|---------------|
| Мерные (М) | Один токен на place, нет весов рёбер |
| Неразмеряемые | Запрещены петли (self-loops) |
| Трансферные | Без ограничений (полная модель) |
| Огибающие (О) | Любая сеть Петри |

## Примеры моделирования

### Параллелизм
```
P1 → T1 → P2 → T2 → P3
          ↘ T3 → P4
```
T1 срабатывает → tokens идёт в P2 и P4 параллельно → join через T2, T3

### Конкуренция
```
P1 → T1 → P2
P1 → T2 → P3
```
T1 и T2 конкурируют за токен в P1 → недетерминизм

### Синхронизация
```
P1 → T1 → P2
P3 → T1 → P4
```
T1 требует токены и в P1, и в P3 → синхронизация двух процессов

| Потоки данных | Да | Нет | Неявное |
