**Алгоритм обратного распространения ошибки** (backpropagation) определяет стратегию подбора весов многослойной нейронной сети с применением градиентных методов оптимизации. 

При обучении **главной задачей** является минимизация **целевой функции ошибки**, которая измеряет расхождение между предсказаниями сети и реальными значениями.

### Этапы алгоритма:

#### Прямое распространение (Forward Pass):

На вход сети подаётся вектор значений $x$ (обучающий пример). Последовательно рассчитываются выходные сигналы нейронов каждого слоя — от скрытых до выходного, используя текущие значения весов и применяя функции активации. Параллельно вычисляются производные функций активации для каждого нейрона, которые нужны для следующего этапа. По сути, на этом этапе сеть "делает предсказание" на основе текущих весов.

#### Обратное распространение (Backward Pass):

Вычисляется ошибка на выходе сети — разность между фактическим выходом $y_s$ и ожидаемым целевым значением $y_{target}$. Эта ошибка распространяется в обратном направлении — от выходного слоя к входному, подобно тому, как сигнал шёл вперёд, только теперь распространяется информация об ошибке. На каждом слое используются ранее вычисленные производные функций активации и правило дифференцирования сложной функции (цепное правило) для расчёта градиентов. Градиенты показывают, в каком направлении и насколько нужно изменить каждый вес, чтобы уменьшить ошибку. После расчёта градиентов происходит корректировка весов пропорционально их вкладу в общую ошибку.

#### Обновление весов:

Веса корректируются по формуле: $w_{new} = w_{old} - \eta \cdot \nabla E$, где $\eta$ — скорость обучения (learning rate), а $\nabla E$ — градиент функции ошибки. Скорость обучения определяет величину шага при движении к минимуму функции ошибки.

### Повторение этапов:

Оба этапа повторяются на примерах из обучающей выборки (часто используется разбиение на батчи — небольшие порции данных) до тех пор, пока норма градиента не станет меньше заданного порога $\epsilon$ — критерия сходимости алгоритма. Также можно остановить обучение по другим критериям: достижение максимального числа эпох (проходов по всей выборке) или прекращение улучшения на валидационной выборке.
