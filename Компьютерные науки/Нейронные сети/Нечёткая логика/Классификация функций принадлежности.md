Функции принадлежности делят на следующие классы:
1. Кусочно-линейные функции принадлежности
	- Треугольные
$$
y(x,a,b,c) = 
\begin{cases}
o, x \le a \\
\frac{x-a}{b-a}, a \le x \le b \\
\frac{c-x}{c-b}, b \le x \le c \\
0, c \le x\\
\end{cases}
$$
	- Трапецевидные
$$
y(x,a,b,c,d) = 
\begin{cases}
o, x \le a \\
\frac{x-a}{b-a}, a \le x \le b \\
1, b \le x \le c \\
\frac{x-d}{d-c}, c \le x \le d \\
0, d \le x\\
\end{cases}
$$
