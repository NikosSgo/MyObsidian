Функции принадлежности делят на следующие классы:
1. Кусочно-линейные функции принадлежности. Приблизительно равно, среднее значение.
	- Треугольные
$$
y(x,a,b,c) = 
\begin{cases}
o, x \le a \\
\frac{x-a}{b-a}, a \le x \le b \\
\frac{c-x}{c-b}, b \le x \le c \\
0, c \le x\\
\end{cases}
$$
	- Трапецевидные
$$
y(x,a,b,c,d) = 
\begin{cases}
o, x \le a \\
\frac{x-a}{b-a}, a \le x \le b \\
1, b \le x \le c \\
\frac{d-x}{d-c}, c \le x \le d \\
0, d \le x\\
\end{cases}
$$
2. Z-образные и S-образные функции принадлежности.
	- Z-образные. Малое количество, небольшое значение.
$$
y(x,a,b) = 
\begin{cases}
1, x \le a \\
\frac{1}{2}+ \frac{1}{2}\cos(\frac{x-a}{b-a}\pi), b \le x \le c \\
0, b < x\\
\end{cases}
$$
	- S-образные. Большое количество, большое значение.
$$
y(x,a,b) = 
\begin{cases}
0, x < a \\
\frac{1}{2}+ \frac{1}{2}\cos(\frac{x-b}{b-a}\pi), b \le x \le c \\
1, b < x\\
\end{cases}
$$
	- Сигмоидальные. Если $a>0$, то получаем S-образную, если меньше, то Z-образную
$$
y(x,a,b) = \frac{1}{1-e^{-a(x-b)}} 
$$
	- Линейная Z-образная
$$
y(x,a,b) = 
\begin{cases}
1, x \le a \\
\frac{b-x}{b-a}, b \le x \le c \\
0, b < x\\
\end{cases}
$$
	- Линейная S-образная
$$
y(x,a,b) = 
\begin{cases}
1, x \le a \\
\frac{x-a}{b-a}, b \le x \le c \\
0, b < x\\
\end{cases}
$$
3. $\Pi$-образные функции принадлежности 
	- Обычная
$$
y(x,a,b,c,d)=Z(x,a,b)*S(x,c,d)
$$
	- Сигмоидальная
$$
y(x,a,b,c,d)=\sigma(x,a,b)*\sigma(x,c,d)
$$
