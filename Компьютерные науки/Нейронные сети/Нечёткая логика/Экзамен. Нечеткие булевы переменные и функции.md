### Нечеткие булевы переменные

**Нечёткая булева переменная** $x$ принимает значения в $[0,1]$:
- $x = 1$ — истина
- $x = 0$ — ложь
- $0 < x < 1$ — частичная истина

Отличие от [[Понятие нечеткого высказывания и нечеткого предиката|нечёткого высказывания]]: булева переменная — базовый элемент, высказывание — осмысленное утверждение.

---

### Логические операции (по Заде)

| Операция | Обозначение | Формула |
|---|---|---|
| Отрицание | $\overline{x}$ | $1 - x$ |
| Конъюнкция (И) | $x \land y$ | $\min(x, y)$ |
| Дизъюнкция (ИЛИ) | $x \lor y$ | $\max(x, y)$ |
| Импликация | $x \to y$ | $\max(1-x, y)$ |
| Эквивалентность | $x \leftrightarrow y$ | $\min(x\to y,\; y\to x)$ |

Подробнее — [[Основные логические операции с нечеткими высказываниями]].

**Свойства:** выполняются коммутативность, ассоциативность, дистрибутивность, законы де Моргана. Закон исключённого третьего ($x \lor \overline{x} = 1$) **не выполняется**.

### Функции нечетких булевых переменных

**Определение:** Функция $f(x_1,\dots,x_n)$, где $x_i \in [0,1]$, строится из переменных и констант $0,1$ операциями $\land, \lor, \overline{\phantom{x}}$.

**Пример:** Нечёткое XOR: $f(x,y) = (x \land \overline{y}) \lor (\overline{x} \land y)$

**Таблица функции** — для конечного набора значений (например, $\{0, 0.5, 1\}$):

| $x$ | $y$ | $x \land y$ | $x \lor y$ | $x \oplus y$ |
|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 |
| 0 | 0.5 | 0 | 0.5 | 0.5 |
| 0 | 1 | 0 | 1 | 1 |
| 0.5 | 0 | 0 | 0.5 | 0.5 |
| 0.5 | 0.5 | 0.5 | 0.5 | 0 |
| 0.5 | 1 | 0.5 | 1 | 0.5 |
| 1 | 0 | 0 | 1 | 1 |
| 1 | 0.5 | 0.5 | 1 | 0.5 |
| 1 | 1 | 1 | 1 | 0 |

где $x \oplus y = (x \land \overline{y}) \lor (\overline{x} \land y)$.

**Нормальные формы:** ДНФ (дизъюнкция конъюнкций) и КНФ (конъюнкция дизъюнкций) — аналогичны булеву случаю, но не единственны.
