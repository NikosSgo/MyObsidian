Пусть задано нечёткое множество $A$ на универсальном множестве $X$ с функцией принадлежности  
$\mu_{A}(x)$.

1. Носитель нечёткого множества — это множество всех элементов, степень принадлежности которых **больше нуля**: $\operatorname{supp}(\tilde{A}) = { x \in X \mid \mu_{\tilde{A}}(x) > 0 }.$
2. Высота нечёткого множества — это максимальное значение функции принадлежности:  $h(\tilde{A}) = \sup_{x \in X} \mu_{\tilde{A}}(x).$ 
	 Если $h(\tilde{A}) = 1$, то нечёткое множество называется **нормальным**.
3. Ядро нечёткого множества — это множество элементов, которые принадлежат нечёткому множеству **полностью**:  $\operatorname{core}(\tilde{A}) = { x \in X \mid \mu_{\tilde{A}}(x) = 1 }.$
4. Точки перехода — это элементы, для которых степень принадлежности принимает промежуточные значения:  $0 < \mu_{\tilde{A}}(x) < 1.$
	 Они образуют **нечёткую границу** множества.
5. Границы нечёткого множества — это совокупность точек перехода, где множество **не является ни полностью истинным, ни полностью ложным**.
	 Формально:  $\operatorname{bd}(\tilde{A}) = { x \in X \mid 0 < \mu_{\tilde{A}}(x) < 1 }.$
6. Множество $\alpha$-уровня — это чёткое множество элементов, степень принадлежности которых **не меньше** заданного уровня $( \alpha )$:  $A_\alpha = { x \in X \mid \mu_{\tilde{A}}(x) \ge \alpha }, \quad \alpha \in (0,1].$
	 При $\alpha = 1$ множество $\alpha$-уровня совпадает с ядром.
7. Ближайшее чёткое множество — это множество, полученное путём выбора элементов, степень принадлежности которых превышает заданный порог.
	 Наиболее часто используется правило:  $A^* = { x \in X \mid \mu_{\tilde{A}}(x) \ge 0.5 }.$
	 Это частный случай множества $\alpha$-уровня при $\alpha = 0.5$.
