**Векторные представления текста** — это способ перевести слова или фразы в **числовые векторы**, которые нейросеть сможет обрабатывать. 

Такая трансформация нужна, потому что нейросети не умеют работать с текстом напрямую. 

**Основная идея** в том, чтобы слова, похожие по смыслу, имели **похожие векторы**, то есть находились рядом в многомерном пространстве.

Векторы слов становятся **входом для нейросетей**, таких как, RNN , CNN или трансформеры (BERT, GPT).

#### Методы векторного представления текста:

| Метод                | Принцип                | Контекст? | Уровень       | Обучение     |
| -------------------- | ---------------------- | --------- | ------------- | ------------ |
| [[One-hot encoding]] | Базисный вектор        | Нет       | Слово         | Нет          |
| [[Word2Vec]]         | Предсказание контекста | Локальный | Слово         | Предобучение |
| [[FastText]]         | Субсловные единицы     | Локальный | Слово/Символы | Предобучение |

1.  **One-Hot** → **Статические эмбеддинги** (Word2Vec, GloVe) → **Контекстуальные** (ELMo) → **Трансформеры** (BERT).
2.  Современный подход: **Предобучение на большом корпусе** (BERT) + **Дообучение на задаче**.
3.  Для простых задач: **Embedding слой**, обучаемый с нуля.
