# Экзамен. Регуляризация и методы борьбы с переобучением

## Переобучение (Overfitting)

Сеть **запоминает** обучающие данные, включая шум, и теряет способность **обобщать**. На train loss падает, на val loss растёт.

## Методы регуляризации

### L1-регуляризация (Lasso)
$$L_{total} = L + \lambda \sum |w_i|$$
- Поощряет **разреженность** весов (многие веса → 0)
- Отбор признаков

### L2-регуляризация (Ridge / Weight Decay)
$$L_{total} = L + \lambda \sum w_i^2$$
- **Штрафует** большие веса, делая модель более гладкой
- Самый распространённый вариант

### Dropout
- **Training**: случайно «выключает» нейроны с вероятностью p (обычно 0.5)
- **Inference**: используются **все** нейроны, веса масштабируются на (1−p)
- Эффективная **ансамблевая** техника

### Batch Normalization
- Нормализует выходы предыдущего слоя по mini-batch: $\hat{x} = \frac{x - \mu_B}{\sqrt{\sigma_B^2 + \epsilon}}$
- Ускоряет обучение, позволяет большую скорость обучения
- Слабый регуляризационный эффект

### Early Stopping
- Останавливаем обучение при **росте val loss** (patience)
- Сохраняем модель с лучшим val score

### Аугментация данных
- Искусственное расширение обучающей выборки (повороты, отражения, шум)
- См. отдельный файл

### Ансамблевые методы
- **Bagging** (Random Forest) — параллельные модели на подвыборках
- **Boosting** (XGBoost) — последовательные модели, фокус на ошибках
- **Stacking** — мета-модель поверх базовых

## Сравнение

| Метод | Суть | Когда применять |
|-------|------|----------------|
| L1 | Разреженность | Много признаков |
| L2 | Малые веса | Всегда (по умолчанию) |
| Dropout | Выключение нейронов | Полносвязные, CNN |
| BN | Нормализация | Глубокие сети |
| Early Stop | Контроль val loss | Всегда |
