### Классификация изображений с помощью нейронной сети

**Задача:** отнести входное изображение к одному из $C$ классов.

**Вход:** изображение (тензор $H \times W \times 3$ для RGB).
**Выход:** вектор вероятностей по классам (softmax-слой).

---

### Выбор архитектуры

**Для изображений — свёрточные нейронные сети (CNN):**
- **LeNet** — базовые свёртки + полносвязные слои (MNIST)
- **AlexNet** — глубже, ReLU, Dropout, ImageNet
- **VGG** — глубокая, однородные 3×3 свёртки
- **ResNet** — residual blocks (обходные соединения, борьба с затуханием градиента)
- **EfficientNet** — сбалансированная глубина/ширина/разрешение

---

### Принцип работы CNN

**1. Свёрточный слой (Convolution):**
- Фильтр $K \times K$ скользит по изображению
- Вычисляет скалярное произведение фильтра и участка изображения
- Результат — карта признаков (feature map)

**2. Функция активации:** ReLU ($f(x)=\max(0,x)$) — убирает отрицательные значения

**3. Пулинг (Pooling):**
- Max Pooling — берёт максимум в окне (уменьшает размерность)
- Устойчивость к сдвигам + уменьшение числа параметров

**4. Полносвязный слой (Fully Connected):**
- В конце сети (после свёрток и пулинга)
- Преобразует признаковое пространство в $C$ классов

**Архитектура:**
```
INPUT → [Conv → ReLU → Pool] × N → Flatten → FC → ReLU → FC → Softmax → OUTPUT
```

---

### Обучение нейронной сети с учителем

Дано: $\{(x_i, y_i)\}$ — изображения и метки классов.

**Функция ошибки (Loss):** Cross-Entropy:
$$\mathcal{L} = -\sum_{i=1}^C y_i \log(\hat{y}_i)$$
где $y_i$ — one-hot метка, $\hat{y}_i$ — предсказание.

**Алгоритмы оптимизации:**
- **SGD** — стохастический градиентный спуск (по мини-батчам)
- **Adam** — адаптивная скорость обучения (momentum + RMSProp)
- **RMSProp** — нормировка градиентов

**Смысл:** градиент ошибки по весам $\partial \mathcal{L}/\partial w$ распространяется обратно (backpropagation), веса обновляются: $w := w - \eta \nabla \mathcal{L}$.

---

### Последовательное vs пакетное обучение

| Параметр | Последовательное (Online) | Пакетное (Mini-batch) |
|---|---|---|
| Обновление | После каждого примера | После батча из $m$ примеров |
| Скорость | Нестабильная, шумная | Стабильная |
| Память | Мало | Средне ($m \times$ размер 1 примера) |
| Сходимость | Может застревать | Гладкая, быстрее |
| На практике | Не используется | Стандарт ($m=32,64,128,256$) |

**Batch (эпоха):** полный проход по всем обучающим данным.
**Iteration:** один шаг (один градиентный шаг по батчу).
