1. Подбор набора входных данных, влияющих на ожидаемы результат
2. Преобразование исходных данных с учётом характера и типа проблемы, отображаемой нейросетевой моделью и выбираются способы представления информации
3. Проектирование архитектуры нейронной сети, то есть числа слоев, числа нейронов в каждом слое и функции активации нейронов учитывающих характер решаемой задачи.
4. Обучение сети, то есть уточнением значений весовых коэффициентов связей на основе многократного прогона через сеть эталонных примеров

	Третий и четвёртый этап обычно производятся неоднократно и одновременно для уточнения параметров нейронной сети. Также есть два подхода: конструктивный и деструктивный.
	- В конструктивном обучение начинается на сети небольшого размера и постепенно увеличивается для достижения необходимой точности
	- В деструктивном создается сеть с избыточным количеством слоёв и нейронов, а после удаляются лишние без потери точности

5. На пятом этапе производится тестирование обученной сети на независимой выборке примеров.
