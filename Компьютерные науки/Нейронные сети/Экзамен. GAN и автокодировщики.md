# Экзамен. GAN и автокодировщики

## GAN (Generative Adversarial Network)

### Архитектура
- **Генератор G(z)**: шум z → фейковый образец
- **Дискриминатор D(x)**: образец → вероятность «настоящий»

### Минимаксная игра
$$\min_G \max_D \; \mathbb{E}[\log D(x)] + \mathbb{E}[\log(1 - D(G(z)))]$$

- G стремится **обмануть** D
- D стремится **отличить** настоящие от фейковых
- Идеал: D(G(z)) → 0.5 (D не может отличить)

### Проблемы обучения
- **Нестабильность** — D и G могут не сходиться
- **Mode collapse** — G генерирует ограниченное разнообразие
- Затухающий/взрывающий градиент

### Варианты GAN

| Модель | Особенность |
|--------|-------------|
| **DCGAN** | Свёрточные слои, стабильная архитектура |
| **Conditional GAN** | Дополнительная метка класса (y) для G и D |
| **CycleGAN** | Перенос стиля без парных данных (cyclic consistency) |
| **StyleGAN** | Управление стилем на разных уровнях детализации |

## Автокодировщики (Autoencoders)

### Базовая архитектура
- **Энкодер**: x → z (сжатое представление, bottleneck)
- **Декодер**: z → x̂ (реконструкция)
- Цель: **минимизировать** потерю реконструкции ||x − x̂||²

### Denoising Autoencoder (DAE)
- На вход подаётся **зашумлённый** x̃ = x + ε
- Обучается восстанавливать **чистый** x
- Заставляет модель выучивать **устойчивые** признаки

### VAE (Variational Autoencoder)
- Энкодер выдаёт **параметры** распределения (μ, σ)
- z сэмплируется: z = μ + σ · ε, ε ~ N(0,1)
- **Байесовский** подход: ELBO = реконструкция − KL-расхождение
- Генерация: берём случайный z из N(0,1) → декодер → новый образец

### Сравнение

| Тип | Обучение | Генерация | Качество |
|-----|----------|-----------|----------|
| GAN | Adversarial | z → G(z) | Высокое |
| VAE | ELBO максимизация | z ~ N(0,1) → decoder | Среднее (размытое) |
| DAE | Реконструкция | Нет (только очищение) | — |
