# Экзамен. Нейронные сети Хопфилда

## Определение

Сеть Хопфилда — **полностью связанная рекуррентная нейронная сеть** с симметричными весами (wᵢⱼ = wⱼᵢ) и нулевой диагональю (wᵢᵢ = 0). Используется как **ассоциативная память** для хранения и восстановления образцов.

## Энергетическая функция

$$E = -\frac{1}{2}\sum_{i \neq j} w_{ij} x_i x_j$$

- Энергия **монотонно убывает** при обновлении нейронов
- Сеть всегда сходится к **локальному минимуму** энергии
- Обученные паттерны correspond стабильным состояниям (минимумам E)

## Правило Хебба (обучение)

$$w_{ij} = \frac{1}{N}\sum_{p=1}^{P} \xi_i^p \xi_j^p$$

где P — число паттернов, N — число нейронов, ξ — компоненты паттернов (±1).

## Хранимость (ёмкость)

- **Порог Хопфилда**: максимум P ≈ **0.138N** паттернов
- При превышении — появляются **ложные стабильные состояния** (квазистабильные)
- Паттерны должны быть **ортогольны** (независимы) для надёжного хранения

## Процесс восстановления

1. Подать искажённый/неполный образ на вход
2. Итеративно обновлять состояния нейронов
3. Сеть сходится к **ближайшему** хранимому паттерну

## Ограничения

- Ограниченная ёмкость (0.138N)
- Появление ложных воспоминаний
- Нет чёткого разделения паттернов при большом P
- Только бинарные значения (±1 или 0/1)

## Применение

- Распознавание образов
- Восстановление данных по фрагментам
- Оптимизация комбинаторных задач
