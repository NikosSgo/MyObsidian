# Подготовка обучающих данных

## Этапы

### 1. Сбор данных
- Источники: базы данных, API, веб-скрапинг, файлы
- Важно: достаточный объём,代表性 (representativeness)

### 2. Очистка данных (Data Cleaning)
- Удаление дубликатов
- Обработка пропусков (NaN):
  - Удаление строк/столбцов
  - Заполнение: среднее, медиана, мода, KNN
  - Индикатор пропуска
- Исправление ошибок (выбросы, опечатки)
- Форматирование (даты, типы данных)

### 3. Feature Engineering (создание признаков)
- Кодирование категорий:
  - **One-hot encoding:** [красный, синий] → [1,0], [0,1]
  - **Label encoding:** красный → 0, синий → 1
  - **Target encoding:** среднее целевой по категории
- Извлечение признаков из текста, дат, координат
- Полиномиальные признаки (x², x₁·x₂)
- Бинаризация (пороговые значения)

### 4. Нормализация / Стандартизация

| Метод | Формула | Когда |
|-------|---------|-------|
| Min-Max | (x - min) / (max - min) | Данные [0, 1], нейросети |
| Z-score | (x - μ) / σ | Нормальное распределение |
| RobustScaler | (x - median) / IQR | Выбросы |

### 5. Разделение данных

| Набор | Доля | Назначение |
|-------|------|-----------|
| Train | 60–80% | Обучение модели |
| Validation | 10–20% | Настройка гиперпараметров |
| Test | 10–20% | Итоговая оценка |

### 6. Кросс-валидация (Cross-Validation)
- **K-Fold:** данные делятся на K частей, каждая используется как test
- Средняя метрика по K фолдам
- **Stratified K-Fold:** сохраняет пропорции классов
- Более надёжная оценка, чем однократное разделение

## Дисбаланс классов (Class Imbalance)

### Проблема
Класс A: 95% записей, класс B: 5% → модель предсказывает всегда A.

### Решения

#### Oversampling (увеличение миноритарного класса)
- **Random oversampling:** дублирование случайных записий
- **SMOTE:** синтетические примеры между ближайшими соседями
  - Выбирает k ближайших соседей
  - Генерирует новые точки на отрезках

#### Undersampling (уменьшение мажоритарного класса)
- **Random undersampling:** случайное удаление
- **Tomek Links:** удаление граничных точек
- **NearMiss:** выбор наиболее удалённых от миноритарного
