# Экзамен. Аугментация данных и Transfer Learning

## Аугментация данных

Искусственное **расширение** обучающей выборки для повышения обобщения.

### Основные приёмы

| Приём | Описание |
|-------|----------|
| **Повороты** | Случайный поворот изображения (±15–30°) |
| **Отражения** | Горизонтальное / вертикальное отражение |
| **Обрезка (cropping)** | Случайная обрезка с возвратом к исходному размеру |
| **Color jittering** | Изменение яркости, контраста, насыщенности |
| **Mixup** | Линейная комбинация двух изображений и их меток: $\tilde{x} = \lambda x_i + (1-\lambda)x_j$ |
| **Cutout** | Замаскировать случайный прямоугольный регион (нормировать нулями) |
| **Добавление шума** | Гауссов / соль-перец шум |

### Эффект
- Увеличивает **разнообразие** обучающих данных
- Снижает переобучение
- Повышает **robustness** модели

## Transfer Learning (Трансферное обучение)

Использование знаний модели, обученной на **другом** (большем) наборе данных.

### Подходы

**1. Извлечение признаков (Feature Extraction)**
- Замораживаются веса предобученной модели
- Обучается только **новый классификатор** (последний слой)
- Быстро, мало данных

**2. Тонкая настройка (Fine-tuning)**
- Размораживаются последние слои предобученной модели
- Обучение с **малой скоростью** (learning rate × 0.01–0.1)
- Лучший результат при **достаточном** объёме данных

### Предобученные модели (ImageNet)
- **ResNet** (152+ слоёв), **VGG** (16/19), **Inception**, **EfficientNet**
- Обучены на 1M+ изображений, 1000 классов

### Domain Adaptation (Адаптация домена)
- Проблема: распределение source и target доменов **различается**
- Методы: domain-adversarial training, коррекция распределения
- Без меток целевого домена — **unsupervised domain adaptation**

### Когда применять

| Сценарий | Подход |
|----------|--------|
| Мало данных, похожий домен | Feature extraction |
| Средне данных, похожий домен | Fine-tuning последних слоёв |
| Много данных, разный домен | Fine-tuning + domain adaptation |
