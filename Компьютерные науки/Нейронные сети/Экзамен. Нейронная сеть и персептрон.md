# Экзамен. Нейронная сеть и персептрон

## Искусственный нейрон

### Структура
$$y = f\left(\sum_{i=1}^{n} w_i x_i + b\right)$$

- $x_i$ — **входы** (признаки)
- $w_i$ — **веса** (степень влияния каждого входа)
- $b$ — **смещение** (bias) — сдвигает порог активации
- $f$ — **функция активации**

### Функции активации

| Функция | Формула | Градиент | Проблема |
|---------|---------|----------|----------|
| Sigmoid | $\sigma(z) = \frac{1}{1+e^{-z}}$ | $\sigma(1-\sigma)$ | Vanishing gradient |
| Tanh | $\tanh(z)$ | $1-\tanh^2(z)$ | Vanishing gradient |
| ReLU | $\max(0, z)$ | 0 или 1 | «Мёртвые» нейроны (z<0) |
| Leaky ReLU | $\max(\alpha z, z)$ | α или 1 | Малое α |
| Softmax | $\frac{e^{z_k}}{\sum e^{z_j}}$ | — | Только на выходе (классификация) |

## Персептрон (Perceptron)

### Однослойный персептрон
- Решает **линейно разделимые** задачи
- Алгоритм:
  1. Инициализация весов (случайно или нули)
  2. Для каждого примера: $\hat{y} = \text{sign}(w \cdot x + b)$
  3. Если ошибка: $w := w + \eta \cdot (y - \hat{y}) \cdot x$, $b := b + \eta(y-\hat{y})$
  4. Повторять до сходимости

### Теорема сходимости персептрона
- Если данные **линейно разделимы**, персептрон **гарантированно** найдёт решение за конечное число шагов
- **Не гарантирует** оптимальность решения
- Для линейно неразделимых данных **не сходится**

### Ограничения
- **XOR** — классическая задача, которую однослойный персептрон **не может** решить
- Доказательство: XOR не является линейно разделимым

## Многослойный персептрон (MLP)

### Архитектура
```
Входной слой → Скрытые слои → Выходной слой
```
- **Входной слой:** принимает признаки
- **Скрытые слои:** извлекают абстрактные представления (features)
- **Выходной слой:** предсказание (softmax для классификации)
- **Универсальный аппроксиматор:** MLP с одним скрытым слоем (достаточной ширины) может аппроксимировать любую непрерывную функцию

### Обратное распространение ошибки (Backpropagation)

1. **Forward pass:** вычислить $\hat{y}$ по всей сети
2. **Вычислить loss:** $L(y, \hat{y})$
3. **Backward pass** (цепное правило):
   - $\frac{\partial L}{\partial w^{(l)}} = \frac{\partial L}{\partial a^{(l)}} \cdot \frac{\partial a^{(l)}}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial w^{(l)}}$
4. **Обновить веса:** $w^{(l)} := w^{(l)} - \alpha \cdot \frac{\partial L}{\partial w^{(l)}}$

### Проблемы глубоких сетей
- **Vanishing gradient:** градиент экспоненциально убывает к первым слоям (сигмоиды)
- **Exploding gradient:** градиент экспоненциально растёт
- **Решения:** ReLU, Batch Normalization, ResNet skip-connections, инициализация He/Xavier

## Сравнение

| Модель | Скрытые слои | Нелинейность | XOR |
|--------|-------------|-------------|-----|
| Однослойный персептрон | 0 | Да (sign) | Нет |
| MLP | ≥1 | Да (ReLU, ...) | Да |
| Линейная регрессия | 0 | Нет | Нет |
