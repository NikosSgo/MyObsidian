# Экзамен. Обобщенно-регрессионная нейронная сеть (GRNN)

## Определение

**GRNN (General Regression Neural Network)** — регрессионный вариант PNN. Предсказывает **непрерывное значение** y для входного вектора x на основе ядерной оценки условного математического ожидания.

## Архитектура (4 слоя)

| Слой | Функция |
|------|---------|
| **Входной** | Вектор признаков x (без нейронов, просто передача) |
| **Паттернов** | Каждый нейрон = обучающий образец (xᵢ, yᵢ); вычисляет $G_i = K\left(\frac{\|x - x_i\|}{\sigma}\right)$ |
| **Суммирования** | **Числитель**: Σ Gᵢ · yᵢ ; **Знаменатель**: Σ Gᵢ |
| **Выходной** | $\hat{y} = \frac{\sum G_i \cdot y_i}{\sum G_i}$ — взвешенное среднее |

## Гауссово ядро

$$G_i = \exp\left(-\frac{\|x - x_i\|^2}{2\sigma^2}\right)$$

- **σ (сигма)** — параметр сглаживания
- Малое σ → сеть запоминает каждый образец (переобучение)
- Большое σ → сглаживание, потеря деталей (недообучение)

## Обучение

- **Однопроходное** — один проход по данным, веса определяются сразу
- Нет итерационной оптимизации (бэкпропагации)
- Параметр σ подбирается **перебором** (cross-validation)

## Преимущества

- **Однопроходное обучение** — быстрая конвергенция
- **Нет локальных минимумов** — гладкая регрессионная поверхность
- Аппроксимация приближается к **оптимальному** решению (при σ → 0 и N → ∞)
- Простая реализация и интерпретация

## Применение

- Прогнозирование временных рядов
- Аппроксимация функций
- Замена полиномиальной регрессии
