## Динамическое программирование

### Основные принципы
1. **Разделяй и властвуй:** разбить задачу на подзадачи
2. **Запоминание результатов:** сохранять решения подзадач (мемоизация)
3. **Использование результатов:** собирать решение из решений подзадач

### Отличие от жадных алгоритмов
- Жадные: принимают локально оптимальное решение на каждом шаге
- ДП: перебирают все варианты и выбирают лучший

### Пример: задача о рюкзаке
Даны предметы с весами $w_i$ и стоимостями $v_i$, рюкзак вместимостью $W$.

$$dp[i][j] = \max(dp[i-1][j], dp[i-1][j-w_i] + v_i)$$

### Пример: числа Фибоначчи
```python
def fib(n):
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

### Когда использовать ДП
- **Оптимизация:** найти максимум/минимум
- **Подсчёт:** количество способов
- **Наличие:** можно ли достичь цель

### Свойства задач ДП
1. **Оптимальная подструктура:** оптимальное решение содержит оптимальные решения подзадач
2. **Перекрывающиеся подзадачи:** одни и те же подзадачи решаются многократно
