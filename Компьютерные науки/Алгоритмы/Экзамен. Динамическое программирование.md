### Динамическое программирование (ДП)

**Определение:** метод решения задач, при котором задача разбивается на **перекрывающиеся подзадачи**, решения которых **запоминаются** (мемоизация) и используются повторно.

---

### Основные принципы

1. **Оптимальная подструктура** — оптимальное решение задачи содержит оптимальные решения подзадач.
2. **Перекрытие подзадач** — одни и те же подзадачи решаются многократно.
3. **Мемоизация (запоминание)** — сохраняем результаты подзадач, чтобы не пересчитывать.

**Отличие от «разделяй и властвуй»:** подзадачи не независимы — они перекрываются.

---

### Подходы

**Top-Down (сверху-вниз, мемоизация):**
```
function fib(n):
    if n <= 1: return n
    if memo[n] != -1: return memo[n]
    memo[n] = fib(n-1) + fib(n-2)
    return memo[n]
```

**Bottom-Up (снизу-вверх, таблица):**
```
function fib(n):
    dp[0] = 0, dp[1] = 1
    for i in 2..n:
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]
```

Обычно Bottom-Up эффективнее (нет рекурсивных вызовов).

---

### Пример задачи

**Задача о рюкзаке (0-1 Knapsack):** Даны $n$ предметов с весами $w_i$ и стоимостью $v_i$, рюкзак вместимостью $W$. Найти максимальную стоимость.

**Рекуррентность:**
$$
dp[i][w] = \max(dp[i-1][w],\; dp[i-1][w-w_i] + v_i)
$$
где $dp[i][w]$ — макс. стоимость для первых $i$ предметов при весе $\le w$.

**Bottom-Up:**
```
def knapsack(W, weights, values, n):
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(1, W+1):
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i-1][w], 
                               dp[i-1][w-weights[i-1]] + values[i-1])
            else:
                dp[i][w] = dp[i-1][w]
    return dp[n][W]
```

**Сложность:** $O(nW)$ — псевдополиномиальная.

---

### Когда использовать ДП

- Задача просит «найти минимум/максимум/количество способов»
- Есть рекуррентная зависимость
- Можно выделить состояние и переходы
- Классические задачи: редакционное расстояние (Левенштейн), задача о рюкзаке, числа Фибоначчи, задача о размене монет, наибольшая общая подпоследовательность (LCS), оптимальная стратегия игры
