### Эволюционные алгоритмы

**Общая схема** решения задачи оптимизации функции:

1. **Инициализация:** создать начальную популяцию особей (случайные решения).
2. **Оценка приспособленности:** вычислить целевую функцию для каждой особи.
3. **Селекция:** выбрать лучшие особи для размножения (пропорционально приспособленности).
4. **Скрещивание (кроссинговер):** создать потомков комбинацией генов родителей.
5. **Мутация:** случайно изменить гены потомков (с маленькой вероятностью).
6. **Формирование новой популяции:** отобрать особи в следующее поколение.
7. Повторять шаги 2-6 до выполнения критерия остановки.

```
Псевдокод:
population = init_random()
while not stop_condition():
    fitness = evaluate(population)
    parents = select(population, fitness)
    offspring = crossover(parents)
    offspring = mutate(offspring)
    population = survive(population, offspring)
return best(population)
```

**Применение:** оптимизация функций, обучение нейросетей (NEAT), задачи маршрутизации.

### Алгоритм искусственной иммунной системы

**Идея:** имитация адаптивной иммунной системы организма для решения задач оптимизации.

**Аналогия с биологией:**
- **Антитела** — возможные решения задачи
- **Антигены** — целевая функция (что нужно распознать/оптимизировать)
- **Аффинность** — степень соответствия решения задаче (аналог приспособленности)
- **Клонирование** — размножение лучших антител
- **Соматическая гипермутация** — мутация клонов (сильнее для низкой аффинности)

**Алгоритм CLONALG (клональный отбор):**

1. Инициализировать популяцию антител случайно
2. Для каждого антигена:
   - Вычислить аффинность всех антител
   - Выбрать $n$ лучших антител
   - Клонировать пропорционально аффинности (чем лучше — тем больше клонов)
   - Мутировать клоны (обратно пропорционально аффинности)
   - Заменить худшие антитела новыми клонами
3. Повторять до сходимости

**Отличие от генетического алгоритма:** нет скрещивания, механизм мутации зависит от качества решения (хорошие решения мутируют слабо, плохие — сильно). Также AIS использует **отрицательный отбор** — удаление антител, атакующих собственные клетки.

**Применение:** распознавание образов, кластеризация, задачи оптимизации, обнаружение аномалий.
