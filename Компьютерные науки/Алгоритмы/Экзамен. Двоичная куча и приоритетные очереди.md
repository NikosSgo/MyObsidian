## Двоичная куча

### Определение
**Двоичная куча** — двоичное дерево, где каждый узел больше (max-куча) или меньше (min-куча) своих потомков.

### Представление в массиве
Для узла с индексом $i$:
- Родитель: $(i-1)/2$
- Левый потомок: $2i + 1$
- Правый потомок: $2i + 2$

### Операции

**Вставка (push):**
1. Добавить элемент в конец массива
2. Просеять вверх (heapify up): сравнивать с родителем, менять местами

**Извлечение минимума/максимума (pop):**
1. Заменить корень последним элементом
2. Удалить последний элемент
3. Просеять вниз (heapify down): сравнивать с потомками, менять местами

### Сложность
- Вставка: $O(\log n)$
- Извлечение: $O(\log n)$
- Просмотр мин/макс: $O(1)$
- Построение кучи из массива: $O(n)$

### Приоритетная очередь
Куча — идеальная структура для приоритетной очереди:
- Вставка за $O(\log n)$
- Извлечение элемента с наивысшим приоритетом за $O(\log n)$

### Применение
- Сортировка кучей (heap sort) за $O(n \log n)$
- Пути в графах (алгоритм Дейкстры)
- Очереди задач с приоритетами
