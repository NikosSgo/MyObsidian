### Двоичная куча (Binary Heap)

**Бинарная куча** — полное бинарное дерево, где:
- **Min-heap:** значение в каждой вершине $\le$ значениям потомков (минимум в корне)
- **Max-heap:** значение в каждой вершине $\ge$ значениям потомков (максимум в корне)

**Хранение** в массиве: для элемента с индексом $i$:
- Левый потомок: $2i+1$
- Правый потомок: $2i+2$
- Родитель: $\lfloor (i-1)/2 \rfloor$

---

### Операции и сложность

| Операция | Сложность | Описание |
|---|---|---|
| `peek()` (посмотреть min/max) | $O(1)$ | Корень массива |
| `insert(x)` | $O(\log n)$ | Вставка в конец + `siftUp` |
| `extractMin()` / `extractMax()` | $O(\log n)$ | Удаление корня + `siftDown` |

**siftUp (просеивание вверх):** новый элемент сравнивается с родителем и меняется местами, если меньше (для min-heap).

**siftDown (просеивание вниз):** корень меняется с наименьшим потомком, пока свойство кучи не восстановится.

**heapify (построение кучи из массива):** $O(n)$ — применение siftDown к половине элементов.

---

### Приоритетная очередь

**Приоритетная очередь** — абстрактная структура данных, где элементы имеют приоритет. Бинарная куча — самая популярная реализация.

**Операции:**
- `push(element, priority)` — вставляет элемент
- `pop()` — извлекает элемент с наивысшим приоритетом
- `peek()` — смотрит элемент без извлечения

**Асимптотика:** те же $O(\log n)$ на вставку/извлечение.

---

### Пример задачи

**Задача:** Дан поток чисел, найти $k$ наибольших элементов (Top K).

**Решение:** поддерживаем min-heap размера $k$. Каждый новый элемент сравниваем с корнем: если больше — удаляем корень и вставляем новый.

```
function topK(stream, k):
    heap = MinHeap()
    for x in stream:
        if heap.size() < k:
            heap.push(x)
        elif x > heap.peek():
            heap.pop()
            heap.push(x)
    return heap
```

**Сложность:** $O(n \log k)$ — вместо $O(n \log n)$ при полной сортировке.

**Другие применения:**
- Алгоритм Дейкстры (поиск кратчайшего пути)
- Алгоритм A*
- Объединение $k$ отсортированных списков
- Планировщики задач ОС (Round Robin с приоритетами)
