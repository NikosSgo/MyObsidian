### Временная и емкостная сложность алгоритмов

**Временная сложность** $T(n)$ — количество элементарных операций, выполняемых алгоритмом на входе размера $n$.

**Емкостная сложность (память)** $M(n)$ — количество используемой памяти.

**Функция сложности** — $f: \mathbb{N} \to \mathbb{R}$, где $f(n)$ — время/память в худшем случае.

---

### Сложность данных

Одна и та же задача может иметь разную сложность для разных структур данных:

| Структура | Поиск | Вставка | Удаление |
|---|---|---|---|
| Массив | $O(n)$ | $O(n)$ | $O(n)$ |
| Связный список | $O(n)$ | $O(1)$ | $O(1)$ |
| Бинарное дерево поиска | $O(\log n)$ | $O(\log n)$ | $O(\log n)$ |
| Хеш-таблица | $O(1)$ ср. | $O(1)$ ср. | $O(1)$ ср. |

---

### Виды оценок

- **Минимальная (best case)** — $T_{\min}(n)$: лучший случай (неинформативен)
- **Максимальная (worst case)** — $T_{\max}(n)$: гарантированная верхняя граница
- **Средняя (average case)** — $T_{\text{avg}}(n)$: среднее по всем входам
- Обычно рассматривают **worst case** — даёт гарантию времени выполнения

### Анализ циклов

**Одиночный цикл for:**
```python
for i in range(n):     # n итераций
    O(1)               # каждая за O(1)
```
Сложность: $O(n)$

**Вложенные циклы:**
```python
for i in range(n):         # n
    for j in range(n):     # n
        O(1)
```
Сложность: $O(n^2)$

**Цикл с уменьшением шага:**
```python
i = n
while i > 0:
    O(1)
    i //= 2
```
Сложность: $O(\log n)$ — каждую итерацию $i$ делится на 2.

**Цикл while с неизвестным числом шагов:**
```python
while i < n:
    O(1)
    i += someComplexFunction()
```
Нужно анализировать, как меняется счётчик. Если каждую итерацию $i$ растёт на $1$ — $O(n)$.

**Repeat-until (do-while):** аналогично while — минимум одна итерация гарантирована.
