# Экзамен. Алгоритм Дейкстры

## Суть

Находит **кратчайший путь** от одной вершины ко всем остальным в **взвешенном графе** с неотрицательными весами рёбер.

## Принцип

Жадный подход: на каждом шаге выбираем непосещённую вершину с **минимальным расстоянием** и «релаксируем» её соседей.

## Алгоритм

```
Dijkstra(G, source):
    dist[v] = ∞ для всех v, dist[source] = 0
    Q = все вершины (приоритетная очередь по dist)

    while Q не пуста:
        u = extract_min(Q)           // вершина с мин. расстоянием
        for each v ∈ adj(u):
            if dist[u] + weight(u,v) < dist[v]:
                dist[v] = dist[u] + weight(u,v)
                prev[v] = u          // для восстановления пути
```

## Релаксация

Если путь через `u` короче текущего пути до `v`:
```
dist[v] = min(dist[v], dist[u] + w(u,v))
```

## Сложность

| Реализация | Сложность |
|------------|-----------|
| Матрица смежности (простой перебор) | O(V²) |
| Приоритетная очередь (binary heap) | O((V + E) log V) |
| Fibonacci heap | O(E + V log V) |

## Ограничение

**Запрещены отрицательные веса рёбер!** При наличии отрицательного ребра жадный принцип ломается — уже обработанная вершина может получить меньшее расстояние.

## Пример

Граф: A→B(1), A→C(4), B→C(2), B→D(6), C→D(3)

| Шаг | Посещённая | dist[A] | dist[B] | dist[C] | dist[D] |
|-----|------------|---------|---------|---------|---------|
| 0 | — | 0 | ∞ | ∞ | ∞ |
| 1 | A | 0 | 1 | 4 | ∞ |
| 2 | B | 0 | 1 | 3 | 7 |
| 3 | C | 0 | 1 | 3 | 6 |
| 4 | D | 0 | 1 | 3 | 6 |

Кратчайший путь A→D: A→B→C→D, вес = 6

## Восстановление пути

По массиву `prev` идём от целевой вершины к начальной:
```
D ← C ← B ← A  →  путь: A→B→C→D
```
