## Двоичный поиск

### Принцип работы
1. Взять средний элемент массива
2. Если искомое значение равно среднему — найдено
3. Если искомое значение меньше среднего — искать в левой половине
4. Если больше — в правой половине
5. Повторять, пока границы не сойдутся

### Реализация
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### Сложность
- **Время:** $O(\log n)$
- **Память:** $O(1)$ (итеративная версия)

### Ограничения
- Массив **должен быть отсортирован**
- Доступ по индексу за $O(1)$

### Применение
- Поиск в отсортированном массиве
- Поиск границы в монотонной последовательности
- Оптимизация перебора (бинарный поиск по ответу)
