### Двоичный (бинарный) поиск

**Алгоритм:** поиск элемента в **отсортированном** массиве. На каждом шаге сравниваем искомый элемент со средним элементом и отбрасываем половину массива.

```
function binarySearch(arr, target):
    left = 0, right = arr.length - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

**Сложность:** $O(\log n)$ — на каждом шаге размер поиска уменьшается вдвое.

---

### Пример задачи

**Задача:** Найти первое вхождение элемента в отсортированном массиве (нижняя граница).

```
function lowerBound(arr, target):
    left = 0, right = arr.length
    while left < right:
        mid = (left + right) // 2
        if arr[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

**Другие применения:**
- Поиск корня уравнения (вещественный бинпоиск)
- Поиск в массиве сдвигов (циклический сдвиг отсортированного массива)
- «Бинпоиск по ответу» — когда ответ монотонен (напр., минимальный размер контейнера для упаковки)

---

### Ограничения

1. **Массив должен быть отсортирован** — иначе алгоритм не работает.
2. **Случайный доступ к элементам** — нужна структура данных с $O(1)$ доступом по индексу (массив, а не связный список).
3. **Однородность данных** — на массивах с разным распределением может работать неэффективно.
4. **Для связанных списков** — бинарный поиск $O(n)$ (нет random access).
