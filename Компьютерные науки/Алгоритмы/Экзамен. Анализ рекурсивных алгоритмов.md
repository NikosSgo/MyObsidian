### Анализ сложности рекурсивных алгоритмов

#### Рекуррентные уравнения

Сложность рекурсивного алгоритма описывается рекуррентным уравнением.

**Пример (бинарный поиск):**
$$
T(n) = T(n/2) + O(1),\quad T(1) = O(1) \Rightarrow T(n) = O(\log n)
$$

**Пример (сортировка слиянием):**
$$
T(n) = 2T(n/2) + O(n),\quad T(1) = O(1) \Rightarrow T(n) = O(n\log n)
$$

---

### Линейная рекурсия

Один рекурсивный вызов на каждом шаге.

**Общий вид:** $T(n) = aT(n/b) + f(n)$

**Пример 1 — факториал:**
```python
def fact(n):
    if n <= 1: return 1
    return n * fact(n-1)
```
$T(n) = T(n-1) + O(1) \Rightarrow T(n) = O(n)$ — $n$ вызовов, каждый $O(1)$.

**Пример 2 — бинарный поиск:**
```python
def binarySearch(arr, l, r, x):
    if l > r: return -1
    mid = (l+r)//2
    if arr[mid] == x: return mid
    if arr[mid] < x: return binarySearch(arr, mid+1, r, x)
    return binarySearch(arr, l, mid-1, x)
```
$T(n) = T(n/2) + O(1) \Rightarrow T(n) = O(\log n)$

---

### Нелинейная рекурсия

Несколько рекурсивных вызовов на каждом шаге.

**Пример — числа Фибоначчи (наивно):**
```python
def fib(n):
    if n <= 1: return n
    return fib(n-1) + fib(n-2)
```
$T(n) = T(n-1) + T(n-2) + O(1) \Rightarrow T(n) = O(2^n)$ — экспоненциально!

**Пример — сортировка слиянием:**
```python
def mergeSort(arr):
    if len(arr) <= 1: return arr
    mid = len(arr)//2
    left = mergeSort(arr[:mid])
    right = mergeSort(arr[mid:])
    return merge(left, right)
```
$T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n\log n)$ — два вызова, но деление пополам.

---

### Основная теорема (Master Theorem)

Для $T(n) = aT(n/b) + f(n)$:

1. Если $f(n) = O(n^{\log_b a - \varepsilon})$, то $T(n) = \Theta(n^{\log_b a})$
2. Если $f(n) = \Theta(n^{\log_b a})$, то $T(n) = \Theta(n^{\log_b a}\log n)$
3. Если $f(n) = \Omega(n^{\log_b a + \varepsilon})$ и $af(n/b) \le cf(n)$, то $T(n) = \Theta(f(n))$

**Примеры:**
- MergeSort: $a=2, b=2, f(n)=n \Rightarrow \log_2 2 = 1 \Rightarrow$ case 2: $\Theta(n\log n)$
- BinarySearch: $a=1, b=2, f(n)=1 \Rightarrow \log_2 1 = 0 \Rightarrow$ case 2: $\Theta(\log n)$
- Наивные Фибоначчи: не применима ($b$ не константа)
