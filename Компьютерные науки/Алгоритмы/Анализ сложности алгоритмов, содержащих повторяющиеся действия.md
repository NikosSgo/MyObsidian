При анализе алгоритма с повторяющимися действиями необходимо определить:
- размер входных данных $n$;
- операцию, характеризующую основную работу алгоритма;
- количество выполнений тела цикла;
- сложность одной итерации;
- зависимость границ и шага цикла от $n$ и текущего состояния данных.

Если на итерации $i$ тело требует $C(i)$ операций, то общая сложность цикла выражается суммой:

$$
T(n)=\sum_{i=0}^{k(n)-1}C(i),
$$

где $k(n)$ — количество итераций. Если каждая итерация занимает $\Theta(1)$, сложность определяется только количеством повторений: $T(n)=\Theta(k(n))$.

При точном подсчёте учитывают:
- инициализацию переменной цикла — один раз;
- проверку условия — обычно на один раз больше количества выполнений тела;
- изменение переменной цикла — после каждой завершённой итерации;
- операции внутри тела.

Для асимптотической оценки эти постоянные различия обычно несущественны.

**Цикл `for`** применяется, когда последовательность значений управляющей переменной известна заранее.

```python
for i in range(n):
    process(i)
```

Тело выполняется $n$ раз. Если `process` имеет постоянную сложность, то:

$$
T(n)=\Theta(n).
$$

Если переменная изменяется с постоянным шагом $d>0$, количество итераций равно приблизительно $n/d$. Постоянный делитель не меняет порядок роста:

$$
T(n)=\Theta\left(\frac{n}{d}\right)=\Theta(n).
$$

Для последовательных циклов их сложности складываются:

```python
for i in range(n):
    process(i)

for j in range(n * n):
    process(j)
```

$$
T(n)=\Theta(n)+\Theta(n^2)=\Theta(n^2).
$$

Для вложенных независимых циклов количества итераций перемножаются:

```python
for i in range(n):
    for j in range(n):
        process(i, j)
```

$$
T(n)=n\cdot n=\Theta(n^2).
$$

Перемножать границы можно только тогда, когда число итераций внутреннего цикла одинаково для каждой внешней итерации. Если его граница зависит от внешнего счётчика, используется сумма:

```python
for i in range(n):
    for j in range(i):
        process(i, j)
```

$$
T(n)=\sum_{i=0}^{n-1}i
=\frac{n(n-1)}{2}
=\Theta(n^2).
$$

Если стоимость тела изменяется, также суммируют стоимости отдельных итераций. Например, при $C(i)=\Theta(i)$:

$$
T(n)=\sum_{i=1}^{n}\Theta(i)=\Theta(n^2).
$$

**Цикл `while`** выполняется, пока его условие истинно. Количество повторений обычно не записано явно, поэтому необходимо исследовать изменение переменных, входящих в условие.

```python
i = 0
while i < n:
    process(i)
    i += 1
```

Значение `i` увеличивается на единицу от $0$ до $n$, поэтому тело выполняется $n$ раз:

$$
T(n)=\Theta(n).
$$

Если управляющая величина изменяется на постоянное значение, число итераций линейно:

```python
x = n
while x > 0:
    x -= 3
```

$$
k(n)=\left\lceil\frac{n}{3}\right\rceil,
\qquad T(n)=\Theta(n).
$$

Если величина на каждой итерации умножается или делится на постоянное число, количество итераций логарифмическое:

```python
x = n
while x > 1:
    x //= 2
```

После $k$ итераций $x\approx n/2^k$. Цикл завершится при $n/2^k\leq1$, следовательно:

$$
k\geq\log_2 n,
\qquad T(n)=\Theta(\log n).
$$

Аналогично цикл, в котором счётчик принимает значения $1,2,4,8,\ldots$, имеет логарифмическое число итераций.

Для вложенных циклов разных типов применяется тот же принцип:

```python
for i in range(n):
    x = n
    while x > 1:
        process(i, x)
        x //= 2
```

Внешний цикл выполняется $n$ раз, внутренний — $\log_2 n$ раз для каждого значения `i`:

$$
T(n)=\Theta(n\log n).
$$

Если изменение управляющей переменной зависит от входных значений, точное число итераций заранее неизвестно. Тогда отдельно находят:
- минимальную оценку — для наиболее благоприятного входа;
- максимальную оценку — для наиболее неблагоприятного входа;
- среднюю оценку — при заданном распределении входных данных.

```python
i = 0
while i < n and data[i] != target:
    i += 1
```

Для последовательного поиска:
- лучший случай — $Theta(1)$;
- худший случай — $Theta(n)$;
- средний случай при равновероятном положении элемента — $Theta(n)$.

При анализе `while` также необходимо доказать завершение цикла. Для этого выделяют **вариант цикла** — неотрицательную величину, которая на каждой итерации строго уменьшается и не может уменьшаться бесконечно. Например, в цикле с `x -= 3` вариантом может служить $\max(x,0)$.

**Цикл `repeat...until`** проверяет условие после выполнения тела, поэтому тело выполняется хотя бы один раз:

```pascal
i := 0;
repeat
    process(i);
    i := i + 1;
until i >= n;
```

Для $n>0$ тело выполнится $n$ раз, поэтому $T(n)=\Theta(n)$. Если $n=0$, оно всё равно выполнится один раз.

Цикл `repeat...until condition` можно представить как:

```text
выполнить тело один раз
while condition ложно:
    повторить тело
```

Следовательно, методы анализа `repeat` и `while` одинаковы. Различие состоит в моменте проверки условия и гарантированной первой итерации. Это может изменить точное количество операций, но обычно не меняет асимптотическую сложность.

Основные методы анализа повторяющихся действий:
- **прямой подсчёт** — определить точное число итераций по границам и шагу;
- **суммирование** — записать сумму, если стоимость итерации или граница внутреннего цикла изменяется;
- **оценка сверху и снизу** — заменить сложную сумму более простыми границами;
- **исследование управляющей переменной** — определить, как быстро она приближается к условию завершения;
- **минимальный, средний и максимальный случаи** — применяются при зависимости числа повторений от данных;
- **экспериментальное измерение** — помогает проверить предположение, но не заменяет теоретического доказательства.

При наличии `break`, `continue` или нескольких условий завершения рассматривают все возможные пути выполнения. Для максимальной сложности выбирают путь с наибольшим числом итераций, для минимальной — с наименьшим.
