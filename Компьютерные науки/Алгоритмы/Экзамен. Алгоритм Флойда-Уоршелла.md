# Экзамен. Алгоритм Флойда-Уоршелла

## Суть

Находит **кратчайшие расстояния между всеми парами вершин** взвешенного ориентированного графа.

## Принцип

Динамическое программирование: последовательно рассматриваем промежуточные вершины и улучшаем путь.

## Алгоритм

```python
# dist[i][j] — расстояние от i до j
dist = матрица смежности (∞ = нет ребра, 0 на диагонали)

for k in range(V):          # промежуточная вершина
    for i in range(V):      # откуда
        for j in range(V):  # куда
            if dist[i][k] + dist[k][j] < dist[i][j]:
                dist[i][j] = dist[i][k] + dist[k][j]
```

**Ключевая идея:** после итерации `k` массив `dist[i][j]` содержит кратчайший путь из `i` в `j`, используя только вершины `{0, 1, ..., k}` как промежуточные.

## Сложность

**O(V³)** — три вложенных цикла по вершинам.

## Преимущества

- Работает с **отрицательными весами** (но без отрицательных циклов!)
- Простая реализация (3 цикла)
- Находит расстояния для **всех пар** вершин сразу

## Обнаружение отрицательных циклов

Если после завершения алгоритма на диагонали `dist[i][i] < 0` — существует отрицательный цикл, проходящий через вершину `i`.

## Восстановление пути

Используем матрицу `next[i][j]` — следующая вершина на пути из `i` в `j`:

```python
next = инициализация (next[i][j] = j если ребро i→j существует)

for k in range(V):
    for i in range(V):
        for j in range(V):
            if dist[i][k] + dist[k][j] < dist[i][j]:
                dist[i][j] = dist[i][k] + dist[k][j]
                next[i][j] = next[i][k]
```

Восстановление пути из `i` в `j`:
```
path = [i]
while i != j:
    i = next[i][j]
    path.append(i)
```

## Сравнение с алгоритмом Дейкстры

| Критерий | Флойд-Уоршелл | Дейкстра |
|----------|---------------|----------|
| Цель | Все пары | Одна вершина → все |
| Сложность | O(V³) | O((V+E) log V) |
| Отрицательные веса | ✓ | ✗ |
| Реализация | Простая | Сложнее |
