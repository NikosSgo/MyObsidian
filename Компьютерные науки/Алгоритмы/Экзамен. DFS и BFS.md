## DFS и BFS

### BFS (Breadth-First Search) — поиск в ширину
1. Пометить все вершины как непосещённые
2. Поставить начальную вершину в очередь
3. Извлечь вершину из очереди, посетить всех непосещённых соседей
4. Добавить их в очередь
5. Повторять до пустой очереди

**Сложность:** $O(V + E)$

**Применение:** кратчайший путь в невзвешенном графе, поиск в мазе, проверка связности

### DFS (Depth-First Search) — поиск в глубину
1. Пометить текущую вершину как посещённую
2. Для каждого непосещённого соседа — рекурсивно вызвать DFS
3. (Или использовать стек вместо рекурсии)

**Сложность:** $O(V + E)$

**Применение:** поиск циклов, топологическая сортировка, поиск компонент связности, проверка планарности

### Сравнение

| Критерий | BFS | DFS |
|----------|-----|-----|
| Структура данных | Очередь | Стек/рекурсия |
| Обход | По уровням | По ветвям |
| Кратчайший путь | Да (невзвешенный граф) | Нет |
| Память | $O(V)$ | $O(V)$ |

### Когда DFS предпочтительнее
- Нужно найти цикл или проверить связность
- Топологическая сортировка
- Глубина графа мала

### Когда BFS предпочтительнее
- Нужен кратчайший путь
- Граф широкий, но неглубокий
