### DFS (поиск в глубину)

**Идея:** идём «вглубь» от вершины, пока можем, затем возвращаемся.

**Реализация** (рекурсивно):
```
function dfs(v):
    visited[v] = true
    for u in graph[v]:
        if not visited[u]:
            dfs(u)
```

**Итеративно** (через стек):
```
function dfs(start):
    stack = [start]
    while stack:
        v = stack.pop()
        if not visited[v]:
            visited[v] = true
            for u in graph[v]:
                stack.push(u)
```

**Сложность:** $O(V + E)$ — каждая вершина и ребро посещаются один раз.

### BFS (поиск в ширину)

**Идея:** обход по уровням — сначала все соседи, потом соседи соседей и т.д.

**Реализация** (через очередь):
```
function bfs(start):
    queue = [start]
    visited[start] = true
    while queue:
        v = queue.pop(0)  # извлекаем первый
        for u in graph[v]:
            if not visited[u]:
                visited[u] = true
                queue.push(u)
```

**Сложность:** $O(V + E)$.

**Важно:** BFS находит **кратчайший путь** в невзвешенном графе.

---

### Сравнение

| Характеристика | DFS | BFS |
|---|---|---|
| Структура | Стек (LIFO) | Очередь (FIFO) |
| Память | $O(h)$, $h$ — глубина | $O(w)$, $w$ — ширина |
| Кратчайший путь | Нет | Да (в невзвешенном) |
| Обход | Вглубь | По уровням |

---

### Какие задачи решают

**DFS предпочтительнее:**
- Поиск циклов в графе
- Топологическая сортировка
- Компоненты сильной связности (алгоритм Косарайю)
- Задачи с backtracking (поиск всех путей)

**BFS предпочтительнее:**
- Кратчайший путь в невзвешенном графе
- Поиск в лабиринте (минимальное количество шагов)
- Проверка двудольности графа
- Алгоритм Прима/Kрускала (через приоритетную очередь — но это уже не чистый BFS)
