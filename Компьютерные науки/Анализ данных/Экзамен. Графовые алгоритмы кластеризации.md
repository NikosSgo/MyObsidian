# Экзамен. Графовые алгоритмы кластеризации

## Основная идея

Данные представляются как **граф**: объекты — узлы, схожесть — рёбра. Кластеризация сводится к разбиению графа на **сообщества** (плотные подграфы).

## Spectral Clustering (спектральная кластеризация)

### Алгоритм
1. Построить **матрицу схожести** ( affinity matrix ) W
2. Вычислить **матрицу лапласиана**: L = D − W (D — диагональная матрица степеней)
3. Найти **первые k собственных векторов** матрицы L
4. Провести **K-means** в пространстве собственных векторов

### Матрица лапласиана
- **Не нормализованный**: $L = D - W$
- **Нормализованный**: $L_{sym} = D^{-1/2}LD^{-1/2}$ или $L_{rw} = D^{-1}L$

### Преимущества
- Находит кластеры **любой формы** (не только сферические)
- Хорошо работает с **шумом**
- Связь с теорией графов (min-cut)

## Community Detection (обнаружение сообществ)

### Louvain Method

1. Каждый узел — отдельное сообщество
2. **Локальная оптимизация**: перемещение узла в сообщество с максимальным приростом **модулярности**
3. **Агрегация**: объединение сообществ в суперузлы
4. Повтор шагов 2–3 до сходимости

**Модулярность Q**:
$$Q = \frac{1}{2m}\sum_{ij}\left[A_{ij} - \frac{k_i k_j}{2m}\right]\delta(c_i, c_j)$$

- Q → 1: хорошая структура сообществ
- Q ≈ 0: случайное разбиение

**Сложность**: $O(n \log n)$ — очень быстрый

### Girvan-Newman Algorithm

1. Вычислить **centrality** (между--centrальность) всех рёбер
2. Удалить ребро с **наибольшей** центральностью
3. Пересчитать центральность
4. Повторять, пока граф не распадётся на компоненты

**Преимущество**: определяет **оптимальное число** кластеров
**Недостаток**: медленный — $O(m^2 n)$

## Graph Cuts (разрезы графа)

### Minimum Cut (минимальный разрез)
- Разбиение графа на 2 части с **минимальной суммой** весов удаляемых рёбер
- **Проблема**:倾向于 разбить на 1 узел и остальные

### Normalized Cut (нормализованный разрез)
$$Ncut(A, B) = \frac{cut(A, B)}{vol(A)} + \frac{cut(A, B)}{vol(B)}$$

- **vol(A)** — сумма степеней узлов в A
- Учитывает размер компонент → более **сбалансированные** разбиения
- Решается через **спектральный метод** (собственные векторы)

### Ratio Cut
$$RatioCut(A, B) = \frac{cut(A, B)}{|A|} + \frac{cut(A, B)}{|B|}$$

- Аналогично Ncut, но с учётом **числа** узлов вместо веса

## Преимущества графовых методов

| Преимущество | Описание |
|-------------|----------|
| **Любая форма кластеров** | Не требуют сферической формы |
| **Обнаружение сообществ** | Логическая структура графа |
| **Разреженные данные** | Граф естественно представляет sparse данные |
| **Визуализация** | Граф легко визуализировать |
| **Размерность** | Работают в spaces высокой размерности |

## Сравнение

| Алгоритм | Сложность | Число кластеров | Форма кластеров |
|----------|----------|-----------------|----------------|
| Spectral | $O(n^3)$ | Задаётся | Любая |
| Louvain | $O(n \log n)$ | Автоматически | Любая |
| Girvan-Newman | $O(m^2 n)$ | Автоматически | Любая |
| Normalized Cut | $O(n^3)$ | 2 (иерархически) | Любая |
