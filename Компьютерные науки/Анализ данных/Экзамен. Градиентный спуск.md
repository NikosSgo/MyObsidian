# Экзамен. Градиентный спуск

## Определение
Итеративный алгоритм **минимизации** функции стоимости путём движения в направлении **наибольшего убывания** (против градиента).

## Основы алгоритма

### Функция стоимости (Cost Function)
$J(\theta)$ — мера ошибки модели. Примеры:
- MSE (Mean Squared Error): $J(\theta) = \frac{1}{n}\sum(y_i - \hat{y}_i)^2$
- Cross-Entropy: $J(\theta) = -\frac{1}{n}\sum[y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$

### Правило обновления
$$\theta := \theta - \alpha \cdot \nabla_\theta J(\theta)$$

- $\alpha$ — **learning rate** (шаг обучения): слишком большой → расходимость, слишком малый → медленная сходимость
- $\nabla_\theta J(\theta)$ — градиент (вектор частных производных)

### Сходимость
- Градиент обращается в нуль → локальный/глобальный минимум
- Для выпуклых функций — гарантированный глобальный минимум
- Для невыпуклых — возможна застревание в локальном минимуме или седловой точке

---

## Варианты градиентного спуска

### Batch Gradient Descent
- Использует **все** данные для вычисления градиента на каждом шаге
- Стабильное сходимость, но **медленно** на больших датасетах
- Чёткий путь к минимуму (детерминированный)

### Stochastic Gradient Descent (SGD)
- Использует **один** случайный пример на каждом шаге
- Быстрое обновление, **шум** в градиенте
- Может «перепрыгнуть» локальный минимум (полезно для невыпуклых)
- Важно: уменьшать learning rate со временем

### Mini-batch Gradient Descent
- Компромисс: **батч** (32–256 примеров)
- Более стабильный градиент, чем SGD, быстрее batch
- **Де facto стандарт** в глубоком обучении

## Оптимизаторы ( momentum, adaptive LR )

### SGD with Momentum
$$v_t = \beta v_{t-1} + (1-\beta)\nabla J$$
$$\theta := \theta - \alpha v_t$$
- Сглаживает колебания, ускоряет движение вдоль рова

### AdaGrad
$$G_t = G_{t-1} + (\nabla J)^2$$
$$\theta := \theta - \frac{\alpha}{\sqrt{G_t + \epsilon}} \nabla J$$
- **Уменьшает LR** для часто обновляемых параметров
- Проблема: LR → 0 слишком быстро

### RMSProp
$$E_t = \beta E_{t-1} + (1-\beta)(\nabla J)^2$$
$$\theta := \theta - \frac{\alpha}{\sqrt{E_t + \epsilon}} \nabla J$$
- Использует **экспоненциальное скользящее среднее** вместо суммы
- Исправляет проблему AdaGrad

### Adam (Adaptive Moment Estimation)
$$m_t = \beta_1 m_{t-1} + (1-\beta_1)\nabla J \quad \text{(1st moment)}$$
$$v_t = \beta_2 v_{t-1} + (1-\beta_2)(\nabla J)^2 \quad \text{(2nd moment)}$$
- Коррекция смещения: $\hat{m}_t = m_t/(1-\beta_1^t)$
- **De facto стандарт** для глубоких сетей (β₁=0.9, β₂=0.999, ε=1e-8)

## Learning Rate Schedules

| Стратегия | Формула | Когда использовать |
|-----------|---------|-------------------|
| Step Decay | $\alpha = \alpha_0 \cdot 0.5^{epoch/k}$ | Умеренная фаза обучения |
| Cosine Annealing | $\alpha = \alpha_{min} + \frac{1}{2}(\alpha_{max}-\alpha_{min})(1+\cos(\pi t/T))$ | Современные архитектуры |
| Linear Warmup | $\alpha = \alpha_{max} \cdot t/T_{warmup}$ | Большие батчи, трансформеры |
| Exponential | $\alpha = \alpha_0 \cdot e^{-kt}$ | Постепенное затухание |
