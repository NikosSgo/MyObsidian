# Векторное представление текста

## Зачем нужно
Компьютеры работают с числами, не с текстом. Векторное представление — способ перевести слова/тексты в числовые векторы для ML-моделей.

## Bag of Words (BoW)

### Суть
- Словарь из всех уникальных слов корпуса
- Каждый документ — вектор длины = |словарь|
- Значение = количество вхождений слова (или 0/1)

### Пример
```
Документ 1: "кот ест рыбу"  → [1, 1, 1, 0]
Документ 2: "кот ест корм"  → [1, 1, 0, 1]
Словарь:     [кот, ест, рыба, корм]
```

### Плюсы/минусы
+ Простота, быстрота
- Потеря порядка слов
- Высокая разреженность
- Нет семантической близости

## TF-IDF

### Формула
- **TF** (Term Frequency) = freq(слово, док) / |док|
- **IDF** (Inverse Document Frequency) = log(N / df(слово))
- **TF-IDF = TF × IDF**

### Смысл
- Слово часто встречается в документе, но **редко** в корпусе → высокий вес
- Слово "и", "в" получают низкий вес

### Плюсы/минусы
+ Учитывает важность слова
- Всё ещё нет семантики
- Высокая размерность

## Word2Vec

### CBOW (Continuous Bag of Words)
- По **контексту** предсказывает **центральное слово**
- Вход: окружение, выход: слово
- Быстрее Skip-gram, лучше для частотных слов

### Skip-gram
- По **слову** предсказывает **контекст**
- Вход: слово, выход: окружение
- Лучше для редких слов и малых корпусов

### Архитектура
```
Вход → Embedding → Промежуточный слой (300D) → Выход
```
- Размерность: обычно 100–300
- Аналогия: "king - man + woman = queen"

### Плюсы/минусы
+ Учитывает семантику и контекст
+ Математические операции с векторами
- Не учитывает морфологию
- Одно слово → один вектор (полисемия)

## GloVe (Global Vectors)

### Суть
- Комбинация **статистики корпуса** и ** контекстных** методов
- Обучается на **матрице совместной встречаемости** (co-occurrence matrix)
- Цель: dot product векторов ≈ логарифм совместной встречаемости

### Плюсы/минусы
+ Использует глобальную статистику корпуса
+ Хорошая семантическая близость
- Матрица огромна по памяти

## Sentence Embeddings

| Метод | Описание |
|-------|----------|
| **Avg Word2Vec** | Среднее векторов слов |
| **TF-IDF weighted** | Взвешенное среднее по TF-IDF |
| **Doc2Vec (PV-DM)** | Вектор документа как отдельная сущность |
| **BERT sentence** | Контекстуальное представление предложения |

## Сравнение

| Метод | Семант. близость | Порядок слов | Сложность | Размерность |
|-------|------------------|--------------|-----------|-------------|
| BoW | Нет | Нет | Низкая | |Словарь| |
| TF-IDF | Частично | Нет | Низкая | |Словарь| |
| Word2Vec | Да | Нет | Средняя | 100–300 |
| GloVe | Да | Нет | Средняя | 50–300 |
| Sentence | Да | Да | Высокая | 768+ |
