# Экзамен. Обучение с учителем и без учителя

## Supervised Learning (обучение с учителем)

**Данные**: $X$ (признаки) + $y$ (метки/целевая переменная)
**Цель**: научиться предсказывать $y$ для новых $X$

### Классификация (дискретный результат)

| Алгоритм | Принцип | Плюсы | Минусы |
|----------|---------|-------|--------|
| **kNN** | Голосование K ближайших | Простой, без обучения | Медленный на больших данных |
| **SVM** | Максимальная разделяющая гиперплание | Хорош в высоких размерностях | Долго на больших данных |
| **Decision Tree** | Рекурсивное разбиение по признакам | Интерпретируемый | Склонен к переобучению |
| **Random Forest** | Ансамбль деревьев (bagging) | Точный, устойчивый | Менее интерпретируемый |
| **Naive Bayes** | Теорема Байеса (независимость признаков) | Быстрый, работает с малыми данными | Грубое предположение |

### Регрессия (непрерывный результат)

| Алгоритм | Формула | Когда использовать |
|----------|---------|-------------------|
| **Linear Regression** | $y = w_0 + w_1 x_1 + ... + w_n x_n$ | Линейная зависимость |
| **Polynomial Regression** | $y = w_0 + w_1 x + w_2 x^2 + ...$ | Нелинейная зависимость |
| **Ridge (L2)** | $J = \text{loss} + \alpha \sum w_i^2$ | Мультиколлинеарность |
| **Lasso (L1)** | $J = \text{loss} + \alpha \sum |w_i|$ | Отбор признаков |

## Unsupervised Learning (обучение без учителя)

**Данные**: только $X$ (без меток)
**Цель**: найти **структуру** в данных

### Кластеризация

| Алгоритм | Принцип | Плюсы | Минусы |
|----------|---------|-------|--------|
| **K-means** | Минимизация внутрикластерного расстояния | Быстрый, простой | Нужно задать K, сферические кластеры |
| **DBSCAN** | Плотность: ядро + окрестность | Не нужно задавать K, находит шум | Чувствителен к параметрам ε |
| **Иерархическая** | Агломеративная/дивизионная | Дендрограмма, не нужно K | Медленная $O(n^3)$ |

### Сравнение кластеризации

| Параметр | K-means | DBSCAN | Иерархическая |
|----------|---------|--------|---------------|
| Число кластеров | Задаётся | Находит автоматически | Задаётся порогом |
| Форма кластеров | Сферические | Любая | Зависит от метода |
| Шум | Назначает кластеру | Выделяет отдельно | Зависит от метода |
| Скорость | Быстрая $O(nk)$ | Средняя $O(n \log n)$ | Медленная $O(n^3)$ |

### Снижение размерности

| Алгоритм | Тип | Принцип |
|----------|-----|---------|
| **PCA** | Линейный | Максимальная дисперсия, собственные векторы |
| **t-SNE** | Нелинейный | Сохранение локальной структуры (вероятности) |
| **UMAP** | Нелинейный | Быстрее t-SNE, сохраняет глобальную структуру |

## Semi-supervised Learning

- Использует **мало** размеченных + **много** неразмеченных данных
- Пример: **Label Propagation** — распространение меток по графу схожести
- Когда разметка **дорогая** (медицинская диагностика)

## Self-supervised Learning

- Метки создаются **автоматически** из самих данных
- Пример: предсказание **следующего слова** (GPT), **маскированного токена** (BERT)
- Затем дообучение на downstream-задачах (transfer learning)

## Сравнение подходов

| Критерий | Supervised | Unsupervised | Semi-supervised |
|----------|-----------|--------------|-----------------|
| Метки | Обязательны | Не нужны | Малое количество |
| Оценка качества | Accuracy, F1, AUC | Silhouette, Davies-Bouldin | Зависит от задачи |
| Применение | Классификация, регрессия | Кластеризация, визуализация | Малые данные |
