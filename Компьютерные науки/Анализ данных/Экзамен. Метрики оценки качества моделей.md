# Экзамен. Метрики оценки качества моделей

## Метрики классификации

### Confusion Matrix (матрица ошибок)

|  | Предсказано: Да | Предсказано: Нет |
|--|-----------------|------------------|
| **Факт: Да** | TP (True Positive) | FN (False Negative) |
| **Факт: Нет** | FP (False Positive) | TN (True Negative) |

### Accuracy (точность)
$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$

- Доля **правильных** предсказаний
- **Проблема**: бесполезна при дисбалансе классов (90% одного класса → 90% accuracy «пустой» модели)

### Precision (точность предсказаний)
$$Precision = \frac{TP}{TP + FP}$$

- Из всех **предсказанных положительных** — сколько действительно положительных
- Важна когда **FP дороги** (спам-фильтр: не отправить важное письмо в спам)

### Recall (полнота)
$$Recall = \frac{TP}{TP + FN}$$

- Из всех **реально положительных** — сколько нашли
- Важна когда **FN дороги** (диагноз болезни: не пропустить больного)

### F1-score
$$F1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}$$

- **Гармоническое среднее** Precision и Recall
- Используется при **дисбалансе классов**

### AUC-ROC
- **ROC-кривая**: True Positive Rate (Recall) vs False Positive Rate
- **AUC** (Area Under Curve) — площадь под ROC-кривой
  - AUC = 1.0 — идеальная модель
  - AUC = 0.5 — случайное угадывание
  - AUC < 0.5 — модель хуже случайного

## Метрики регрессии

### MSE (Mean Squared Error)
$$MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2$$

- Среднеквадратичная ошибка
- **Штрафует** за большие ошибки (квадрат)

### RMSE (Root Mean Squared Error)
$$RMSE = \sqrt{MSE}$$

- В той же размерности, что и целевая переменная
- Интерпретируемее MSE

### MAE (Mean Absolute Error)
$$MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|$$

- Средняя абсолютная ошибка
- **Менее чувствителен** к выбросам, чем MSE

### R² (коэффициент детерминации)
$$R^2 = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

- Доля дисперсии, объяснённая моделью
  - R² = 1 — модель объясняет **всю** дисперсию
  - R² = 0 — модель **не лучше** среднего значения
  - R² < 0 — модель **хуже** среднего значения

## Метрики кластеризации

### Silhouette Score (Силуэт)
$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

- **a(i)** — среднее расстояние до объектов своего кластера
- **b(i)** — среднее расстояние до ближайшего другого кластера
- Значения: от **-1** (неправильное кластерирование) до **+1** (идеальное)
- **0** — на границе кластеров

### Davies-Bouldin Index
- Среднее отношение **внутрикластерного** расстояния к **межкластерному**
- **Меньше** → лучше кластеризация
- Минимум = 0 (не достичь на практике)

### Dunn Index
$$DI = \frac{\min_{i \neq j} d(C_i, C_j)}{\max_k diam(C_k)}$$

- Отношение **минимального межкластерного** расстояния к **максимальному внутрикластерному**
- **Больше** → лучше

## Таблица сравнения

| Задача | Метрика | Лучше когда |
|--------|---------|-------------|
| Классификация (баланс) | Accuracy | Классы сбалансированы |
| Классификация (дисбаланс) | F1, AUC-ROC | Один класс редок |
| Регрессия (выбросы) | MAE | Много выбросов |
| Регрессия (точность) | RMSE | Нужно штрафовать большие ошибки |
| Кластеризация | Silhouette | Оценка формы кластеров |
