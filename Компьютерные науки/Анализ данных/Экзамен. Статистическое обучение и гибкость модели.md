### Задача статистического обучения

Дано: $n$ наблюдений $\{(x_i, y_i)\}_{i=1}^n$, где $x_i \in \mathbb{R}^p$ — признаки, $y_i$ — целевая переменная.

**Цель:** найти функцию $f$, которая предсказывает $y$ по $x$:
$$y = f(x) + \varepsilon$$
где $\varepsilon$ — случайная ошибка (неустранимая).

**Формула разложения ошибки (Bias-Variance Tradeoff):**
$$\mathbb{E}[(y - \hat{f}(x))^2] = \underbrace{\text{Bias}[\hat{f}(x)]^2}_{\text{смещение}} + \underbrace{\text{Var}[\hat{f}(x)]}_{\text{разброс}} + \underbrace{\sigma^2}_{\text{шум}}$$

- **Bias** — ошибка из-за упрощающих предположений (модель слишком простая)
- **Variance** — ошибка из-за чувствительности к обучающим данным (модель слишком сложная)

---

### Выбор степени гибкости

**Гибкая модель** (высокая сложность): низкий bias, высокий variance (переобучение).
**Простая модель** (низкая сложность): высокий bias, низкий variance (недообучение).

**Методы регулировки гибкости:**
1. **Регуляризация (Ridge, Lasso, Elastic Net):** штраф за большие коэффициенты
   - Ridge: $\min ||y - X\beta||^2 + \lambda||\beta||^2$
   - Lasso: $\min ||y - X\beta||^2 + \lambda||\beta||_1$ — обнуляет коэффициенты
2. **Выбор числа признаков** — PCA, отбор (feature selection)
3. **Параметры модели** — глубина дерева, число слоёв сети, k в kNN
4. **Кросс-валидация** — k-fold CV для оценки обобщающей способности

**Процесс:**
```
Сложность → Ошибка на обучении ↓, Ошибка на тесте ↓ (до точки) ↑ (после)
                     ↑                   ↑
              недообучение          переобучение
```
Оптимальная сложность — минимум ошибки на тесте (валидации).
