# Экзамен. Обучение с подкреплением и ансамбли

## Reinforcement Learning (обучение с подкреплением)

Агент обучается через **взаимодействие** с средой, получая **награды/штрафы**.

### Ключевые понятия

| Понятие | Описание |
|---------|----------|
| **Agent** | Принимает решения |
| **Environment** | Среда, в которой действует агент |
| **State (S)** | Текущее состояние среды |
| **Action (A)** | Действие агента |
| **Reward (R)** | Награда за действие |
| **Policy (π)** | Стратегия: какое действие выбрать в состоянии S |
| **Discount factor (γ)** | Вес будущих наград (0–1) |

### Q-learning (метод без модели)

$$Q(S, A) \leftarrow Q(S, A) + \alpha \cdot [R + \gamma \cdot \max_{A'} Q(S', A') - Q(S, A)]$$

- **Off-policy**: политика жадная, но обучение учитывает exploration
- Не требует модели среды (model-free)
- Нужна **Q-таблица** (state × action) или **нейросеть** (DQN)

### SARSA (метод с моделью)

$$Q(S, A) \leftarrow Q(S, A) + \alpha \cdot [R + \gamma \cdot Q(S', A') - Q(S, A)]$$

- **On-policy**: использует ту же политику для выбора A'
- Более **осторожный** (conservative) — учитывает exploration
- Подходит для сред с **опасными** состояниями

### Сравнение Q-learning и SARSA

| Параметр | Q-learning | SARSA |
|----------|-----------|-------|
| Тип | Off-policy | On-policy |
| Выбор A' | $\arg\max Q(S',A')$ | Следующее действие политики |
| Риск | Может быть агрессивным | Более безопасный |
| Сходимость | Быстрее в безопасных средах | Медленнее, но стабильнее |

## Ensembles (ансамбли)

**Идея**: комбинация нескольких моделей даёт **лучший** результат.

### Bagging (Bootstrap Aggregating)

1. Бутстрап-выборки (с возвращением) из данных
2. Обучение **независимых** моделей
3. **Усреднение** (регрессия) или **голосование** (классификация)

**Random Forest** = Bagging + Decision Trees + случайный подпризнаков

- Уменьшает **дисперсию** (variance)
- Снижает **переобучение**

### Boosting (бустинг)

Модели обучаются **последовательно**, каждая исправляет ошибки предыдущей.

| Алгоритм | Особенности |
|----------|------------|
| **AdaBoost** | Увеличивает веса ошибочных объектов |
| **XGBoost** | Регуляризация, работа с пропусками, GPU |
| **LightGBM** | Быстрее XGBoost, histogram-based split, GOSS |
| **CatBoost** | Автоматическое кодирование категорий |

- Уменьшает **смещение** (bias)
- Хорош для **табличных** данных

### Stacking

1. Обучение **base-моделей** (разных алгоритмов)
2. **Мета-модель** обучается на предсказаниях base-моделей
- Комбинирует сильные стороны разных подходов
- Сложнее в реализации и отладке

## Bias-Variance Tradeoff в ансамблях

| Тип ошибки | Описание | Метод снижения |
|------------|----------|----------------|
| **Bias** (смещение) | Модель слишком простая | Boosting, увеличение сложности |
| **Variance** (дисперсия) | Модель слишком чувствительна к данным | Bagging, регуляризация |
| **Noise** (шум) | Неустранимая ошибка данных | Очистка данных |

$$\text{Total Error} = Bias^2 + Variance + Noise$$

### Влияние ансамблей

| Ансамбль | Bias | Variance | Скорость |
|----------|------|----------|----------|
| **Bagging** | Не меняется | **Снижает** | Параллельное обучение |
| **Boosting** | **Снижает** | Может увеличить | Последовательное |
| **Stacking** | **Снижает** | **Снижает** | Медленное |

## Сравнение ансамблей

| Критерий | Bagging | Boosting | Stacking |
|----------|---------|----------|----------|
| Параллелизм | Да | Нет | Частично |
| Переобучение | Устойчив | Устойчив (с регуляризацией) | Риск |
| Точность | Хорошая | Высокая | Очень высокая |
| Интерпретируемость | Низкая | Средняя | Низкая |
| Скорость предсказания | Быстрая | Быстрая | Медленная |
