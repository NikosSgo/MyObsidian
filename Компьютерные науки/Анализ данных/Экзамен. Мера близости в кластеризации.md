# Экзамен. Мера близости в кластеризации

## Метрики расстояния (числовые данные)

### Евклидово расстояние
$$d(x, y) = \sqrt{\sum_{i=1}^{n}(x_i - y_i)^2}$$

- Самая распространённая метрика
- **Чувствительно** к масштабу признаков
- Хорошо работает при **сферических** кластерах
- Проблемы в **высоких** размерностях (проклятие размерности)

### Манхэттенское расстояние (L1)
$$d(x, y) = \sum_{i=1}^{n}|x_i - y_i|$$

- Расстояние по «кварталам» (только горизонтально/вертикально)
- **Менее чувствительно** к выбросам
- Лучше для **разреженных** данных (тексты, рекомендательные системы)
- Используется в Lasso-регрессии

### Чебышёвское расстояние (L∞)
$$d(x, y) = \max_i|x_i - y_i|$$

- Максимальная разница по **любому** из измерений
- Применение: логистика (склад, транспорт — расстояние по самому долгому маршруту)

### Расстояние Махаланобиса
$$d(x, y) = \sqrt{(x - y)^T S^{-1} (x - y)}$$

- Учитывает **корреляции** между признаками
- **S** — ковариационная матрица
- Эквивалентно евклидову в **ортогонализированном** пространстве
- Лучше при **коррелированных** признаках

## Метрики подобия (множества, тексты)

### Косинусное сходство
$$\cos(\theta) = \frac{x \cdot y}{\|x\| \cdot \|y\|}$$

- Измеряет **угол** между векторами (не расстояние!)
- Значения: **-1** (противоположные) → **0** (ортогональные) → **+1** (идентичные)
- **Не зависит** от длины вектора
- Широко в **NLP**, рекомендательных системах, TF-IDF

### Индекс Жаккара
$$J(A, B) = \frac{|A \cap B|}{|A \cup B|}$$

- Отношение **пересечения** к **объединению** множеств
- Значения: **0** (нет общего) → **1** (идентичны)
- Применение: бинарные данные, подобие документов (мешок слов)

## Когда какую метрику использовать

| Метрика | Тип данных | Когда использовать |
|---------|-----------|-------------------|
| **Евклидова** | Числовые, сбалансированные | Кластеры сферические, малая размерность |
| **Манхэттен** | Числовые, разреженные | Выбросы, рекомендательные системы |
| **Чебышёва** | Числовые | Важен худший/лучший признак |
| **Махаланобис** | Числовые, коррелированные | Мультиколлинеарность |
| **Косинусное** | Тексты, векторы | NLP, TF-IDF, документы |
| **Жаккар** | Бинарные/категориальные | Множества, бинарные данные |

## Влияние метрики на кластеризацию

- **Евклидова** → кластеры могут быть неправильной формы (вытянутые)
- **Косинусное** → игнорирует длину, фокусируется на направлении
- **Махаланобис** → корректно обрабатывает корреляции
- Разная метрика может давать **принципиально разные** кластеры

## Стандартизация

Перед использованием метрик расстояния **обязательно** нормализовать данные:
- **Z-score** (стандартизация): $(x - \mu) / \sigma$
- **Min-Max** (нормализация): $(x - min) / (max - min)$

Без этого признаки с **большим масштабом** будут доминировать.
