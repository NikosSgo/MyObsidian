# Экзамен. Линейная и полиномиальная регрессия

## Линейная регрессия

### Простая линейная регрессия
Модель: $\hat{y} = \beta_0 + \beta_1 x$

Метод **наименьших квадратов (OLS)** — минимизация $J(\beta_0, \beta_1) = \sum(y_i - \hat{y}_i)^2$:

$$\beta_1 = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sum(x_i - \bar{x})^2}, \quad \beta_0 = \bar{y} - \beta_1\bar{x}$$

### Множественная линейная регрессия
Модель: $\hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + ... + \beta_n x_n$

Матричная форма: $\hat{y} = X\beta$

Решение: $\beta = (X^TX)^{-1}X^Ty$

### Коэффициент детерминации R²
$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

- R² = 1 — идеальное предсказание
- R² = 0 — модель не лучше среднего
- R² < 0 — модель хуже среднего

**Adjusted R²** — штрафует за лишние признаки:
$$R^2_{adj} = 1 - \frac{(1-R^2)(n-1)}{n-p-1}$$

## Полиномиальная регрессия

### Модель
$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 + ... + \beta_d x^d$

- Это **линейная регрессия** по полиномиальным признакам
- Параметры линейны → OLS применим

### Выбор степени полинома d
- **Низкая степень** → **недообучение** (underfitting, high bias)
- **Высокая степень** → **переобучение** (overfitting, high variance)
- Используйте кросс-валидацию для выбора оптимальной степени

### Признаки переобучения
- R² на train ≈ 1, R² на test ≈ 0
- Большие по модулю коэффициенты β
- Кривая «подстраивается» под каждый点

## Регуляризация

### Ridge Regression (L2)
$$J(\beta) = \sum(y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{p} \beta_j^2$$
- Штрафует **квадраты** коэффициентов → уменьшает их, но **не обнуляет**
- Решение: $\beta = (X^TX + \lambda I)^{-1}X^Ty$
- Хорошо при мультиколлинеарности

### Lasso Regression (L1)
$$J(\beta) = \sum(y_i - \hat{y}_i)^2 + \lambda \sum_{j=1}^{p} |\beta_j|$$
- Штрафует **модули** коэффициентов → **обнуляет незначимые** признаки
- Автоматический **отбор признаков**
- Проблема: при группе коррелированных признаков выбирает один

### Elastic Net
$$J(\beta) = \sum(y_i - \hat{y}_i)^2 + \lambda_1 \sum|\beta_j| + \lambda_2 \sum\beta_j^2$$
- Комбинация L1 и L2
- Гиперпараметр `l1_ratio` (α): α=1 → Lasso, α=0 → Ridge

### Сравнение регуляризаций

| Метод | L1 (Lasso) | L2 (Ridge) | Elastic Net |
|-------|-----------|-----------|-------------|
| Обнуление признаков | Да | Нет | Да |
| Групповой эффект | Нет | Да | Да |
| Мультиколлинеарность | Одна переменная | Все | Группа |
| Использование | Отбор признаков | Штраф large β | Баланс |
