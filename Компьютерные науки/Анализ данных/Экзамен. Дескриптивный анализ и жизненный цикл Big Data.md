### Основные понятия статистики

**Генеральная совокупность** — всё множество объектов исследования.
**Выборка** — часть генеральной совокупности, непосредственно исследуемая.

**Требования к выборке:** репрезентативность (отражает свойства генеральной совокупности), случайность.

---

### Меры центральной тенденции

| Мера | Описание | Когда использовать |
|---|---|---|
| **Среднее (Mean)** | $\bar{x} = \frac{1}{n}\sum x_i$ | Нормальное распределение, нет выбросов |
| **Медиана** | Средний элемент упорядоченного ряда | Выбросы, асимметричное распределение |
| **Мода** | Наиболее частое значение | Категориальные данные, пики |

**Сравнительный анализ:**
- Среднее чувствительно к выбросам
- Медиана устойчива к выбросам
- Мода — единственная мера для номинальных данных

**Дополнительные меры:**
- **Дисперсия:** $\sigma^2 = \frac{1}{n}\sum(x_i - \bar{x})^2$
- **Стандартное отклонение:** $\sigma = \sqrt{\sigma^2}$
- **Квартили:** Q1 (25%), Q2 (50% = медиана), Q3 (75%)
- **Интерквартильный размах (IQR):** Q3 - Q1

### Жизненный цикл Big Data

**Стандарты:** CRISP-DM, SEMMA.

**CRISP-DM (Cross-Industry Standard Process for Data Mining):**
```
1. Business Understanding  — понимание бизнес-задачи
2. Data Understanding      — сбор, описание, проверка данных
3. Data Preparation        — очистка, трансформация, конструирование признаков
4. Modeling                — построение модели (ML/DM)
5. Evaluation              — оценка качества модели
6. Deployment              — внедрение в производство
```

### Классификация методов Data Mining

| Категория | Методы | Задачи |
|---|---|---|
| **Классификация** | Деревья решений, SVM, kNN, логистическая регрессия | Отнесение к категории |
| **Кластеризация** | K-means, DBSCAN, иерархическая | Группировка без меток |
| **Регрессия** | Линейная, полиномиальная, Lasso/Ridge | Прогноз числового значения |
| **Ассоциативные правила** | Apriori, FP-Growth | Поиск часто встречаемых наборов |
| **Понижение размерности** | PCA, t-SNE | Уменьшение числа признаков |
| **Обнаружение аномалий** | Isolation Forest, LOF | Поиск выбросов |
