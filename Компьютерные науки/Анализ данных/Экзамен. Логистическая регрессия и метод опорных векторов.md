# Экзамен. Логистическая регрессия и метод опорных векторов

## Логистическая регрессия

### Модель
Преобразует линейную комбинацию признаков в **вероятность** [0, 1]:

$$P(y=1|x) = \sigma(z) = \frac{1}{1 + e^{-z}}, \quad z = w^Tx + b$$

### Сигмоидная функция
- $\sigma(z) \in (0, 1)$, монотонно возрастает
- $\sigma'(z) = \sigma(z)(1 - \sigma(z))$
- Порог 0.5: если $z > 0$ → класс 1, иначе → класс 0

### Функция потерь (Binary Cross-Entropy)
$$J(w,b) = -\frac{1}{n}\sum[y_i\log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)]$$

Градиент: $\frac{\partial J}{\partial w} = \frac{1}{n}X^T(\hat{y} - y)$ — линейный, оптимизация аналогична OLS

### Мультиклассовая классификация

**One-vs-Rest (OvR):**
- Обучаем K моделей: каждая против «остальных»
- Предсказание: класс с наибольшей вероятностью
- Простое, но может быть несогласованность

**Softmax-регрессия:**
$$P(y=k|x) = \frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}$$
- Обобщение сигмоиды на K классов (множественная регрессия)
- Сумма вероятностей = 1

## Метод опорных векторов (SVM)

### Основная идея
Найти **разделяющую гиперплоскость** с **максимальным зазором (margin)** между классами.

### Ключевые понятия

- **Гиперплоскость:** $w^Tx + b = 0$
- **Margin:** расстояние от гиперплоскости до ближайших точек → $\frac{2}{||w||}$
- **Support Vectors:** ближайшие точки обоих классов, определяющие гиперплоскость
- Оптимизация: $\min \frac{1}{2}||w||^2$ при условии $y_i(w^Tx_i + b) \geq 1$

### Soft Margin SVM
- Для данных **не линейно разделимых** (шум, выбросы)
- Вводит **slack variables** $\xi_i \geq 0$:
$$\min \frac{1}{2}||w||^2 + C\sum_{i=1}^{n}\xi_i$$
  при $y_i(w^Tx_i + b) \geq 1 - \xi_i$
- **C** — компромисс: большой C → жёсткий.margin (переобучение), малый C → мягкий margin

### Kernel Trick

Преобразование в **пространство более высокой размерности** без явного вычисления:

$$K(x_i, x_j) = \phi(x_i)^T\phi(x_j)$$

| Ядро | Формула | Когда использовать |
|------|---------|-------------------|
| **Linear** | $K(x,y) = x^Ty$ | Линейно разделимые данные |
| **Polynomial** | $K(x,y) = (\gamma x^Ty + r)^d$ | Полиномиальная граница |
| **RBF (Gaussian)** | $K(x,y) = e^{-\gamma\|\|x-y\|\|^2}$ | Нелинейные границы, де facto стандарт |
| **Sigmoid** | $K(x,y) = \tanh(\gamma x^Ty + r)$ | Нейронные сети-подобные |

- γ в RBF контролирует «влияние» одной точки: большое γ → переобучение

### SVM vs Логистическая регрессия

| Критерий | SVM | Логистическая регрессия |
|----------|-----|------------------------|
| Оптимизация | Максимизация margin | Максимизация правдоподобия |
| Опорные векторы | Только ближайшие точки | Все точки |
| Ядра | Да (kernel trick) | Нет (нелинейность через признаки) |
| Интерпретируемость | Низкая | Выская (вероятности) |
| Масштабируемость | O(n²) – O(n³) | O(n) |
