### Классификация

**Задача:** отнести объект к одному из заранее известных классов (обучение с учителем).

**Принцип работы:** по обучающей выборке с метками классов строится правило (модель), которое предсказывает класс для новых объектов.

**Алгоритмы:**
- **Логистическая регрессия** — линейная граница, вероятностный выход
- **Деревья решений (CART, C4.5)** — пороговые правила на признаках
- **Метод опорных векторов (SVM)** — максимизация отступа между классами
- **kNN (k-ближайших соседей)** — голосование ближайших точек
- **Случайный лес (Random Forest)** — ансамбль деревьев
- **Градиентный бустинг (XGBoost, LightGBM)** — последовательные деревья

### Кластеризация

**Задача:** разбить объекты на группы (кластеры) без предварительных меток (обучение без учителя).

**Принцип работы:** объекты внутри одного кластера максимально похожи, объекты из разных кластеров — максимально различны.

**Алгоритмы:**
- **K-means** — минимизация внутрикластерной суммы квадратов
- **DBSCAN** — кластеризация по плотности (находит кластеры произвольной формы)
- **Иерархическая (AGNES, DIANA)** — дендрограмма слияния/разделения
- **Gaussian Mixture Models (GMM)** — вероятностная кластеризация

### Корреляция

**Корреляция** — мера взаимосвязи двух переменных.

**Коэффициент корреляции Пирсона:**
$$r = \frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum(x_i - \bar{x})^2 \sum(y_i - \bar{y})^2}}$$

- $r \in [-1, 1]$: 1 — полная положительная, -1 — полная отрицательная, 0 — нет линейной связи

**Ограничение:** корреляция ≠ причинность.

### Регрессия

**Задача:** предсказание числового значения по признакам.

**Линейная регрессия:**
$$y = \beta_0 + \beta_1 x_1 + \dots + \beta_n x_n + \varepsilon$$

Оценка параметров — метод наименьших квадратов (MSE):
$$\min_{\beta} \sum(y_i - \hat{y}_i)^2$$

**Применение в Data Mining:**
- Классификация: логистическая регрессия (через sigmoid)
- Корреляция: выявление значимых признаков (коэффициенты $\beta$)
- Прогнозирование: временные ряды, тренды
