# Экзамен. Методы очистки данных

## Пропущенные значения (Missing Values)

### Причины пропусков
- Ошибки ввода, сбои систем, отказ от ответа
- **MCAR** (Missing Completely At Random) — случайные, не связаны ни с чем
- **MAR** (Missing At Random) — связаны с другими признаками
- **MNAR** (Missing Not At Random) — связаны со значением переменной

### Методы обработки

| Метод | Описание | Когда использовать |
|-------|----------|-------------------|
| **Удаление строк** | `dropna()` | Пропусков < 5%, MCAR |
| **Удаление столбцов** | Удалить признак целиком | > 50% пропусков в столбце |
| **Среднее (mean)** | Замена на среднее | Числовые, без выбросов |
| **Медиана (median)** | Замена на медиану | Числовые, с выбросами |
| **Мода (mode)** | Замена на самое частое | Категориальные |
| **KNN-imputation** | Замена на среднее K ближайших | Точные данные, есть корреляции |
| **Интерполяция** | Линейная/полиномиальная | Временные ряды |

## Выбросы (Outliers)

### Метод Z-score
$$Z = \frac{x - \mu}{\sigma}$$

- Если $|Z| > 3$ → выброс (99.7% данных в ±3σ)
- **Проблема**: сам μ и σ чувствительны к выбросам

### Метод IQR (Interquartile Range)
$$IQR = Q_3 - Q_1$$
$$\text{Выбросы}: x < Q_1 - 1.5 \cdot IQR \;\text{или}\; x > Q_3 + 1.5 \cdot IQR$$

- **Более устойчив** чем Z-score
- Не зависит от распределения

### Isolation Forest
- Ансамбль деревьев, каждое **изолирует** случайный объект
- Выбросы изолируются за **меньшее число** разделений
- Хорошо работает в **высоких** размерностях

### Методы обработки выбросов
- **Удаление** (если < 1% данных)
- **Замена** на медиану/квинтили
- **Винсоризация**: замена на границы (1% и 99%)
- **Логарифмическое преобразование**: $\log(x+1)$

## Дубликаты

| Тип | Описание | Метод |
|-----|----------|-------|
| **Полные** | Идентичные строки | `df.drop_duplicates()` |
| **Частичные** | Совпадают ключевые поля | Группировка + проверка |

## Стандартизация и нормализация

### Z-score (стандартизация)
$$z = \frac{x - \mu}{\sigma}$$

- Среднее = 0, стандартное отклонение = 1
- Не привязан к диапазону
- Хорошо для **нормального** распределения

### Min-Max (нормализация)
$$x' = \frac{x - x_{min}}{x_{max} - x_{min}}$$

- Диапазон **[0, 1]**
- **Чувствителен** к выбросам
- Хорош для нейросетей (активации 0–1)

### Когда что использовать

| Метод | Когда использовать |
|-------|-------------------|
| **Z-score** | SVM, KNN, K-means, линейные модели |
| **Min-Max** | Нейросети, когда нужен фиксированный диапазон |
| **Без преобразования** | Деревья решений, Random Forest |

## Кодирование категориальных переменных

### One-Hot Encoding
- Каждая категория → отдельный **бинарный** столбец
- `Цвет: [красный, синий]` → `Цвет_красный: [1,0]`, `Цвет_синий: [0,1]`
- **Проблема**: много категорий → разреженность (one-hot curse)

### Label Encoding
- Каждая категория → **число**: `красный=0`, `синий=1`
- Просто, но создаёт **ложный порядок** (красный < синий?)
- Подходит для **порядковых** категорий (низкий/средний/высокий)

### Сравнение

| Метод | Порядок | Размерность | Пример |
|-------|---------|-------------|--------|
| **One-Hot** | Нет | Увеличивает | Номинальные: цвет, город |
| **Label** | Да (создаёт) | Не меняет | Порядковые: оценка |
| **Target Encoding** | Нет | Не меняет | Высокая кардинальность |
