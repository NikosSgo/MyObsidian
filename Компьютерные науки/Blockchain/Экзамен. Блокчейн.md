### Блокчейн

**Блокчейн** — распределённая база данных, состоящая из цепочки блоков, где каждый блок связан с предыдущим криптографически.

**Элементы:**
- **Блок** — содержит заголовок (previous hash, timestamp, nonce, merkle root) + тело (список транзакций)
- **Транзакция** — перевод ценности/данных между адресами
- **Хеш** — криптографическая ссылка на предыдущий блок (SHA-256)

**Схема:**
```
[Genesis] ← [Block 1] ← [Block 2] ← ... ← [Block N]
  hash: 0x...    hash: ...     hash: ...
```

---

### Смарт-контракты

**Смарт-контракт** — программа, хранящаяся и исполняемая на блокчейне. Автоматически выполняет условия контракта.
- *Пример (Ethereum):* Solidity-код, развёрнутый в EVM (Ethereum Virtual Machine)
- Неизменяем (после развёртывания)
- Прозрачен (код виден всем)

---

### Майнинг и консенсус

**Майнинг** — процесс создания новых блоков путём решения сложной вычислительной задачи (PoW).

**Виды консенсуса:**

| Алгоритм | Суть | Плюсы | Минусы |
|---|---|---|---|
| **PoW (Proof of Work)** | Решение криптозадачи (найти nonce: `hash(block) < target`) | Безопасен, проверен | Энергозатратный |
| **PoS (Proof of Stake)** | Валидатор выбирается по размеру доли (stake) | Энергоэффективен | «Богатые богатеют» |
| **DPoS (Delegated PoS)** | Голосование за делегатов, они подтверждают блоки | Быстрый | Частичная централизация |
| **PBFT (Practical Byzantine Fault Tolerance)** | Согласование через раунды голосования | Быстрый, финальный | Не масштабируется (>20 узлов) |

**Состав блокчейн-системы:**
```
Приложения (DApps)
    ↕
Смарт-контракты
    ↕
Виртуальная машина (EVM)
    ↕
Консенсус (PoW/PoS)
    ↕
P2P Сеть (узлы-валидаторы)
```
