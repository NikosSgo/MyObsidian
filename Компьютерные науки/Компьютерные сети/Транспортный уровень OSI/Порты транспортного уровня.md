**Порт** — 16-битный номер от `0` до `65535`, который указывает процесс или службу на устройстве.

Один IP-адрес обслуживает много программ одновременно:

```text
192.168.1.10:443  → веб-сервер HTTPS
192.168.1.10:53   → DNS-сервер
192.168.1.10:22   → SSH-сервер
```

Каждый TCP- или UDP-заголовок содержит:
- **Source Port** — порт отправляющего приложения;
- **Destination Port** — порт службы получателя.

Пара `IP-адрес:порт` называется **сокетом**. TCP-соединение однозначно задаётся четырьмя значениями:

```text
IP клиента : порт клиента  →  IP сервера : порт сервера
```

Например, несколько вкладок могут одновременно обращаться к `203.0.113.10:443`: у них будут разные временные порты клиента, поэтому ОС не перепутает ответы.

## Диапазоны портов

- `0–1023` — well-known ports: стандартные службы, например HTTP `80`, HTTPS `443`, DNS `53`.
- `1024–49151` — зарегистрированные порты приложений.
- `49152–65535` — динамические/эфемерные порты; ОС обычно выдаёт их клиентским приложениям временно.

Номер порта сам по себе не является защитой: доступ ограничивают firewall, правила ОС и само приложение.
