**Коммутация каналов** — это способ передачи данных, при котором перед началом обмена между отправителем и получателем создаётся **выделенный сквозной канал связи**. Этот канал остаётся закреплённым за соединением до его завершения.

Например, телефонная сеть сначала устанавливает соединение, затем происходит разговор, после чего канал освобождается.

#### Этапы работы
1. **Установление соединения:** Сеть выбирает маршрут и резервирует ресурсы на всех промежуточных узлах.
2. **Передача данных:** Данные идут по заранее созданному каналу. Другие пользователи не могут использовать зарезервированную пропускную способность.
3. **Разрыв соединения**  
    После завершения обмена канал освобождается.

Пример маршрута:
```
Компьютер A → Коммутатор 1 → Коммутатор 2 → Компьютер B
```

На каждом участке маршрута резервируется часть пропускной способности:
```
A ===== S1 ===== S2 ===== B
      выделенный канал
```

#### Особенности

После установления соединения данные обычно передаются:
- по одному и тому же маршруту;
- с постоянной пропускной способностью;
- с предсказуемой задержкой;
- без необходимости каждый раз искать путь для отдельной порции данных.

Например, если для соединения выделено `64 Кбит/с`, эта полоса будет занята всё время существования соединения — даже когда стороны временно ничего не передают.

#### Преимущества

- **Гарантированная пропускная способность.** Ресурсы заранее зарезервированы.
- **Стабильная задержка.** После установления канала задержка обычно почти не изменяется.
- **Сохранение порядка данных.** Все данные проходят по одному маршруту.
- **Удобство для непрерывного трафика.** Подходит для обычной телефонии и других потоков, которым требуется постоянная скорость передачи.
#### Недостатки
- **Неэффективное использование ресурсов.** Если участник молчит или не передаёт данные, канал всё равно остаётся занятым.
- **Необходимо время на установление соединения.**
- **Ограниченное количество соединений.** Если все каналы заняты, новое соединение установить нельзя.
- **Низкая устойчивость к повреждению маршрута.** При отказе одного из участков соединение может оборваться.

##### Виды коммутации каналов

- Пространственное разделение: Для соединения физически или логически выделяется отдельный путь через коммутационное оборудование.
- Временное разделение: Один физический канал делится на временные интервалы. Каждому соединению регулярно предоставляется свой интервал. Даже если абонент ничего не передаёт, его временной интервал может остаться неиспользованным.

## Коммутация каналов и коммутация пакетов

| Характеристика | Коммутация каналов     | Коммутация пакетов                   |
| -------------- | ---------------------- | ------------------------------------ |
| Канал          | Выделяется заранее     | Не выделяется                        |
| Маршрут        | Обычно постоянный      | Пакеты могут идти разными маршрутами |
| Ресурсы        | Зарезервированы        | Используются совместно               |
| Задержка       | Более предсказуемая    | Может изменяться                     |
| Эффективность  | Низкая при паузах      | Высокая для неравномерного трафика   |
| Пример         | Традиционная телефония | Интернет                             |

В интернете преимущественно применяется **коммутация пакетов**. Сообщение разделяется на пакеты, которые передаются через общие сетевые ресурсы:

```
Пакет 1 → маршрут A
Пакет 2 → маршрут B
Пакет 3 → маршрут A
```

На принимающей стороне пакеты собираются обратно в исходное сообщение.
