### Виды адресации в сетях

| Тип адреса | Уровень OSI | Формат | Пример | Назначение |
|---|---|---|---|---|
| **MAC** | Канальный (L2) | 6 байт HEX | `00:1A:2B:3C:4D:5E` | Идентификация сетевого интерфейса |
| **IP (v4)** | Сетевой (L3) | 4 байта | `192.168.1.1` | Идентификация узла в сети |
| **IP (v6)** | Сетевой (L3) | 16 байт | `fe80::1` | Аналог IPv4, расширенный |
| **Порт** | Транспортный (L4) | 2 байта | `:80`, `:443` | Идентификация приложения/процесса |
| **DNS** | Прикладной (L7) | Доменное имя | `example.com` | Человекочитаемый адрес |

### Алгоритмы доступа к среде передачи данных (MAC-уровень)

Решают задачу: как несколько узлов разделяют одну среду передачи (общую шину) без коллизий.

#### 1. CSMA/CD (Carrier Sense Multiple Access with Collision Detection)
- **Слушает:** свободен ли канал
- **Передаёт:** если свободен
- **Детектирует коллизию:** при одновременной передаче
- **Backoff:** экспоненциальная задержка перед повторной попыткой
- *Применение:* Ethernet (устарел в коммутируемых сетях)

#### 2. CSMA/CA (Collision Avoidance)
- Слушает канал и ждёт случайное время перед передачей
- Использует RTS/CTS (Request to Send / Clear to Send) — резервирование
- *Применение:* Wi-Fi (802.11)

#### 3. Token Passing (маркерный доступ)
- По кольцу передаётся маркер (специальный кадр)
- Только владелец маркера может передавать
- *Применение:* Token Ring, FDDI

#### 4. TDMA / FDMA / CDMA
- **TDMA** — разделение по времени (каждому узлу — свой слот)
- **FDMA** — разделение по частоте (разные частоты)
- **CDMA** — кодовое разделение (коды Уолша)
- *Применение:* сотовые сети (GSM — TDMA/FDMA, 3G — CDMA)

#### 5. Polling (опрос)
- Центральный контроллер опрашивает узлы по очереди
- *Применение:* Bluetooth (piconet), промышленные сети
