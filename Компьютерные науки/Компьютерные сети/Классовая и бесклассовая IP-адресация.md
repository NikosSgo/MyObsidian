# Классовая и бесклассовая IP-адресация

## Классовая адресация (Classful)

IP-адрес (IPv4) = 32 бита, разделённых на **ネットワーク ID** + **хост ID**.

### Классы

| Класс | Диапазон первого октета | Префикс | Маска | Кол-во хостов |
|-------|------------------------|---------|-------|---------------|
| **A** | 1–126 | /8 | 255.0.0.0 | 2²⁴ − 2 = 16 777 214 |
| **B** | 128–191 | /16 | 255.255.0.0 | 2¹⁶ − 2 = 65 534 |
| **C** | 192–223 | /24 | 255.255.255.0 | 2⁸ − 2 = 254 |
| **D** | 224–239 | — | — | Мулькаст |
| **E** | 240–255 | — | — | Экспериментальные |

> −2因为在 каждый сети: адрес сети (все 0) + адрес broadcaст (все 1).

### Недостатки классовой адресации

- **Избыточность:** класс B (65K хостов) слишком велик для 1000 узлов, класс C (254 хоста) слишком мал
- **Нерациональное использование пространства** адресов
- **Ограниченная маршрутизация** — нельзя агрегировать подсети

## CIDR (Classless Inter-Domain Routing)

### Суть

Отказ от фиксированных классов. Маска подсети задаётся произвольным префиксом /n.

**Пример:** `192.168.1.0/26` — 26 бит на сеть, 6 бит на хост → 2⁶ − 2 = 62 хоста.

### Запись CIDR

```
IP-адрес/длина префикса
10.0.0.0/8      — 2²⁴ адресов
172.16.0.0/12   — 2²⁰ адресов
```

### Variable-Length Subnet Masking (VLSM)

Разделение сети на подсети с разными размерами масок.

**Пример:** Сеть `192.168.1.0/24`:
- `192.168.1.0/25` → 126 хостов (отдел A)
- `192.168.1.128/26` → 62 хоста (отдел B)
- `192.168.1.192/28` → 14 хостов (серверы)

## Супернеттинг (Route Aggregation)

Объединение нескольких сетей в одну большую сеть с уменьшенной маской.

**Пример:**
```
192.168.0.0/24  ─┐
192.168.1.0/24   ├──→  192.168.0.0/22  (4 сети, 1022 хоста)
192.168.2.0/24   │
192.168.3.0/24  ─┘
```

Уменьшает размер таблицы маршрутизации.

## Сравнение: Classful vs CIDR

| Критерий | Classful | CIDR |
|----------|----------|------|
| Маска | Фиксированная (/8, /16, /24) | Произвольная /n |
| Использование адресов | Неэффективное | Гибкое (VLSM) |
| Маршрутизация | Без агрегации | С агрегацией (supernetting) |
| Простота | Выше | Ниже (требует знания масок) |
| Актуальность | Устарел | Действует (RFC 4632) |
