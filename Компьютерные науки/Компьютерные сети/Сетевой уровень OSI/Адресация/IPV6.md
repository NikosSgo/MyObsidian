**IPv6 (Internet Protocol version 6)** — следующая версия IP. Его адрес состоит из **128 бит**, поэтому доступных адресов намного больше, чем в IPv4.

Адрес записывается восемью группами по четыре шестнадцатеричные цифры:

```text
2001:0db8:0000:0000:0000:0000:0000:0010
```

Нули можно сокращать:
- ведущие нули внутри группы опускаются: `0db8` → `db8`;
- одну непрерывную последовательность нулевых групп можно заменить на `::`.

Поэтому тот же адрес записывается так:

```text
2001:db8::10
```

## Что содержит IPv6-пакет

IPv6-пакет состоит из базового заголовка, необязательных расширенных заголовков и полезной нагрузки — обычно TCP-сегмента, UDP-дейтаграммы или ICMPv6-сообщения.

```text
[ базовый IPv6-заголовок: 40 байт | расширения | данные верхнего уровня ]
```

### Пример: пакет проходит через роутеры

Пусть ПК `2001:db8:1::10` отправляет данные серверу `2001:db8:2::20`.

1. **ПК формирует пакет.**
   - **Version** (4 бита) сообщает, что это IPv6.
   - **Source Address** и **Destination Address** (по 16 байт) содержат адреса конечных узлов.
   - **Payload Length** (2 байта) задаёт размер всего после базового заголовка.
   - **Next Header** (1 байт) говорит, что идёт дальше: расширенный заголовок или TCP (*Transmission Control Protocol*, `6`), UDP (*User Datagram Protocol*, `17`), ICMPv6 (*Internet Control Message Protocol version 6*, `58`). Получатель по нему передаст данные нужному протоколу.
   - **Traffic Class** (1 байт) и **Flow Label** (20 бит) позволяют сетевому оборудованию одинаково обрабатывать пакеты с нужным приоритетом или из одного потока.

2. **Роутер выбирает маршрут.**
   - Он использует **Destination Address**, чтобы выбрать следующий путь.
   - Адреса источника и назначения не меняются по дороге: они принадлежат конечным устройствам.

3. **Роутер контролирует время жизни пакета.**
   - **Hop Limit** (1 байт), например, равен 64. Каждый роутер уменьшает его на 1.
   - При нуле пакет отбрасывается, чтобы он не ходил по сети по кругу.

4. **Дополнительные возможности передаются расширенными заголовками.**
   - Базовый заголовок всегда занимает 40 байт и не содержит контрольной суммы: проверка ошибок уже есть на канальном и транспортном уровнях.
   - После него могут идти заголовки фрагментации, безопасности или параметров назначения. Их наличие и порядок определяет **Next Header**.
   - Фрагментацию выполняет только отправитель, а не роутеры по пути.

## Префикс сети

Как и в IPv4, длина префикса показывает, какая часть адреса обозначает сеть:

```text
2001:db8:1234:1::10/64
```

В обычной IPv6-подсети используется `/64`: первые 64 бита — префикс сети, последние 64 бита — идентификатор интерфейса.

## Виды IPv6-адресов

- **Global unicast** — глобально маршрутизируемый адрес в Интернете; обычно начинается с `2` или `3`.
- **Link-local** — адрес только для текущего канала/сети, диапазон `fe80::/10`. Он назначается интерфейсу автоматически и нужен, например, для связи с роутером.
- **Unique local** — частные адреса для внутренней сети, диапазон `fc00::/7` (обычно `fd...`).
- **Multicast** — доставка группе получателей, диапазон `ff00::/8`.
- **Loopback** — `::1`, адрес самого устройства.
- **Unspecified** — `::`, адрес «не указан».

В IPv6 **нет broadcast**. Вместо него используются multicast-адреса, поэтому устройства получают только те служебные сообщения, которые относятся к нужной группе.
