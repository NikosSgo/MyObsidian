**Path-Vector маршрутизация** — роутер передаёт сеть назначения вместе с путём, который маршрут уже прошёл через автономные системы (*AS*).

1. Роутер получает префикс и список AS в пути.
2. Если в списке уже есть его собственная AS, маршрут отвергается: это защищает от междоменной петли.
3. Из допустимых маршрутов выбирается не просто кратчайший, а соответствующий политике организации.
4. Передавая маршрут дальше, роутер добавляет номер своей AS в начало пути.

Здесь главное — политика: через какие сети разрешено передавать трафик, какие маршруты предпочитать и кому их объявлять.

## Основная реализация: BGP

**BGP** (*Border Gateway Protocol*) — основной протокол маршрутизации между автономными системами Интернета и практическая реализация path-vector.

- Работает между AS: провайдерами, крупными организациями и облачными сетями.
- Передаёт префикс и атрибуты маршрута: например, **AS_PATH**, LOCAL_PREF, MED.
- Выбирает маршрут по политике и атрибутам, а не только по длине AS_PATH.
- Использует TCP-подключение на порту `179` для обмена обновлениями.

BGP делает Интернет связным, но сложен в настройке: ошибочное объявление маршрута может повлиять на трафик множества сетей.
