### Коммутатор (Switch) — L2

**Назначение:** объединение устройств в одной локальной сети.

**Внутренняя архитектура:**
- ASIC (железная коммутация) — аппаратная, высокая скорость
- CAM-таблица (Content Addressable Memory) — MAC-адрес → порт

**Алгоритм работы:**
1. Получает кадр
2. Смотрит MAC-адрес назначения
3. Ищет в CAM-таблице: если есть → отправляет только на нужный порт; если нет → флудит на все порты (кроме входного)
4. Обучается: записывает MAC-адрес источника + порт в таблицу

**Защита от циклических маршрутов:**
- **STP (Spanning Tree Protocol)** — логически отключает избыточные линки
- Использует BPDU (Bridge Protocol Data Units)
- Выбор корневого моста (Root Bridge), расчёт кратчайших путей

### Маршрутизатор (Router) — L3

**Назначение:** соединение разных сетей, маршрутизация между подсетями.

**Внутренняя архитектура:**
- Процессор + ОЗУ (таблица маршрутизации)
- Сетевая ОС (Cisco IOS, Linux iproute2)
- NAT, ACL (Access Control Lists) — фильтрация, брандмауэр

**Алгоритм работы:**
1. Получает IP-пакет
2. Смотрит IP-адрес назначения
3. Ищет в таблице маршрутизации longest prefix match
4. Пересылает на следующий hop (next hop)

**Защита от циклических маршрутов:**
- **TTL (Time To Live)** — каждый роутер уменьшает TTL на 1, при 0 — отбрасывает пакет
- **Split Horizon** — не объявлять маршрут обратно тому, от кого узнал
- **Poison Reverse** — объявлять маршрут с метрикой «бесконечность»
- **Метрики протоколов:** OSPF (cost), RIP (hop count), BGP (AS-path)

---

### Сравнение

| Характеристика | Коммутатор (Switch) | Маршрутизатор (Router) |
|---|---|---|
| Уровень OSI | L2 (канальный) | L3 (сетевой) |
| Адресация | MAC-адреса | IP-адреса |
| Таблица | CAM (MAC → port) | Routing table (IP → next hop) |
| Скорость | Очень высокая (ASIC) | Средняя (процессор) |
| Соединяет | Устройства в одной подсети | Разные подсети/сети |
| Защита от петель | STP (блокировка портов) | TTL + алгоритмы маршрутизации |
