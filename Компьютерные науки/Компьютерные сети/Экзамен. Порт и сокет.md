# Порт и сокет

## Порт (Port)
- **16-битный** номер (0–65535), идентифицирующий процесс на хосте
- Комбинация **IP + порт** = сетевой эндпоинт

### Диапазоны портов
| Диапазон | Название | Описание |
|----------|----------|----------|
| 0–1023 | Well-known | Системные сервисы (HTTP=80, HTTPS=443, SSH=22, DNS=53) |
| 1024–49151 | Registered | Зарегистрированные IANA (MySQL=3306, Redis=6379) |
| 49152–65535 | Dynamic/ephemeral | Временные, назначаются ОС клиенту |

## Сокет (Socket)
- **Сокет = IP-адрес + порт** — логическая конечная точка
- Позволяет обмениваться данными между процессами по сети

### Типы сокетов

#### TCP-сокет
- Потоковый, надёжный, с установлением соединения
- Гарантия доставки, порядка, контроль потока
- Два сокета: `(IP1:port1, IP2:port2)`

#### UDP-сокет
- Дейтаграммный, без установления соединения
- Быстрый, но без гарантий
- Один сокет принимает от всех отправителей

### Socket API (POSIX)

```c
// Сервер
int s = socket(AF_INET, SOCK_STREAM, 0);  // создание
bind(s, &addr, sizeof(addr));               // привязка к порту
listen(s, backlog);                          // ожидание подключений
int c = accept(s, &client_addr, &len);     // принятие соединения
read(c, buf, len);                          // приём данных
write(c, buf, len);                         // отправка данных
close(c);                                   // закрытие

// Клиент
int s = socket(AF_INET, SOCK_STREAM, 0);
connect(s, &server_addr, sizeof(addr));     // подключение
write(s, data, len);                        // отправка
read(s, buf, len);                          // приём
close(s);
```

### UDP Socket API
```c
int s = socket(AF_INET, SOCK_DGRAM, 0);    // без SOCK_STREAM
bind(s, &addr, sizeof(addr));
recvfrom(s, buf, len, 0, &src_addr, &slen); // приём + адрес отправителя
sendto(s, buf, len, 0, &dst_addr, dlen);    // отправка с указанием адреса
```

## TCP vs UDP

| Характеристика | TCP | UDP |
|----------------|-----|-----|
| Соединение | Устанавливается | Нет |
| Доставка | Гарантирована | Не гарантирована |
| Порядок | Гарантирован | Не гарантирован |
| Контроль потока | Да | Нет |
| Скорость | Ниже | Выше |
| Применение | HTTP, SSH, FTP | DNS, VoIP, игры |
