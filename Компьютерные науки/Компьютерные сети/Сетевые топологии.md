# Сетевые топологии

## Определение

**Топология сети** — логическая или физическая структура расположения узлов и соединений между ними.

## Типы топологий

### Bus (Шина)

Все узлы подключены к общему каналу (шине).

```
───┬───┬───┬───┬───
   A   B   C   D
```

- ✅ Простота, низкая стоимость кабеля
- ❌ Один кабель — единственный отказ, коллизии
- 📌 Ранние Ethernet (10Base2, 10Base5)

### Star (Звезда)

Все узлы подключены к центральному узлу (коммутатор/хаб).

```
    B
    │
A ──HUB── C
    │
    D
```

- ✅ Простота управления, изоляция отказа одного узла
- ❌ Отказ центра — отказ всей сети
- 📌 Современные Ethernet (10/100/1000Base-T)

### Ring (Кольцо)

Каждый узел соединён с двумя соседями,形成 замкнутый контур.

```
A → B → C
↑         ↓
D ← E ← F
```

- ✅ Равный доступ (token passing), предсказуемая задержка
- ❌ Отказ одного узла нарушает кольцо (решается dual ring)
- 📌 Token Ring (IBM), FDDI

### Mesh (Полная решётка)

Каждый узел соединён со всеми (full mesh) или частью (partial mesh).

```
A ── B
│ ╲  │
│  ╲ │
D ── C
```

- ✅ Высокая надёжность, множество альтернативных путей
- ❌ Высокая стоимость (n(n-1)/2 соединений)
- 📌 Телефонная сеть骨干, backbone-каналы

### Tree (Дерево)

Иерархическая структура: корневой узел → промежуточные → листья.

```
        Root
       /    \
     A        B
    / \      / \
   C   D    E   F
```

- ✅ Иерархическое управление, масштабируемость
- ❌ Отказ корня или промежуточного узла затрагивает ветку
- 📌 Корпоративные сети, VLAN

### Hybrid (Гибридная)

Комбинация двух и более топологий.

- ✅ Гибкость, оптимизация под задачи
- ❌ Сложность проектирования и управления
- 📌 Большинство реальных сетей (Internet)

## Сравнение

| Топология | Стоимость | Надёжность | Масштабируемость | Сложность управления |
|-----------|-----------|------------|-----------------|---------------------|
| Bus | Низкая | Низкая | Ограниченная | Простая |
| Star | Средняя | Средняя | Хорошая | Простая |
| Ring | Средняя | Средняя* | Ограниченная | Средняя |
| Mesh | Высокая | Высокая | Средняя | Сложная |
| Tree | Средняя | Средняя | Хорошая | Средняя |
| Hybrid | Разная | Высокая | Отличная | Сложная |

* при dual ring (FDDI) — высокая
