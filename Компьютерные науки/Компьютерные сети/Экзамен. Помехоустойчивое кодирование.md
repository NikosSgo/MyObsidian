# Помехоустойчивое кодирование

## Обнаружение vs Исправление ошибок

| Кодирование | Цель | Избыточность | Сложность |
|-------------|------|--------------|-----------|
| **Обнаружение** | Узнать, что ошибка есть | Низкая | Низкая |
| **Исправление** | Восстановить данные | Высокая | Высокая |

## Методы обнаружения ошибок

### Бит чётности (Parity Bit)
- Добавляется 1 бит для чётности (чётное/нечётное число единиц)
- Обнаруживает **нечётное** число ошибок
- Не обнаруживает чётное число ошибок

### Контрольная сумма (Checksum)
- Байты данных суммируются, результат передаётся вместе с данными
- Приёмник пересчитывает и сравнивает
- **Пример:** IP, TCP, UDP

### CRC (Cyclic Redundancy Check)
- Деление полинома данных на порождающий полином
- Остаток — контрольная последовательность
- Обнаруживает все ошибки длины ≤ степени полинома
- **Высокая надёжность**, широко используется (Ethernet, Wi-Fi)

## Методы исправления ошибок

### Код Хэмминга (Hamming Code)
- Встраивает контрольные биты в позиции 2^k
- Исправляет **одну** ошибку, обнаруживает **две**
- Кодовое расстояние d = 3
- **Формула:** m + r ≤ 2^r − 1 (m — данные, r — проверочные биты)

### Код Рида-Соломона (Reed-Solomon)
- Блочный код, работает с символами (не битами)
- Исправляет до t ошибок, если 2t контрольных символов
- **Примеры:** CD/DVD, QR-коды, космические связи

## Компромиссы

| Параметр | Низкая избыточность | Высокая избыточность |
|----------|---------------------|----------------------|
| Пропускная способность | Выше | Ниже |
| Защита от ошибок | Слабее | Сильнее |
| Задержка обработки | Меньше | Больше |
| Применение | LAN, Wi-Fi | Космос, хранение |

## Выбор метода
- **Нетребовательные каналы:** parity, checksum
- **Средние условия:** CRC
- **Ненадёжные каналы:** Hamming, Reed-Solomon
- **Критичные данные:** комбинация (CRC + Hamming)
