# Алгоритмы маршрутизации

## Статическая маршрутизация

### Таблицы маршрутизации
- Таблица заполняется **вручную** (statially configured)
- Не адаптируется к изменениям топологии
- Подходит для малых, стабильных сетей

### Flooding (затопление)
- Пакет пересылается **всем** соседям, кроме источника
- Гарантирует доставку по кратчайшему пути
- Минус: экспоненциальный рост трафика
- Применение: военные сети, аварийные ситуации

## Адаптивная маршрутизация

### Distance-Vector (расстояние-вектор)
- Каждый узел знает расстояние до всех целей **через соседей**
- Алгоритм **Беллмана-Форда**: D(x) = min_v { c(x,v) + D(v) }
- **RIP** — пример протокола (макс. 15 хопов, обновление каждые 30 сек)
- Проблема: медленная сходимость, «проблема.count-to-infinity»

### Link-State (состояние канала)
- Каждый узел знает **полную топологию** сети
- Алгоритм **Дейкстры** строит дерево кратчайших путей
- **OSPF** — пример протокола (области, метрика cost)
- Преимущества: быстрая сходимость, иерархичность
- Минус: высокие затраты памяти и вычислений

### Path-Vector (путь-вектор)
- Хранит **полный путь** (список AS) до назначения
- **BGP** — протокол междоменной маршрутизации
- Решает policy-based маршрутизацию
- Защита от петель через проверку AS-path

## Сравнение

| Критерий | Distance-Vector | Link-State | Path-Vector |
|----------|-----------------|------------|-------------|
| Информация | У соседей | Полная топология | Полный путь |
| Алгоритм | Беллман-Форд | Дейкстры | Расширение DV |
| Протокол | RIP | OSPF, IS-IS | BGP |
| Масштаб | Малые сети | Средние/крупные | Глобальные |
| Сходимость | Медленная | Быстрая | Быстрая |
| Области | Нет | Да | AS (автономные системы) |
| Сложность | Низкая | Высокая | Средняя |
