# Кодирование информации в сетях

## Зачем нужно line coding

Преобразование двоичных данных (0/1) в электрические/оптические сигналы. Ключевые требования:
- Синхронизация (clock recovery)
- Минимизация DC-компонента
- Обнаружение ошибок
- Спектральная эффективность

## Типы кодирования

### NRZ (Non-Return to Zero)

**Правило:** 1 → высокий уровень, 0 → низкий уровень.

| + | - |
|---|---|
| Простота | DC-компонент при длительной последовательности 0 или 1 |
| | Нет синхронизации при длинных сериях |

### NRZI (NRZ Inverted)

**Правило:** Смена уровня на границе бита = 1, без смены = 0.

| + | - |
|---|---|
| Решает проблему длинных серий единиц | Длинные серии нулей по-прежнему вызывают потерю синхронизации |
| | Нет обнаружения ошибок |

### Manchester

**Правило:** В середине каждого бита — переход. 0 → переход с high в low, 1 → с low в high.

| + | - |
|---|---|
| Гарантированный переход в каждом бите (синхронизация) | Требует удвоенной полосы пропускания |
| Нет DC-компонента | Сложность при высоких скоростях |

### Differential Manchester

**Правило:** Наличие/отсутствие перехода на границе бита编码 0/1; переход в середине — всегда.

| + | - |
|---|---|
| Синхронизация + устойчивость к инверсии | Удвоенная полоса |
| | Сложность декодирования |

### MLT-3 (Multi-Level Transmit)

**Правило:** Три уровня (-1, 0, +1). 1 → переход к следующему уровню, 0 → без изменений.

| + | - |
|---|---|
| Низкая частота сигнала | Медленная синхронизация |
| Используется в FDDI, 100Base-TX | Ограниченная помехоустойчивость |

### 4B/5B

**Правило:** Каждые 4 бита кодируются в 5-битный символ. 16 из 32 символов используются, остальные — для контроля.

| + | - |
|---|---|
| Гарантирует transitions каждые 3-4 бита | 20% накладные расходы |
| Обнаружение ошибок (запрещённые символы) | Снижение эффективной полосы |

### 8B/10B

**Правило:** 8 бит → 10-битный символ. Балансировка DC-компонента (running disparity).

| + | - |
|---|---|
| Контроль DC-уровня | 20% накладные расходы |
| Обнаружение 1-битных и 2-битных ошибок | |
| Используется в Gigabit Ethernet, PCIe | |
