Нейронные сети можно классифицировать по следующим признакам:
- По типу обучения.
- По глубине и сложности.
- По используемому правилу коррекции коэффициентов.
- Архитектуре и структуре связей.

---

### Типы обучения нейронных сетей:
- Обучение с учителем
- Обучение без учителя
- Гибридный подход

---

### Типы нейронных сетей по глубине и сложности:
- Однослойные нейронные сети
- Многослойные нейронные сети
- Глубокие нейронные сети

---

### Типы нейронных сетей по правилу коррекции коэффициентов:

- Правило обратного распространения ошибки
- Синхронное обучение
- Конкурентное обучение 
- Правило Больцмана
