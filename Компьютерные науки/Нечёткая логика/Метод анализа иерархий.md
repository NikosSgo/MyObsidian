**Метод анализа иерархий (Analytic Hierarchy Process, AHP)** используется для принятия решений, когда необходимо выбрать оптимальный вариант из множества альтернатив с учётом нескольких критериев, которые могут иметь разный вес. Основная идея метода состоит в следующем:

1. **Декомпозиция задачи**.  
    Сначала сложная задача представляется в виде иерархии уровней:    
    - **Цель** — верхний уровень иерархии (например, «Выбрать лучший проект»).
    - **Критерии** — средний уровень, по которым оцениваются альтернативы (например, стоимость, качество, сроки).
    - **Альтернативы** — нижний уровень иерархии (варианты решения задачи).
2. **Парные сравнения**.  
    На каждом уровне элементы сравниваются **попарно** по важности или предпочтительности относительно родительского критерия. Для этого используется **шкала Саати**, обычно от 1 до 9, где:
    - 1 — элементы одинаково важны,
    - 3 — умеренное предпочтение одного над другим,
    - 5 — сильное предпочтение,
    - 7 — очень сильное предпочтение,
    - 9 — крайнее предпочтение,
    - 2,4,6,8 — промежуточные значения.
    
    Результатом является **матрица парных сравнений** $A = [a_{ij}]$, где элемент (a_{ij}) показывает, насколько $i$-й элемент важнее $j$-го. Матрица всегда **обратима**: $a_{ji} = 1 / a_{ij}$.
    
3. **Вычисление весов**.  
    Из матрицы парных сравнений вычисляются **вектор весов** $w = [w_1, w_2, \dots, w_n]$, который отражает относительную важность каждого элемента. Один из способов — метод **среднего геометрического**:
$$
w_i = \frac{\left(\prod_{j=1}^{n} a_{ij}\right)^{1/n}}{\sum_{k=1}^{n} \left(\prod_{j=1}^{n} a_{kj}\right)^{1/n}}.  
$$
    
4. **Проверка согласованности**.  
    Для оценки согласованности сравнений используется **коэффициент согласованности** (CR):
$$
CI = \frac{\lambda_{\max} - n}{n-1}, \quad CR = \frac{CI}{RI},  
$$
    
    где $\lambda_{\max}$ — максимальное собственное значение матрицы $A$, $n$ — размер матрицы, $RI$ — случайный индекс (Random Index). Обычно $CR < 0.1$ считается допустимой согласованностью.
5. **Синтез итогового решения**.  
    После вычисления весов на всех уровнях иерархии, вес альтернатив относительно глобальной цели определяется как **суммарное произведение весов по пути от цели к альтернативе**. Это позволяет ранжировать альтернативы и выбрать оптимальную.
