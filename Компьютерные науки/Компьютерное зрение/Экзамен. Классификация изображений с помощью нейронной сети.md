# Экзамен. Классификация изображений с помощью нейронной сети

## CNN — Convolutional Neural Network

### Свёрточные слои (Convolutional Layers)

**Фильтры (ядра):** матрица весов $k \times k$, находит паттерны (границы, текстуры)

**Операция свёртки:** вычисление скалярного произведения ядра и окна входа:
$$\text{output}(i,j) = \sum_m \sum_n \text{input}(i+m, j+n) \cdot \text{kernel}(m,n) + b$$

**Гиперпараметры:**
- **Stride (шаг):** перемещение ядра (1 → полная свёртка, 2 → уменьшение размера)
- **Padding:** добавление нулей по краям:
  - `valid` — без padding
  - `same` — padding для сохранения размера

**Выход:** feature map — карта признаков (каждый фильтр → свой канал)

### Слои пулинга (Pooling)

| Тип | Операция | Назначение |
|-----|----------|-----------|
| Max Pooling | Максимум в окне | Сохраняет наиболее активные признаки |
| Average Pooling | Среднее в окне | Сглаживает, менее агрессивный |
| Global Average Pooling | Среднее по всей карте | Заменяет FC-слой (EfficientNet) |

- Уменьшает пространственный размер → меньше параметров
- Добавляет **инвариантность** к малым сдвигам

### Fully Connected Layers (Полносвязные)

- **Flatten:** feature map → вектор
- **FC-слой:** классификатор по извлечённым признакам
- **Выходной слой:** softmax (K классов) или sigmoid (бинарная)

### Типичная архитектура
```
Input → [Conv → ReLU → Pool] × N → Flatten → FC → ReLU → FC → Softmax
```

Примеры: **LeNet-5**, **VGG-16**, **ResNet-50**, **EfficientNet**

## Процесс обучения

### Forward pass
Вход → свёртки → пулинг → полносвязные → предсказание

### Функция потерь
- **Categorical Cross-Entropy:** $L = -\sum_{k=1}^{K} y_k \log(\hat{y}_k)$
- Для бинарной: **Binary Cross-Entropy**

### Обратное распространение
- Градиенты через свёрточные слои: свёртка ядра с **реверсированным** feature map
- Через pooling: распространение градиента только на max-элемент (max pooling)

### Оптимизация
| Оптимизатор | Особенности |
|-------------|------------|
| **SGD + Momentum** | Медленная, но лучшая обобщаемость |
| **Adam** | Быстрая сходимость, стандарт для обучения |
| **AdamW** | Adam с правильным weight decay |

## Data Augmentation (Аугментация данных)

**Зачем:** увеличение обучающей выборки → борьба с переобучением

| Техника | Описание |
|---------|---------|
| Горизонтальный/вертикальный flip | Отражение изображения |
| Поворот (rotation) | Поворот на случайный угол |
| Сдвиг (translation) | Случайное смещение по осям |
| Масштабирование (zoom) | Увеличение/уменьшение |
| Яркость/контраст | Изменение цветовых характеристик |
| Random crop | Случайное вырезание фрагмента |
| Mixup | Наложение двух изображений с коэффициентом α |
| Cutout | Замена прямоугольной области на нули |

**Специфика:** augmentation применяется **только к train**, не к val/test.

## Transfer Learning (Трансферное обучение)
1. Берём предобученную модель (ImageNet)
2. Замораживаем свёрточные слои
3. Обучаем только новые FC-слои
4. Размораживаем последние слои → дообучаем
