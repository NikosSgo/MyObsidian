## Компьютерная графика

### Двумерное отсечение

**Задача:** определить, какие части отрезка или многоугольника находятся внутри заданного окна (области отсечения).

### Алгоритм Сазерленда-Коэна

**Принцип:** разбиение отрезка по границам окна.

1. Для каждой границы окна (левая, правая, верхняя, нижняя):
   - Если обе конечные точки внутри — оставить отрезок
   - Если обе снаружи — отбросить
   - Если одна внутри, одна снаруważnie — найти точку пересечения и разбить отрезок
2. Повторять для каждой границы

**Кодирование:** каждой точке присваивается 4-битный код (left, right, bottom, top):
- `0000` — внутри
- Любой другой код — снаружи

**Сложность:** $O(n)$, где $n$ — количество отрезков.

### Алгоритм Кируса-Бека

**Принцип:** параметрическое представление отрезка и проверка пересечения с каждой границей.

Отрезок: $P(t) = P_0 + t(P_1 - P_0)$, $t \in [0, 1]$

Для каждой границы окна вычисляется параметр $t$ пересечения. Ищется最大和最小 $t$ для определения видимой части.

**Сложность:** $O(n)$.

## Задача удаления невидимых линий и поверхностей

### Алгоритм плавающего горизонта

**Принцип:** построчная трассировка поверхности с учётом видимости.

1. Сортируем рёбра по Y-координате
2. Для каждой строки растрового изображения:
   - Определяем активные рёбра
   - Вычисляем цвет пикселей между активными рёбрами
   - Учитываем z-координату (глубину) для определения видимости

**Применение:** рендеринг 3D-поверхностей, заданных функцией $z = f(x, y)$.

### Алгоритм, использующий z-буфер

**Принцип:** для каждого пикселя храним максимальное значение z (глубины).

1. Инициализация z-буфера максимальными значениями
2. Для каждого полигона:
   - Для каждого пикселя полигона:
     - Если z-значение полигона > значения в z-буфере:
       - Обновить z-буфер
       - Установить цвет пикселя

**Достоинства:**
- Простая реализация
- Работа с произвольными полигональными сетками

**Недостатки:**
- Высокая память ($O(W \times H)$)
- Двойная запись одних и тех же пикселей

## Простая модель освещения

### Составляющие освещения
$$I = k_a I_a + k_d I_d \cos\theta + k_s I_s \cos^n\alpha$$

где:
- $k_a I_a$ — фоновая (ambient) составляющая
- $k_d I_d \cos\theta$ — диффузная (diffuse) составляющая (закон Ламберта)
- $k_s I_s \cos^n\alpha$ — зеркальная (specular) составляющая
- $\theta$ — угол между нормалью и направлением на источник
- $\alpha$ — угол между отражённым лучом и направлением наблюдения
- $n$ — показатель глянца

## Методы закраски

### Метод Гуро (Gouraud shading)

**Принцип:** интерполяция цветов по вершинам полигона.

1. Вычислить цвет в каждой вершине полигона (по нормалям)
2. Интерполировать цвета вдоль рёбер
3. Интерполировать цвета вдоль строк

**Достоинства:** устранение ступенчатости (anti-aliasing)
**Недостатки:** неравномерная яркость, отсутствие чётких бликов

### Метод Фонга (Phong shading)

**Принцип:** интерполяция нормалей по вершинам, вычисление цвета для каждого пикселя.

1. Вычислить нормали в вершинах полигона
2. Интерполировать нормали вдоль рёбер и строк
3. Для каждого пикселя вычислить освещение по интерполированной нормали

**Достоинства:** более реалистичные блики, лучшее качество
**Недостатки:** значительно дороже метода Гуро

### Сравнение

| Критерий | Гуро | Фонг |
|----------|------|------|
| Интерполяция | Цвета | Нормали |
| Вычисления | Меньше | Больше |
| Качество | Среднее | Высокое |
| Блики | Размытые | Точные |
