Классификация паттернов:
- Порождающие
	- Фабричный метод
	- Абстрактная фабрика
	- Синглтон
	- Строитель
- Структурнные
	- Адаптер
	- Фасад
	- Прокси
	- Декоратор
- Поведенческие
	- Шаблон
	- Наблюдатель
	- Стратегия
	- Команда
	- Стейт машина - объект меняет своё поведение, в зависимости от значений внутренних состояний
	- Медиатор - центральный объект через который происходит общение
	- Итератор - даёт интерфейс, чтобы в цикле проходится по внутренностям объекта
