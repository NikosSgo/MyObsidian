Это гибкие механизмы маршрутизации сообщений, которые позволяющие направлять сообщения в разные очереди по определённым правилам
Типы обменников:
- Direct - только при полном совпадении routing key
- Fanout - отправляет копию каждого сообщения во все привязанные очереди, игнорируя routing key, подходит для широковещательных сообщений 
- Topic - реализует паттерн-матчинг routing key для маршрутизации сообщений. Поддерживает wildcards: * - совпадение одного слова, # - совпадение нуля или более сегментов 
- Headers - вместо routing key используются заголовки и сообщение попадает в очередь при соответствии этих заголовок
