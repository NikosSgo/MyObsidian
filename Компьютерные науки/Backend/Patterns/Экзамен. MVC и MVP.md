## MVC и MVP

### MVC (Model-View-Controller)

**Разделение обязанностей:**
- **Model:** данные, бизнес-логика, работа с БД
- **View:** отображение данных (UI)
- **Controller:** обработка ввода, координация Model и View

**Поток данных:**
```
User → Controller → Model → View → User
```

**UML-стереотипы:**
- `<<controller>>` — классы контроллеров
- `<<entity>>` — классы модели
- `<<boundary>>` — классы представления

### MVP (Model-View-Presenter)

**Разделение обязанностей:**
- **Model:** данные и бизнес-логика
- **View:** пассивный UI (только отображает)
- **Presenter:** вся логика взаимодействия

**Поток данных:**
```
User → View → Presenter → Model → Presenter → View → User
```

### Разница

| Критерий | MVC | MVP |
|----------|-----|-----|
| Связь View-Model | Прямая | Через Presenter |
| Тестируемость | Сложнее | Легче (View пассивный) |
| Использование | Web-фреймворки | Android, десктоп |

### CRUD-операция (пример)
**Создание статьи:**
1. User вводит данные → View передаёт Presenter
2. Presenter валидирует → вызывает Model.save()
3. Model сохраняет → возвращает результат
4. Presenter обновляет View
