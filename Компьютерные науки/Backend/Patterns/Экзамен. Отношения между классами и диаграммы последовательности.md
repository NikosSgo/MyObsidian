### Отношения между классами (обмен сообщениями)

**Обмен сообщениями** — объекты взаимодействуют, вызывая методы друг друга. В ООП это основной способ коммуникации.

**На диаграмме классов UML** отношения обозначаются:

| Отношение | Линия | Пример |
|---|---|---|
| **Ассоциация** | `———` | Класс А «знает» класс B |
| **Агрегация** | `◇———` | Часть-целое (слабая связь) |
| **Композиция** | `◆———` | Часть-целое (сильная, жизненный цикл общий) |
| **Зависимость** | `- - ->` | Временное использование |
| **Наследование** | `———▷` | IS-A отношение |
| **Реализация** | `- - - ▷` | Реализация интерфейса |

**Обмен сообщениями** показывается стрелкой с именем метода. Направление — от отправителя к получателю.

---

### Диаграмма последовательности

Показывает **временну́ю последовательность** обмена сообщениями между объектами.

**Основные элементы:**

| Элемент | Обозначение |
|---|---|
| **Линия жизни (Lifeline)** | `[Объект]` с пунктирной линией вниз |
| **Сообщение (Message)** | Стрелка от одной линии к другой |
| **Активация (Execution)** | Узкий прямоугольник на линии жизни |
| **Возврат (Reply)** | Пунктирная стрелка назад |
| **Условие (Guard)** | `[условие]` на сообщении |

**Пример — пользователь регистрируется:**
```
User → RegistrationController: register(data)
RegistrationController → UserValidator: validate(data)
UserValidator → RegistrationController: valid=true
RegistrationController → UserService: createUser(data)
UserService → Database: INSERT INTO users
Database → UserService: ok
UserService → RegistrationController: user
RegistrationController → User: 201 Created
```
