### Диаграммы UML

**UML (Unified Modeling Language)** — язык графического описания для объектного моделирования.

**Типы диаграмм (делятся на статические и динамические):**

| Категория | Диаграмма | Назначение |
|---|---|---|
| **Статические** | **Классов** | Структура системы: классы, атрибуты, методы, отношения |
| | **Объектов** | Конкретные экземпляры классов и связи между ними |
| | **Компонентов** | Физические компоненты системы (JAR, DLL, модули) |
| | **Развёртывания** | Физическая топология: сервера, узлы, устройства |
| | **Пакетов** | Группировка элементов в пакеты |
| **Динамические** | **Последовательности** | Обмен сообщениями во времени |
| | **Деятельности** | Поток управления (business process, workflow) |
| | **Состояний** | Жизненный цикл объекта: состояния и переходы |
| | **Коммуникации** | Обмен сообщениями между объектами (акцент на связях) |
| | **Вариантов использования** | Функциональные требования: акторы и прецеденты |

---

### Ключевые диаграммы

**Диаграмма классов:** основная для проектирования.
```
┌─────────────┐
│   User      │
├─────────────┤
│ -id: int    │
│ -name: str  │
├─────────────┤
│ +login()    │
│ +logout()   │
└──────┬──────┘
       │ 1
       │
       │ *
┌──────┴──────┐
│   Order     │
└─────────────┘
```

**Диаграмма деятельности:** похожа на блок-схему с параллельными потоками (fork/join), условиями (decision), началом (start) и концом (end).

**Диаграмма последовательности:** временна́я последовательность обмена сообщениями (подробнее — [[Экзамен. Отношения между классами и диаграммы последовательности]]).

**Диаграмма развёртывания:** показывает, на каких физических узлах (серверах) развёрнуты компоненты системы.

**Диаграмма компонентов:** описывает модули, их интерфейсы и зависимости.
