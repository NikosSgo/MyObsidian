### Этапы жизненного цикла проекта

1. **Анализ требований** — сбор и документирование требований
2. **Проектирование** — архитектура, дизайн системы
3. **Реализация (кодирование)** — написание кода
4. **Тестирование** — проверка качества
5. **Внедрение** — развёртывание системы
6. **Эксплуатация и сопровождение** — поддержка, доработки

---

### Модели ЖЦ

#### Каскадная (Waterfall)
Линейная последовательность этапов. Каждый завершается полностью до начала следующего.
- **Когда:** Требования чёткие, стабильные, однозначные (военные проекты, космос)

#### V-образная модель
Расширение каскадной: каждый этап разработки соответствует этапу тестирования того же уровня.
```
Требования → → → → → Приёмочное тестирование
  Архитектура → → → Интеграционное тестирование
    Детальное проектирование → Модульное тестирование
      Реализация
```

#### Прототипирование
Создаётся рабочий прототип для уточнения требований, затем на основе опыта строится финальная система.

#### Инкрементная модель
Система строится частями (инкрементами). Каждый инкремент добавляет новую функциональность. Первый инкремент содержит базовую функциональность.

#### Итерационная модель
Разработка циклами: на каждой итерации пересматриваются требования, дизайн, код, тесты. К концу каждой итерации — работающая версия.

#### Спиральная модель (Boehm)
Комбинация прототипирования и каскадной. Циклы (итерации) с анализом рисков на каждом витке спирали.
- **Когда:** Высокорисковые проекты, сложные и дорогие системы

#### Гибкие методологии (Agile)
Scrum, XP, Kanban. Короткие итерации (1-4 недели), тесное общение с заказчиком, самоорганизующиеся команды.
- **Когда:** Изменчивые требования, быстрая обратная связь
