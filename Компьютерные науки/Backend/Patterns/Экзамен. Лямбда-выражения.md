# Экзамен. Лямбда-выражения

## Синтаксис (Java 8+)

```
(параметры) -> { тело }
```

```java
// Без тел的身体а — одно выражение
(int a, int b) -> a + b

// С телом — блок кода
(x) -> {
    System.out.println(x);
    return x * 2;
}
```

## Функциональные интерфейсы

Интерфейс с **одним абстрактным методом**. Аннотация `@FunctionalInterface` — не обязательна, но полезна для проверки.

```java
@FunctionalInterface
interface Calculator {
    int calculate(int a, int b);
}

Calculator add = (a, b) -> a + b;
add.calculate(3, 4);  // 7
```

### Встроенные функциональные интерфейсы (java.util.function)

| Интерфейс | Метод | Описание |
|-----------|-------|----------|
| `Function<T,R>` | `R apply(T)` | Преобразование |
| `Predicate<T>` | `boolean test(T)` | Условие |
| `Consumer<T>` | `void accept(T)` | Действие без результата |
| `Supplier<T>` | `T get()` | Поставщик значения |
| `UnaryOperator<T>` | `T apply(T)` | Унарная операция |

## Ссылки на методы (::)

Сокращённая запись лямбды, ссылающейся на существующий метод.

```java
// Лямбда
list.forEach(s -> System.out.println(s));

// Ссылка на метод
list.forEach(System.out::println);

// Ссылка на статический метод
Function<String, Integer> parser = Integer::parseInt;

// Ссылка на метод экземпляра
String::length

// Ссылка на конструктор
ArrayList::new
```

## Использование со Stream API

```java
List<String> names = Arrays.asList("Anna", "Bob", "Charlie", "David");

names.stream()
     .filter(name -> name.length() > 3)        // Predicate
     .map(String::toUpperCase)                   // Function
     .sorted()
     .forEach(System.out::println);
// ANNA, CHARLIE, DAVID
```

## Замыкания (Closures)

Лямбда может захватывать переменные из окружающего контекста.

```java
int factor = 3;
Function<Integer, Integer> multiplier = x -> x * factor;
multiplier.apply(5);  // 15
```

**Правило:** переменная должна быть `final` или effectively final (не изменяться после инициализации).
