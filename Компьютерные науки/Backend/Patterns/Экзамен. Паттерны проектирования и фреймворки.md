### Паттерны vs Фреймворки

**Паттерн проектирования** — это **описание** решения типовой проблемы в контексте (шаблон). Не код, а концепция.
- *Пример:* Singleton, Observer, Factory

**Фреймворк** — это **готовая реализация** архитектуры, которую вы расширяете. Конкретный код, библиотека.
- *Пример:* Django, Spring, ASP.NET Core

**Разница:** паттерн — знание, фреймворк — инструмент. Один фреймворк использует много паттернов.

---

### Типы паттернов проектирования (GoF)

#### Порождающие (Creational) — создание объектов

| Паттерн | Суть | Пример |
|---|---|---|
| **Singleton** | Гарантирует один экземпляр класса | `logging.getLogger()` |
| **Factory Method** | Создание объектов через метод вместо `new` | `Document.create()` |
| **Abstract Factory** | Семейство связанных объектов | GUI: `Button`, `Window` |
| **Builder** | Пошаговое создание сложного объекта | `new PizzaBuilder().cheese().ham().build()` |
| **Prototype** | Клонирование объектов | `obj.clone()` |

#### Структурные (Structural) — компоновка классов/объектов

| Паттерн | Суть | Пример |
|---|---|---|
| **Adapter** | Преобразует интерфейс одного класса в другой | `EuropeanSocket → USAdapter` |
| **Decorator** | Динамическое добавление функциональности | `BufferedInputStream(FileInputStream)` |
| **Proxy** | Заместитель для контроля доступа | `LazyImage.load()` |
| **Facade** | Простой интерфейс к сложной подсистеме | `Computer.start()` (всё внутри) |
| **Composite** | Дерево «часть-целое» | UI: `Panel(Button, TextField)` |

#### Поведенческие (Behavioral) — взаимодействие

| Паттерн | Суть | Пример |
|---|---|---|
| **Observer** | Оповещение подписчиков об изменениях | Event listeners |
| **Strategy** | Алгоритм подменяется на лету | `SortStrategy.sort(data)` |
| **Command** | Запрос как объект (отмена/повтор) | `UndoCommand`, `RedoCommand` |
| **Iterator** | Последовательный обход коллекции | `for item in collection` |
| **State** | Поведение меняется в зависимости от состояния | `TCPConnection` (Open/Close) |
| **Template Method** | Скелет алгоритма, детали в подклассах | `DataProcessor.parse()` + `transform()` |
