Протокол для обмена структурированной информации.
В основе лежит [[XML]] и каждое сообщение представляет собой XML-документ, который называет SOAP-конвертом Envelope и состоит из двух частей:
- Header - необязательный элемент, который содержит дополнительную информацию, относящуюся непосредственно к данным приложения, например, данные для аутентификации, информации о транзакциях или маршрутизации. Он добавляет гибкость и расширяемость
- Body - обязательный элемент, содержит сами данные запроса или ответа, которые обрабатывает приложение

Не привязан к конкретному протоколу прикладного уровня, но чаще всего используется с HTTP, иногда могут использоваться, например SMTP, FTP и другие. 
#### Пример SOAP сообщения 
```xml
<?xml version="1.0"?>
<env:Envelope xmlns:env="http://schemas.xmlsoap.org/soap/envelope/">
   <env:Header>
      <!-- Здесь, например, может быть токен для аутентификации -->
   </env:Header>
   <env:Body>
      <!-- Здесь находятся, например, данные для создания заказа или результат запроса -->
   </env:Body>
</env:Envelope>
```
