### Понятие криптосистемы

**Криптосистема** — набор алгоритмов шифрования/дешифрования. Состоит из:
- $P$ — пространство открытых текстов
- $C$ — пространство шифротекстов
- $K$ — пространство ключей
- $E_k: P \to C$ — алгоритм шифрования
- $D_k: C \to P$ — алгоритм дешифрования (для каждого $k \in K$)

**Условие стойкости:** $D_k(E_k(p)) = p$ (корректность) и без знания $k$ вычислительно невозможно получить $p$ из $c$.

**Классификация криптосистем:**

| Тип | Один ключ? | Скорость | Управление ключами |
|---|---|---|---|
| Симметричные | Да | Быстрые | Сложно (нужен secure канал) |
| Асимметричные | Нет (пара: pub/priv) | Медленные | Легко (pub — открытый) |

---

### Основная проблема симметричных шифров

**Проблема распределения ключей:** отправитель и получатель должны иметь общий секретный ключ, но как передать его по незащищённому каналу? Решение — гибридные схемы (асимметричное шифрование для обмена ключом, симметричное — для данных).

---

### Асимметричное шифрование

**Подход:** два ключа — открытый (public) и закрытый (private).
1. Открытым ключом шифруют, закрытым — расшифровывают.
2. Закрытый ключ не может быть получен из открытого (односторонняя функция).

**Алгоритмы:**
- **RSA** — основан на сложности факторизации больших чисел
- **ElGamal** — основан на дискретном логарифмировании
- **ECDH/ECDSA** — на эллиптических кривых

---

### Криптографические протоколы

**Распределение ключей (Diffie-Hellman):**
```
Alice: a, A = g^a mod p  →→→  Bob: b, B = g^b mod p
                      A → Bob
                  Alice ← B
Alice: K = B^a mod p        Bob: K = A^b mod p
```
Оба получают $K = g^{ab} \mod p$, перехватчик видит только $g^a, g^b$.

**Хеширование:** односторонняя функция $H(m)$ фиксированной длины (SHA-256). Свойства: необратимость, отсутствие коллизий, лавинный эффект.

**Электронная подпись (ЭЦП):** 
1. Отправитель хеширует сообщение $h = H(m)$
2. Подписывает хеш своим закрытым ключом $s = Sign(h, priv)$
3. Получатель проверяет: $Verify(h, s, pub)$
- Обеспечивает: аутентификацию, целостность, неотказуемость

### Симметричное шифрование

#### Блочные шифры

Шифруют данные блоками (DES: 64 бит, AES: 128 бит).

**Шифры Фейстеля:** блок делится на две половины, на каждом раунде одна половина преобразуется через функцию $F$ с ключом и XOR со второй.
- *Примеры:* DES, ГОСТ «Магма», Blowfish
- **Плюс:** расшифровка = та же схема с обратным порядком ключей

**Шифры не-Фейстеля (SP-сети — Substitution-Permutation):**
- Каждый раунд: SubBytes (S-box), ShiftRows (перестановка), MixColumns (смешивание), AddRoundKey (XOR с ключом)
- *Пример:* AES (Rijndael), ГОСТ «Кузнечик»
- **Плюс:** быстрее, лучшее перемешивание

#### Поточные шифры

Шифруют побитно (побайтно), генерируя ключевой поток — псевдослучайную последовательность (ПСП). XOR потока с данными.

**ПСП (псевдослучайная последовательность):**
- Генерируется детерминированным алгоритмом из seed
- Должна быть неотличима от случайной

**Примеры:**
- RC4 (устарел, уязвимости)
- A5/1 (GSM)
- ChaCha20 (современный, в TLS)

**Режимы работы DES/ГОСТ (как блочный = поточный):**
- **CTR (Counter)** — шифруется счётчик XOR с открытым текстом → поточный режим
- **CFB, OFB** — режимы обратной связи, превращают блочный шифр в поточный
- **GCM** — с аутентификацией (AEAD)
